AI 요금 계산기

챗GPT⁠·클로드⁠·제미나이 같은 AI를 API로 쓰면 한 달에 얼마가 나오는지, 회사별 공식 가격표로 계산해 원화로 비교합니다.

무료공식 가격표 기준가격 기준일 2026-10-27

챗GPT⁠·클로드⁠·제미나이 API로 서비스를 만들 때 한 달 요금이 얼마나 나오는지 공식 가격표 기준으로 원화로 계산해 주는 도구입니다.

이럴 때 씁니다
  • 회사에서 AI 챗봇⁠·자동화를 만들기 전에 비용을 어림할 때
  • 모델을 바꾸면 요금이 얼마나 달라지는지 비교할 때
  1. STEP 1

    비슷한 상황을 고릅니다

    상담 챗봇, 문서 요약처럼 비슷한 예시를 누르면 숫자가 알아서 채워집니다.

  2. STEP 2

    숫자를 내 상황에 맞춥니다

    한 번에 넣는 글 양, 받는 답 양, 하루 요청 수를 고치면 아래 표가 바로 다시 계산됩니다.

  3. STEP 3

    모델별 한 달 요금을 비교합니다

    모델마다 한 달 요금이 원화로 나옵니다. 위 버튼으로 회사를 골라 볼 수 있습니다.

한 번 도구를 열면 다음부터 이 도구는 바로 도구 화면으로 열립니다. 사용법은 위 탭에서 언제든 다시 볼 수 있습니다.

자주 묻는 질문

챗GPT 플러스⁠·클로드 프로 같은 구독료도 계산되나요?

계산하지 않습니다. 이 계산기는 쓴 만큼 내는 API 요금만 셉니다. 월 구독 요금제는 챗GPT⁠·클로드⁠·제미나이⁠·그록 요금제 비교에 정리했습니다.

가격은 어디서 가져오나요?

오픈AI⁠·앤트로픽⁠·구글⁠·xAI의 공식 가격표에서 확인한 값만 씁니다. 페이지 위에 가격 기준일이, 아래에 회사별 가격표 링크가 있습니다. 결제하기 전에는 공식 가격표를 다시 확인하세요.

글자 수는 토큰으로 어떻게 바꾸나요?

기본값은 한글 1글자 ≈ 1토큰으로 넉넉하게 잡았습니다. 모델마다 세는 방식이 다르며, 오픈AI 토크나이저⁠(o200k)⁠로 SHIFT 기사 2만 8천 자를 세어 보니 한글 약 1.7자가 1토큰이었습니다. 정확한 토큰 수를 알면 '토큰 수로'를 골라 직접 넣으세요.

환율은 무엇을 쓰나요?

한국자금중개가 고시한 미화 매매기준율을 기본값으로 씁니다. 기준일은 페이지 아래 가격 출처에 적혀 있고, 환율 칸에 다른 값을 넣으면 바로 다시 계산합니다.

세금이나 이미지⁠·검색 요금도 들어가나요?

들어가지 않습니다. 부가세, 이미지⁠·음성⁠·웹 검색 같은 추가 기능 요금, 회사별 할인과 무료 사용량은 빼고 계산합니다.

문서 비교 (두 파일에서 바뀐 곳 찾기)계약서⁠·보고서의 원본과 수정본을 넣으면 바뀐 곳을 색으로 표시하고 목록으로 정리합니다. 한글⁠(HWP)⁠·워드⁠·PDF를 바로 넣고, 금액⁠·날짜처럼 숫자가 바뀐 곳은 따로 표시합니다.엑셀 합치기 (여러 파일⁠⁠·시트를 한 표로)엑셀⁠(.xlsx)⁠·CSV 파일 여러 개나 시트 여러 장을 한 시트로 이어 붙이거나 한 파일에 모읍니다. 열 이름이 같은 칸끼리 맞추고, 어느 파일에서 온 줄인지 표시합니다.PDF 서명⁠⁠·도장 넣기 (손글씨 서명⁠⁠·이름 도장)PDF에 손으로 그린 서명, 이름으로 만든 도장, 도장 사진, 날짜를 원하는 자리에 넣습니다. 도장 사진의 흰 바탕은 지워 주고, 파일은 서버에 올리지 않습니다.한글⁠⁠·워드⁠⁠·PPT 글자 뽑기 (HWP⁠⁠·DOCX⁠⁠·PPTX → 텍스트)한글(HWP⁠·HWPX)⁠·워드⁠·파워포인트 파일 속 글과 표를 복사할 수 있는 텍스트⁠·마크다운으로 바꿉니다. 한글 프로그램이 없어도 읽고, 표는 칸을 지켜 AI에 붙여 넣기 좋습니다.JPG → PDF 변환 (사진 여러 장을 PDF 한 파일로)JPG⁠·PNG⁠·HEIC 사진 여러 장을 고른 순서대로 PDF 한 파일로 묶습니다. A4⁠·여백⁠·용량을 골라 서류 제출용 PDF를 만들고, 사진은 서버에 올리지 않습니다.PDF → JPG 변환 (쪽마다 사진으로 저장)PDF 쪽을 JPG⁠·PNG 사진으로 바꿉니다. 필요한 쪽만 고르고 선명도를 정하며, 여러 쪽을 세로로 이어 한 장으로 만들 수도 있습니다.표 → 차트 그림 만들기 (보고서⁠⁠·PPT용)엑셀에서 복사한 표나 AI가 준 마크다운 표로 막대⁠·꺾은선⁠·도넛 차트 그림을 만듭니다. PPT 16:9⁠·보고서 4:3 크기 PNG로 받거나 복사해 바로 붙입니다.내 프롬프트함 (빈칸 채워 바로 복사)자주 쓰는 프롬프트를 모아 두고 [회사명]⁠·[날짜] 같은 빈칸만 채워 바로 복사합니다. 한 번 적은 값은 기억하고, 가입 없이 이 브라우저에 저장합니다.프롬프트 점검기 (빠진 것⁠⁠·흐린 말 찾기)내가 쓴 프롬프트에서 빠진 역할⁠·맥락⁠·답 형식과 '잘⁠·적당히⁠·간단하게' 같은 흐린 말, 남은 빈칸, 개인정보를 찾아 표시하고 고친 틀을 만들어 줍니다.AI 답변 서식 정리기 (마크다운 기호 지우기)챗GPT⁠·클로드 답을 카톡⁠·한글에 붙이면 생기는 **, #, 표 기호를 지우고 제목⁠·목록⁠·표를 붙일 곳에 맞게 정리합니다. 한글⁠·워드에는 서식째, 엑셀에는 칸이 나뉜 표로 복사합니다.사진 위치정보⁠(EXIF) 지우기사진에 숨은 GPS 위치⁠·휴대폰 기종⁠·찍은 날짜를 보여 주고, 화질은 그대로 둔 채 그 정보만 지웁니다. 중고 거래⁠·블로그에 집에서 찍은 사진을 올리기 전에 쓰세요.이미지 압축⁠⁠·인스타 규격 자르기사진 용량을 1MB⁠·500KB 이하로 줄이거나 인스타그램 피드 1080×1350, 스토리⁠·릴스 1080×1920 크기로 여러 장을 한 번에 자릅니다. 자를 자리는 끌어서 고릅니다.PDF 합치기⁠⁠·나누기⁠⁠·쪽 뽑기PDF 여러 개를 하나로 합치고, 쪽마다⁠·범위마다 나누고, 필요한 쪽만 골라 새 PDF로 만듭니다. 계약서⁠·지원 서류도 서버에 올리지 않고 브라우저 안에서 처리합니다.엑셀⁠⁠·CSV → 마크다운 표 변환엑셀⁠·구글 시트에서 복사한 칸이나 .xlsx⁠·CSV 파일을 AI가 잘 읽는 마크다운 표로 바꿉니다. 필요한 열만 고르고 빈 줄을 빼서 AI에 보낼 양과 토큰을 줄입니다.프롬프트 비교 (바뀐 부분 표시)고치기 전과 고친 뒤의 프롬프트를 나란히 놓고 더한 말은 초록, 뺀 말은 빨강으로 표시합니다. 낱말⁠·글자⁠·줄 단위로 보고 토큰 수 변화까지 확인합니다.AI 구독료 계산기챗GPT⁠·클로드⁠·제미나이⁠·그록 요금제를 고르면 한 달⁠·1년 구독료를 원화로 더하고, 겹치는 챗봇 구독과 연간 결제로 아끼는 돈을 보여 줍니다.PDF 글자 뽑기 (텍스트⁠⁠·마크다운)PDF 속 글자를 복사할 수 있는 텍스트와 마크다운으로 바꿉니다. 머리글⁠·쪽 번호를 빼고 끊긴 줄을 문단으로 이어 AI에 올리기 좋게 정리합니다.유료 프로그램 무료 대체 찾기포토샵⁠·한글⁠·MS 오피스⁠·프리미어처럼 돈 내고 쓰던 프로그램 대신 쓸 무료 프로그램을 찾아 줍니다. 무료 범위와 원래 파일을 여는지까지 공식 페이지 기준으로 정리했습니다.글자 수⁠⁠·토큰 세기자기소개서⁠·보고서 글자 수를 공백 포함⁠·제외로 세고 바이트, 줄⁠·문단, 목표까지 남은 글자 수와 GPT 토큰 수를 한 번에 보여 줍니다.HEIC → JPG 변환아이폰 HEIC 사진을 JPG⁠·PNG로 바꿉니다. 여러 장을 한 번에 바꿔 ZIP으로 받을 수 있고, 사진은 서버로 올리지 않습니다.사진 속 글자 뽑기 (한국어 OCR)화면 캡처나 문서 사진에서 글자를 뽑아 복사할 수 있게 바꿔 줍니다. 한국어와 영어를 함께 읽고, 사진은 내 컴퓨터 밖으로 나가지 않습니다.AI 티 검사기글을 붙여 넣으면 AI가 자주 쓰는 표현과 문장 버릇을 찾아 표시하고 고치는 방법을 알려 줍니다. AI가 썼는지 판정하는 도구는 아닙니다.프롬프트 만들기역할⁠·맥락⁠·자료⁠·할 일⁠·조건⁠·답 형식⁠·확인 방법 일곱 칸만 채우면 챗GPT⁠·클로드⁠·제미나이에 바로 붙여 넣을 프롬프트가 완성됩니다.개인정보 자동 가리기글이나 엑셀 표에 들어 있는 주민등록번호⁠·전화번호⁠·이메일⁠·카드번호를 찾아 가립니다. 이름표로 바꿔 두면 나중에 AI 답을 원래 값으로 되돌릴 수도 있습니다.무료 실시간 크롬 번역 (회의 통역창)영어⁠·중국어⁠·일본어⁠·프랑스어로 진행되는 회의나 영상을 바로 한국어 자막으로 바꿔 줍니다. 크롬만 있으면 쓸 수 있습니다.
