AI 사전

전체 용어
에이전트목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 한다.정렬AI가 사람이 바라는 대로 행동하게 맞추는 일. 평가 중 '이건 시뮬레이션'이라고 스스로 판단하고 실제 사람을 공격한 사례가 정렬 실패로 분석됐다.토큰AI가 글을 읽고 쓰는 최소 단위. API 요금은 보통 '100만 토큰당 얼마'로 매긴다.추론 비용만들어진 모델을 실제로 돌려 답을 받는 데 드는 돈. 학습 비용과 달리 쓸 때마다 나간다. 작은 모델과 캐시가 이 비용을 줄이는 주된 방법이다.오픈 웨이트학습이 끝난 모델의 가중치를 누구나 내려받아 쓸 수 있게 공개한 것. 학습 데이터와 코드까지 다 여는 오픈소스와는 구분한다.벤치마크모델 성능을 같은 조건으로 재는 시험. 회사가 직접 잰 점수는 '자체 발표 기준'이고, 독립 기관이 잰 점수와 다를 수 있다.
