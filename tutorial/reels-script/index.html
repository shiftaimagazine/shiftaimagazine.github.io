프롬프트 1기본 틀: 규칙부터 알려주기

규칙 프롬프트는 모든 대본 요청 앞에 붙입니다. 한 번 넣어 두면 같은 대화창에서 형식만 바꿔 계속 쓸 수 있습니다.

이렇게 쓰세요주제와 목표 길이(15~22초)를 넣습니다. 장면마다 '화면에 보이는 것'과 '자막'을 나눠 받으면 편집할 때 바로 쓸 수 있습니다.
복사해서 쓰는 프롬프트
지금부터 [15~22]초 세로 영상 대본을 쓸 거야. 규칙: 1) 장면은 5~6개, 장면마다 초 단위 시간을 적고 합계가 [20]초를 넘지 않게. 2) 첫 1.5초에는 설명 없이 가장 놀라운 결과물이나 장면을 먼저 보여 줘. 3) 둘째 문장에서 끝까지 볼 이유를 줘(예: 방법은 마지막에, 정답은 마지막에). 4) 마지막 2.5초는 한 문장짜리 요청 하나만(저장, 댓글, 팔로우 중 하나). 5) 인사말, '여러분', '오늘은' 같은 도입은 금지. 출력은 '장면 | 시간 | 화면 | 자막' 표로. 주제: [주제]

프롬프트 2첫 1.5초 장면 고르기

가진 소재 가운데 첫 1.5초에 놓을 '가장 놀라운 결과물'을 고르게 합니다.

이렇게 쓰세요촬영하거나 만들어 둔 소재를 장면 설명으로 나열합니다. 과정보다 결과, 설명보다 대비가 첫 장면에 맞습니다.
복사해서 쓰는 프롬프트
아래는 내가 가진 영상 소재 목록이야. 이 중 첫 1.5초에 놓을 장면 후보 3개를 골라 줘. 기준은 1) 설명 없이 봐도 '어?' 하게 되는지, 2) 결과물이 한눈에 보이는지, 3) 소리 없이도 이해되는지야. 후보마다 화면에 얹을 자막 한 줄(9자 안쪽)과, 그 장면이 약한 이유도 솔직하게 적어 줘. 소재: [장면 설명 목록]

프롬프트 5둘 중 하나는 AI인 퀴즈 형식

실제 사진과 AI 생성 이미지를 나란히 보여 주고 맞히게 하는 참여형 대본입니다.

이렇게 쓰세요정답 공개를 끝 쪽에 두어 끝까지 보게 만듭니다. 정답과 함께 AI 이미지를 구별한 단서(손, 글자, 그림자 등)를 보여 줍니다. 실제 사진은 직접 찍었거나 사용 권한이 있는 것만 씁니다.
복사해서 쓰는 프롬프트
'둘 중 하나는 AI' 퀴즈 형식 대본을 써 줘. 소재: A는 [실제 사진 설명], B는 [AI 생성 이미지 설명], 정답은 [A/B]야. 구성: 첫 1.5초 두 장을 나란히 → 둘째 문장 '정답은 마지막에' → 두 장을 하나씩 확대하며 힌트 2장면 → 정답 공개와 구별 단서 1장면 → 마지막 2.5초 '맞혔는지 댓글로' 같은 요청 하나. 시청자가 3초 안에 고를 수 있게 자막은 짧게 해 줘. 캡션 끝에 'AI 생성 이미지 포함' 문구도 넣어 줘.

프롬프트 6같은 프롬프트로 모델을 겨루는 대결 형식

같은 프롬프트를 여러 AI 모델에 넣고 나온 결과를 비교합니다.

이렇게 쓰세요공정하게 비교하려면 같은 프롬프트, 같은 날짜, 같은 설정으로 만든 결과만 씁니다. 모델 이름과 테스트 날짜를 자막으로 넣습니다. 결과를 골라 한쪽이 유리하게 보이게 하지 않습니다.
복사해서 쓰는 프롬프트
대결 형식 대본을 써 줘. 같은 프롬프트 '[프롬프트]'를 [모델 A], [모델 B], [모델 C]에 [테스트 날짜]에 넣었고, 결과는 각각 [결과 설명]이야. 구성: 첫 1.5초 가장 차이가 큰 결과 한 장면 → 둘째 문장 '승자는 마지막에' → 프롬프트 공개 1장면 → 모델별 결과 각 1장면(모델 이름·날짜 자막) → 판정 1장면 → 마지막 2.5초 요청 하나. 판정은 내가 정한 기준 '[기준, 예: 손 모양 정확도]'으로만 하고, 결과에 없는 장단점은 지어내지 마.

프롬프트 7꿀팁 형식

AI 사용법 하나를 따라 할 수 있게 보여 주는 실용 대본입니다.

이렇게 쓰세요팁은 하나만 담습니다. 단계가 많으면 영상에서는 결과와 핵심 한 단계만 보여 주고 나머지는 캡션이나 저장용 글로 넘깁니다.
복사해서 쓰는 프롬프트
꿀팁 형식 대본을 써 줘. 팁: [팁 한 가지, 예: 엑셀 수식을 AI에 묻는 법]. 구성: 첫 1.5초 팁을 쓴 뒤의 결과 → 둘째 문장 '방법은 한 줄' 같은 볼 이유 → 하기 전 화면 1장면 → 실제 입력하는 장면 2장면 → 결과 1장면 → 마지막 2.5초 '저장해 두고 따라 하기' 같은 요청 하나. 화면에 보여 줄 프롬프트 문장은 따로 적어 주고, 캡션에 넣을 3줄 요약도 써 줘.

프롬프트 9완성 대본 점검

마지막으로 다 쓴 대본이 SHIFT AI 규칙에 맞는지 항목별로 채점하고 고칩니다.

이렇게 쓰세요AI가 쓴 대본이든 내가 쓴 대본이든 촬영·편집 전에 한 번 거칩니다. 규칙을 어긴 곳만 고치게 해야 대본이 다시 길어지지 않습니다.
복사해서 쓰는 프롬프트
아래 대본이 규칙에 맞는지 점검해 줘. 1) 전체 길이가 15~22초인지, 2) 장면이 5~6개인지, 3) 첫 1.5초에 결과물이 나오는지, 4) 둘째 문장이 끝까지 볼 이유를 주는지, 5) 표지 두 줄이 각각 9자 안쪽인지, 6) 마지막 2.5초에 요청이 하나뿐인지를 '항목 | 통과/실패 | 이유' 표로 보여 줘. 실패한 항목만 고친 대본을 다시 써 줘. 대본: [붙여 넣기]
보너스 · 올리기 전 체크리스트
  1. 첫 1.5초 장면만 봐도 무슨 영상인지 압니다
  2. 표지 두 줄을 직접 세어 보니 줄당 9자 안쪽입니다
  3. 소리를 끄고 봐도 자막만으로 이해됩니다
  4. 마지막 요청은 하나만 남깁니다
  5. 사실·숫자·날짜를 원문으로 확인했고 출처를 자막이나 캡션에 적었습니다
  6. AI로 만든 이미지·영상임을 캡션에 밝혔습니다
  7. 남의 결과물·음악은 사용 권한을 확인했습니다
솔직히 한계
  • 장면 수와 초 단위 규칙은 SHIFT AI 편집팀이 쓰는 기준이라 다른 채널과 주제에서도 같은 반응이 나온다고 보장하지는 않습니다.
  • AI는 글자 수와 시간을 틀리게 세거나 확인되지 않은 사실을 넣을 수 있으니 표지 글자 수와 자막 속 숫자는 직접 확인해야 합니다.
  • 남의 결과물이나 음악은 사용 권한을 먼저 확인하고 AI로 만든 이미지·영상은 캡션에 밝혀야 합니다.
