구글 시트에 문의가 쌓이면 AI가 답장 초안을 지메일에 써 두게, n8n 두 번째 자동화 6단계

구글 폼이나 문의 시트에 새 행이 생기면 n8n이 내용을 읽고 AI로 답장 초안을 만들어 지메일 임시보관함에 넣습니다. 보내기는 사람이 확인한 뒤 직접 누르는 구조입니다.

통째로 맡기는 프롬프트Claude Code에 붙여 넣으면 이 글의 단계를 대신 진행합니다
역할: 너는 n8n 워크플로를 만드는 자동화 도우미야. 맥락: 구글 시트 [시트 이름]에 고객 문의가 한 행씩 쌓여. 열은 접수시각, 이름, 이메일, 문의내용, 상태야. 새 행이 생기면 AI로 답장 초안을 만들어 지메일 임시보관함에 넣고, 상태 열을 '초안 작성'으로 바꾸고 싶어. 입력: 우리 가게 FAQ [붙여 넣기], 답장 말투 [존댓말, 5문장 이내], 쓸 채팅 모델 [Google Gemini / OpenAI 등]. 작업: Google Sheets Trigger(Row added) → Basic LLM Chain(Prompt: Define below, 채팅 모델 연결) → Gmail(Resource: Draft, Operation: Create, 받는 사람은 이메일 열) → Google Sheets(Update Row, 상태 열) 순서의 워크플로 JSON을 만들어 줘. 제약: API 키와 자격 증명은 넣지 말고 비워 둬. 메일을 바로 보내는 Send 동작은 쓰지 마. docs.n8n.io에 있는 노드·설정 이름만 쓰고 모르는 설정은 '확인 필요'로 적어 줘. timezone은 Asia/Seoul. 출력: JSON 전체, 가져온 뒤 내가 화면에서 할 일 목록. 검증: Send 동작이 없는지, 프롬프트에 FAQ에 없는 약속을 하지 말라는 규칙이 있는지, 자격 증명이 비어 있는지 마지막에 점검해 줘.
필요한 것n8n(클라우드 체험 또는 내 PC), 구글 계정(시트·지메일), AI 모델 API 키 또는 n8n 클라우드 Gateway credits
걸리는 시간40분
왜 필요한가요자주 오는 문의(영업시간, 배송, 환불 절차)에 매번 처음부터 답장을 쓰는 시간이 줄어듭니다. 자동 발송이 아니라 초안만 만들게 하면 AI가 틀린 내용을 써도 고객에게 나가기 전에 걸러집니다.
첫 n8n 튜토리얼에서 '매일 아침 AI 소식 요약 메일'을 만들었다면 이번에는 시트의 변화에 반응하는 흐름을 만듭니다. Google Sheets Trigger → Basic LLM Chain(+채팅 모델) → Gmail(Draft: Create) → Google Sheets(Update Row) 네 노드를 잇습니다. 노드와 설정 이름은 2026년 11월 5일 n8n 공식 문서 기준이고 편집부는 이번 글을 위해 이 흐름을 실제 계정으로 돌려 보지는 않았습니다. 구글 계정 연결 방법은 n8n의 구글 자격 증명 문서를 따릅니다.

STEP 1문의 시트 만들기5분

n8n이 읽을 열 이름을 먼저 정합니다.

1행에 접수시각, 이름, 이메일, 문의내용, 상태를 적습니다. 구글 폼을 쓰면 응답이 연결된 시트에 자동으로 쌓이니 그 시트 오른쪽에 상태 열만 더합니다. 시험할 때는 내 메일 주소로 가짜 문의 두세 줄을 넣어 둡니다.

STEP 2새 행을 감시하는 트리거5분

시트에 행이 더해질 때 워크플로가 시작되게 합니다.

새 워크플로에서 첫 노드로 Google Sheets Trigger를 고르고 이벤트를 Row added로 둡니다. 이벤트는 Row added, Row updated, Row added or updated 세 가지가 있습니다. 구글 계정을 연결하고 문서와 시트를 고른 뒤 Fetch Test Event로 가짜 문의가 들어오는지 봅니다.

STEP 3AI 답장 초안 노드10분

Basic LLM Chain에 FAQ와 말투 규칙을 넣어 초안을 쓰게 합니다.

Basic LLM Chain을 잇고 Prompt를 Define below로 바꾼 뒤 아래 프롬프트를 넣습니다. 노드 아래에 쓸 채팅 모델 노드를 연결합니다. 문의 내용은 트리거에서 넘어온 값을 표현식으로 끼워 넣습니다. FAQ에 없는 질문은 '담당자가 확인 후 답변'으로 쓰게 해야 AI가 지키지 못할 약속을 하지 않습니다.
복사해서 쓰는 프롬프트
너는 [가게 이름] 고객 문의에 답장 초안을 쓰는 직원이야. 아래 FAQ에 있는 내용으로만 답하고, FAQ에 없는 질문이나 환불·보상 요청은 '담당자가 확인한 뒤 하루 안에 다시 연락드리겠습니다'라고만 써. 존댓말, 5문장 이내, 인사 한 줄로 시작해. 가격·날짜는 FAQ에 적힌 값만 써. FAQ: [붙여 넣기] 고객 이름: {{ $json['이름'] }} 문의 내용: {{ $json['문의내용'] }}

STEP 4지메일 임시보관함에 넣기5분

보내지 않고 초안으로만 저장합니다.

Gmail 노드를 잇고 Resource를 Draft, Operation을 Create로 고릅니다. 받는 사람은 트리거의 이메일 값, 제목은 '[가게 이름] 문의 답변드립니다', 본문은 Basic LLM Chain이 낸 글을 표현식으로 넣습니다. Message 쪽의 Send나 Reply를 고르면 바로 발송되니 쓰지 않습니다.

STEP 5상태 열 바꾸기5분

같은 문의에 초안이 두 번 생기지 않게 처리 표시를 남깁니다.

마지막에 Google Sheets 노드를 잇고 Update Row를 골라 해당 행의 상태 열에 '초안 작성'을 적습니다. 행을 찾는 기준으로는 접수시각이나 이메일처럼 행마다 다른 값을 씁니다. 사람이 초안을 확인해 보낸 뒤에는 상태를 '발송'으로 직접 바꿉니다.

STEP 6시험하고 켜기10분

가짜 문의로 끝까지 돌려 본 뒤 워크플로를 켭니다.

시트에 새 가짜 문의를 한 줄 더하고 워크플로를 실행해 지메일 임시보관함에 초안이 생기는지, 상태 열이 바뀌는지 확인합니다. FAQ에 없는 질문(예: '환불해 주세요')도 넣어 '담당자 확인' 문장이 나오는지 봅니다. 문제가 없으면 저장하고 켭니다. 내 PC에 설치한 n8n은 PC와 n8n이 켜져 있을 때만 동작합니다.
솔직히 한계
  • 이 흐름은 공식 문서의 노드 이름으로 구성했고 편집부가 실제 구글 계정으로 돌려 보지는 않았습니다. 노드 버전에 따라 설정 이름이 조금 다를 수 있습니다.
  • 고객 이름과 문의 내용이 AI 모델 제공사로 전달됩니다. 개인정보처리방침에 외부 처리 위탁 내용이 필요한지 확인하세요.
  • 모델 API 사용료와 n8n 클라우드 요금은 각 요금표를 따릅니다. 시트 트리거는 일정 간격으로 확인하는 방식이라 몇 분 늦게 반응할 수 있습니다.
