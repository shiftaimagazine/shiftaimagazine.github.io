코딩 몰라도 되는 클로드 코드 첫 설치와 첫 작업, 7단계

터미널을 처음 여는 사람 기준으로 클로드 코드를 설치하고 로그인합니다. 폴더 속 파일 정리, CSV 합치기 같은 사무 작업을 맡겨 봅니다. 허락을 묻는 방식과 되돌리기 어려운 일을 막는 습관도 함께 다룹니다.

바쁘면 이것만
  1. 맥은 터미널, 윈도우는 파워셸을 열고 공식 설치 명령을 붙여 넣습니다.
  2. 새 창에서 claude -⁠-⁠version으로 설치를 확인하고, 연습용 폴더에서 claude를 실행해 로그인합니다.
  3. 처음에는 '이 폴더에 뭐가 있어?' 같은 읽기만 시키고, 바꾸는 일은 사본 폴더에서 허락을 확인하며 진행합니다.
클로드 코드 문서 · 빠른 시작 ↗클로드 코드 문서 · 터미널 안내 ↗
필요한 것클로드 프로 이상 구독(또는 Claude Console 계정), 윈도우⁠·맥 PC
걸리는 시간30분
왜 필요한가요클로드 코드는 개발 도구로 알려졌지만 내 컴퓨터의 파일을 읽고 고치고 명령을 실행하는 능력은 사무 일에도 그대로 쓰입니다. 파일 수백 개 이름 바꾸기, 엑셀 여러 개 합치기처럼 손으로 하면 한 시간 걸리는 일을 말로 맡길 수 있습니다.
공식 빠른 시작 문서 기준으로 클로드 코드는 클로드 프로⁠·맥스⁠·팀⁠·엔터프라이즈 구독이나 Claude Console 계정으로 쓰고 무료 요금제에서는 쓸 수 없습니다. 터미널이 낯설다면 데스크톱 앱의 Code 탭이나 웹(claude.ai/code)⁠에서도 쓸 수 있지만 이 글은 내 PC 폴더를 직접 다루는 터미널 방식을 따라갑니다. 명령은 2026년 11월 5일 공식 문서에 적힌 그대로 옮겼습니다. 한도를 아끼는 법과 스킬⁠·MCP를 붙이는 법은 매거진에 따로 정리한 두 튜토리얼에 있습니다.

STEP 1어디서 쓸지 고르기2분

같은 클로드 코드를 터미널, 데스크톱 앱, 웹에서 쓸 수 있습니다.

내 PC의 폴더와 파일을 바로 다루려면 터미널이나 데스크톱 앱이 맞습니다. 웹은 깃허브 저장소처럼 인터넷에 있는 코드를 다룰 때 씁니다.
어디서맞는 경우준비
터미널내 PC 폴더를 다루고 명령을 직접 보고 싶을 때설치 명령 한 줄
데스크톱 앱 Code 탭터미널 창이 부담스러울 때클로드 데스크톱 앱
웹(claude.ai/code)깃허브 저장소 작업브라우저

STEP 2터미널 열기2분

명령을 입력하는 검은 창을 엽니다.

맥은 Spotlight⁠(⌘+스페이스)⁠에서 '터미널'을 찾아 엽니다. 윈도우는 시작 메뉴에서 'PowerShell'을 찾아 엽니다. 윈도우 창 맨 앞에 PS C:\가 보이면 파워셸이고 PS 없이 C:\만 보이면 명령 프롬프트⁠(CMD)⁠입니다. 공식 문서는 윈도우에 Git for Windows를 함께 설치하길 권합니다.

STEP 3설치 명령 붙여 넣기5분

운영체제에 맞는 한 줄을 붙여 넣고 Enter를 누릅니다.

설치하는 동안에는 진행 표시가 나오지 않으니 끝날 때까지 기다립니다. 이 방식으로 설치하면 이후 업데이트는 자동으로 됩니다. 오류가 나면 공식 문서의 '설치 문제 해결' 페이지에서 오류 문구로 찾습니다.
맥⁠·리눅스⁠(터미널)
curl -fsSL https://claude.ai/install.sh | bash

확인문서 기준: 진행 표시 없이 내려받은 뒤 설치가 끝납니다

윈도우⁠(파워셸)
irm https://claude.ai/install.ps1 | iex

확인문서 기준: 'irm'을 알 수 없다는 오류가 나면 파워셸이 아니라 CMD에 붙여 넣은 것입니다

STEP 4설치 확인1분

새 터미널 창에서 버전이 나오는지 봅니다.

설치한 창이 아니라 새로 연 창에서 확인해야 합니다. 'claude를 찾을 수 없다'는 메시지가 나오면 공식 문서의 PATH 설정 안내를 따릅니다.
터미널
claude --version

확인문서 기준: 버전 번호 뒤에 (Claude Code)⁠가 붙어 나옵니다

STEP 5연습용 폴더에서 시작하고 로그인5분

클로드 코드는 실행한 폴더 안을 작업 범위로 씁니다.

바탕화면에 '클로드연습' 폴더를 만들고 정리해 볼 파일 사본 몇 개를 넣습니다. 터미널에서 cd 명령으로 그 폴더에 들어간 뒤 claude를 입력합니다. 처음 실행하면 브라우저가 열리며 클로드 계정 로그인을 요청하고 한 번 로그인하면 다음부터는 묻지 않습니다.
맥⁠(예시)
cd ~/Desktop/클로드연습
claude

확인로그인을 마치면 버전, 현재 모델, 작업 폴더가 위에 표시된 입력 화면이 나옵니다

STEP 6첫 작업은 읽기만5분

파일을 바꾸기 전에 클로드가 폴더를 어떻게 보는지 확인합니다.

읽기만 하는 질문은 파일을 바꾸지 않습니다. 결과를 보고 정리 계획이 마음에 들면 다음 단계로 넘어갑니다.
복사해서 쓰는 프롬프트
이 폴더에 어떤 파일들이 있는지 종류별로 정리해서 알려줘. 파일 이름 규칙이 제각각이면 어떤 규칙으로 통일하면 좋을지 제안만 해 줘. 아직 아무것도 바꾸거나 지우지 마.

STEP 7바꾸는 일은 허락을 보며10분

클로드 코드는 파일을 바꾸거나 명령을 실행하기 전에 허락을 묻습니다.

허락 요청이 나오면 무엇을 바꾸는지 읽고 Yes를 고릅니다. Shift+Tab으로 허락 방식(권한 모드)⁠을 바꿀 수 있는데, 익숙해질 때까지는 매번 묻는 방식으로 둡니다. 지우기처럼 되돌리기 어려운 일은 처음부터 '지우지 말고 _삭제예정 폴더로 옮겨'라고 적어 둡니다. /help는 명령 목록, /clear는 대화 지우기, /exit는 종료이고 다음 날 이어 하려면 같은 폴더에서 claude -c를 입력합니다.
복사해서 쓰는 프롬프트
이 폴더의 사진 파일 이름을 '촬영날짜_원래이름' 형식으로 바꿔 줘. 날짜는 사진 정보에서 읽고, 날짜가 없는 파일은 그대로 둬. 바꾸기 전에 바뀔 이름 목록을 먼저 보여 주고, 내가 좋다고 하면 그때 바꿔. 어떤 파일도 지우지 마.
넣는 것 (예시)
같은 폴더의 CSV 여러 개를 하나로 합쳐 달라는 요청
나오는 것 (예시)
합칠 파일과 열 이름 차이를 먼저 보여 주고, 허락을 받은 뒤 '합친파일.csv'를 새로 만듭니다(원본은 그대로)
보너스 · 사고를 막는 습관
  1. 처음에는 원본 대신 사본 폴더에서 시킵니다
  2. '지우지 말고 옮겨'를 요청에 넣습니다
  3. 허락 요청 내용을 읽지 않고 Yes를 누르지 않습니다
  4. 회사 기밀 폴더에서는 회사가 허용한 계정으로만 씁니다
  5. 끝나면 /exit로 닫습니다
솔직히 한계
  • 명령은 공식 문서 기준이며 편집부가 이 글을 위해 새로 설치해 보지는 않았습니다. 설치 방식과 화면은 업데이트로 바뀔 수 있습니다.
  • 클로드 코드는 대화와 같은 사용량 한도를 나눠 씁니다. 오래 작업하면 대화 쪽 한도도 함께 줄어듭니다.
  • 폴더 안 파일 내용은 처리 과정에서 앤트로픽 서버로 보내집니다. 민감한 파일이 든 폴더에서 실행하지 마세요.
