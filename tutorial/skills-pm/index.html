기획자⁠·PM이 깔아 두면 좋은 AI 스킬 7개, 기획서⁠·인터뷰 정리⁠·로드맵⁠·보고까지

아이디어를 기획서(PRD)로 바꾸고 사용자 인터뷰를 정리하고 로드맵과 이해관계자 보고를 쓰는 스킬을 골랐습니다. 앤트로픽 공식 product-management 플러그인과 별 2만 8천 개의 PM 스킬 모음이 중심입니다.

걸리는 시간20분
왜 필요한가요기획자는 같은 형식의 문서를 매주 씁니다. 형식과 점검 질문을 스킬로 깔아 두면 빈 문서에서 시작하지 않고 AI가 빠진 항목(성공 지표, 범위 밖 항목, 위험)을 먼저 물어 줍니다.
앤트로픽 knowledge-work-plugins의 product-management 플러그인은 기획서 작성, 로드맵 갱신, 이해관계자 보고·사용자 조사 정리, 경쟁 분석, 지표 검토, 스프린트 계획 스킬을 담았습니다. 파베우 후린의 pm-skills는 탐색·전략·실행·시장 조사·데이터 분석·출시 등 플러그인 9개로 나뉘어 있어 필요한 묶음만 고를 수 있습니다. 딘 피터스의 Product-Manager-Skills는 스킬이 77개로 많지만 비상업 라이선스라 회사 업무에 쓰기 전에 조건부터 봅니다.

STEP 1설치 전에 알아 둘 것5분

스킬은 SKILL.md 설명서와 보조 파일이 든 폴더이고 필요한 순간에만 AI가 꺼내 읽습니다.

클로드 코드에서는 저장소를 플러그인 마켓플레이스로 등록한 뒤 필요한 플러그인만 설치합니다. claude.ai에서는 프로 이상 요금제에서 설정 → Capabilities의 Skills 칸에 스킬 폴더를 ZIP으로 올립니다. 이때 코드 실행과 파일 만들기가 켜져 있어야 합니다. 앤트로픽 도움말은 믿을 수 있는 곳의 스킬만 설치하고 그렇지 않은 스킬은 안에 든 스크립트와 외부 접속 지시를 먼저 읽어 보라고 안내합니다.

스킬 설명은 대부분 영어지만 한국어로 요청해도 상황에 맞는 스킬이 불려 나옵니다. 잘 안 불리면 '○○ 스킬을 써서'라고 이름을 적어 줍니다. 설치와 삭제 방법은 '클로드 코드에 스킬·MCP 붙이는 법, 설치부터 떼기까지 8단계'에 자세히 정리했습니다.

어디서 쓰나설치 방법조건
클로드 코드/plugin marketplace add 저장소 → /plugin install 플러그인@마켓플레이스클로드 프로 이상 또는 Console 계정
claude.ai(웹·앱)설정 → Capabilities → Skills에서 스킬 폴더 ZIP을 'Upload skill'프로·맥스·팀·엔터프라이즈, 코드 실행 켜기
코덱스·커서 등 다른 에이전트npx skills add 저장소 (-a 로 대상 에이전트 지정)Node.js 22.20 이상

STEP 2기획서(PRD) · write-spec3분

막연한 아이디어나 요청을 목표·범위·요구 사항이 있는 기획서로 바꿉니다.

문제 정의, 사용자 이야기, 범위 밖 항목, 성공 지표를 묻고 채워 갑니다. 회사 기획서 양식이 있다면 칸 이름을 알려 주면 그 틀을 따릅니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
클로드 코드
/plugin marketplace add anthropics/knowledge-work-plugins
/plugin install product-management@knowledge-work-plugins

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
write-spec 스킬로 '[장바구니에 담아 둔 상품 가격이 내리면 알림]' 기능 기획서를 써 줘. 모르는 항목은 추측하지 말고 나에게 질문해 줘. 성공 지표는 숫자로 제안해 줘.

STEP 3인터뷰⁠·설문 정리 · synthesize-research3분

인터뷰 기록, 설문 응답, 고객 문의를 주제별 인사이트로 묶습니다.

같은 말을 한 사람이 몇 명인지와 원문 인용을 함께 남겨 근거를 확인할 수 있게 합니다. 디자이너와 함께 쓴다면 design 플러그인의 research-synthesis와 비슷한 역할입니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
synthesize-research 스킬로 아래 인터뷰 기록 8개를 정리해 줘. 주제별로 묶고, 주제마다 언급한 사람 수와 대표 원문 인용 2개, 우리가 결정해야 할 질문을 적어 줘. 기록: [붙여 넣기]

STEP 4로드맵 갱신 · roadmap-update3분

새 과제가 들어왔을 때 무엇을 미루고 무엇을 당길지 정리합니다.

우선순위가 바뀐 이유와 영향을 함께 써 주기 때문에 팀 공유 문서로 바로 씁니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
roadmap-update 스킬로 다음 분기 로드맵을 다시 짜 줘. 지금 로드맵은 [목록], 새로 들어온 요청은 [요청], 개발 인원은 [3명]이야. 미룰 것과 그 이유를 표로 보여 줘.

STEP 5이해관계자 보고 · stakeholder-update3분

주간·월간 진행 보고·출시 공지, 위험 보고를 받는 사람에 맞춰 씁니다.

임원용은 짧게 결론부터, 개발팀용은 일정과 막힌 곳 위주로 바꿔 줍니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
stakeholder-update 스킬로 이번 주 진행 보고를 써 줘. 받는 사람은 [본부장], 이번 주 한 일은 [목록], 막힌 곳은 [디자인 확정 지연]이야. 다섯 줄 안으로, 필요한 결정은 맨 위에.

STEP 6가설⁠·실험 설계 · pm-product-discovery3분

아이디어를 가정으로 쪼개 무엇부터 검증할지와 실험 방법을 정합니다.

기회-해결책 나무, 가정 우선순위, 인터뷰 질문지, 기능 요청 분석 스킬이 한 플러그인에 들어 있습니다. 저장소는 phuryn/pm-skills이고 별 약 2만 8천, 라이선스 MIT, 마지막 커밋은 10월 29일입니다.
클로드 코드
/plugin marketplace add phuryn/pm-skills
/plugin install pm-product-discovery@pm-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
identify-assumptions-new 스킬로 '[구독형 반찬 배달]' 아이디어의 가정을 뽑아 줘. 가장 위험한 가정 3개를 골라 일주일 안에 할 수 있는 검증 실험을 제안해 줘.

STEP 7실행 문서 묶음 · pm-execution3분

OKR, 사용자 스토리, 스프린트 계획, 회고 릴리스 노트, 사전 부검(프리모템)을 씁니다.

같은 플러그인에 회의 요약과 테스트 시나리오 스킬도 있어 스프린트 한 바퀴에 필요한 문서가 대부분 모여 있습니다. 저장소는 phuryn/pm-skills이고 별 약 2만 8천, 라이선스 MIT, 마지막 커밋은 10월 29일입니다.
클로드 코드
/plugin install pm-execution@pm-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
pre-mortem 스킬로 [다음 달 결제 개편 출시]가 실패했다고 가정하고 실패 원인 10개를 뽑아 줘. 원인마다 지금 할 수 있는 예방 조치를 붙여 줘.

STEP 8더 많은 틀이 필요할 때 · Product-Manager-Skills3분

경쟁 분석, 고객 여정 지도, JTBD(해야 할 일), 출시 종료 계획 등 77개 틀을 담은 모음입니다.

스킬 수가 많아 필요한 것만 골라 설치할 수 있습니다. 라이선스가 CC BY-NC-SA 4.0(비상업)이라 회사 업무에 쓰거나 결과물을 판매할 계획이라면 먼저 조건을 확인합니다. 마켓플레이스 이름이 phuryn/pm-skills와 같은 pm-skills라서 둘을 함께 쓰려면 설치할 때 이름을 확인해야 합니다. 저장소는 deanpeters/Product-Manager-Skills이고 별 약 7,700, 라이선스 CC BY-NC-SA 4.0(비상업), 마지막 커밋은 10월 15일입니다.
클로드 코드
/plugin marketplace add deanpeters/Product-Manager-Skills
/plugin install product-manager-skills@pm-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

솔직히 한계
  • 별 수와 마지막 커밋은 2026년 11월 5일 기준입니다. 스킬 이름과 설치 명령은 저장소 쪽에서 자주 바뀌니 설치 전에 README를 한 번 더 확인하세요.
  • 편집부는 각 스킬의 SKILL.md와 README를 읽고 골랐고 모든 스킬을 실제 업무 자료로 돌려 보지는 않았습니다.
  • 기획 스킬은 우리 회사 사정(조직, 예산, 기술 부채)을 모르고 일반적인 틀로 답합니다. 맥락을 충분히 붙여 넣어야 쓸 만한 결과가 나옵니다.
  • 비상업 라이선스 스킬은 회사 안에서 쓰는 것만으로도 조건에 걸릴 수 있어 법무팀에 먼저 물어보는 편이 안전합니다.
