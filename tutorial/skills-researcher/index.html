왜 필요한가요연구에서 AI가 가장 위험한 순간은 없는 논문을 인용하거나 숫자를 지어낼 때입니다. 출처를 실제 학술 데이터베이스에서 찾게 하고 근거를 남기도록 설계된 스킬을 쓰면 이런 사고를 줄이고 반복 작업을 맡길 수 있습니다.
K-Dense-AI의 scientific-agent-skills(옛 이름 claude-scientific-skills)는 문헌 검색, 데이터베이스 조회, 통계, 생물정보학, 논문·포스터·연구비 신청서 작성까지 스킬 177개를 담았습니다. 저장소가 커서 필요한 스킬만 골라 설치하는 편이 좋습니다. 앤트로픽 공식 스킬 가운데 문서를 함께 쓰는 doc-coauthoring과 PDF 읽기·추출 스킬도 연구 작업에 자주 쓰입니다. 생명과학 연구라면 앤트로픽 knowledge-work-plugins의 bio-research 플러그인이 PubMed·bioRxiv 같은 자료원 연결을 함께 제공합니다.

STEP 1설치 전에 알아 둘 것5분

스킬은 SKILL.md 설명서와 보조 파일이 든 폴더이고 필요한 순간에만 AI가 꺼내 읽습니다.

클로드 코드에서는 저장소를 플러그인 마켓플레이스로 등록한 뒤 필요한 플러그인만 설치합니다. claude.ai에서는 프로 이상 요금제에서 설정 → Capabilities의 Skills 칸에 스킬 폴더를 ZIP으로 올립니다. 이때 코드 실행과 파일 만들기가 켜져 있어야 합니다. 앤트로픽 도움말은 믿을 수 있는 곳의 스킬만 설치하고 그렇지 않은 스킬은 안에 든 스크립트와 외부 접속 지시를 먼저 읽어 보라고 안내합니다. K-Dense 저장소는 플러그인 마켓플레이스 대신 skills 명령이나 git clone으로 설치합니다.

스킬 설명은 대부분 영어지만 한국어로 요청해도 상황에 맞는 스킬이 불려 나옵니다. 잘 안 불리면 '○○ 스킬을 써서'라고 이름을 적어 줍니다. 설치와 삭제 방법은 '클로드 코드에 스킬·MCP 붙이는 법, 설치부터 떼기까지 8단계'에 자세히 정리했습니다.

어디서 쓰나설치 방법조건
클로드 코드/plugin marketplace add 저장소 → /plugin install 플러그인@마켓플레이스클로드 프로 이상 또는 Console 계정
claude.ai(웹·앱)설정 → Capabilities → Skills에서 스킬 폴더 ZIP을 'Upload skill'프로·맥스·팀·엔터프라이즈, 코드 실행 켜기
코덱스·커서 등 다른 에이전트npx skills add 저장소 (-a 로 대상 에이전트 지정)Node.js 22.20 이상

STEP 2문헌 검토 · literature-review3분

PubMed, arXiv, bioRxiv, Semantic Scholar 등에서 체계적·범위·서술적 문헌 검토를 진행합니다.

검색어, 포함·제외 기준, 기간을 정해 주면 검토 과정을 기록하며 진행합니다. 논문 한두 편만 빨리 찾을 때는 같은 저장소의 paper-lookup이 가볍습니다. 저장소는 K-Dense-AI/scientific-agent-skills이고 별 약 5만 5천, 라이선스 MIT, 마지막 커밋은 11월 2일입니다.
터미널
npx skills add K-Dense-AI/scientific-agent-skills --skill literature-review -a claude-code

확인문서 기준: 고른 스킬만 클로드 코드용 폴더에 설치됩니다

복사해서 쓰는 프롬프트
literature-review 스킬로 '[청소년 수면 시간과 학업 성취]' 주제의 범위 검토(scoping review)를 해 줘. 기간은 [2016~2026년], 포함 기준은 [실증 연구, 영어·한국어], 제외 기준은 [사설·학회 초록]이야. 검색식, 찾은 논문 수, 제외 이유를 기록하고 논문마다 DOI를 붙여 줘.

STEP 3인용 관리 · citation-management3분

OpenAlex, PubMed, 구글 스칼라에서 서지 정보를 찾아 정확한 인용으로 정리합니다.

AI가 만든 참고문헌 목록을 실제 데이터베이스와 대조해 없는 논문을 걸러 낼 때 특히 쓸모가 있습니다. 조테로를 쓴다면 pyzotero 스킬로 라이브러리와 연결할 수 있습니다(조테로 API 키 필요). 저장소는 K-Dense-AI/scientific-agent-skills이고 별 약 5만 5천, 라이선스 MIT, 마지막 커밋은 11월 2일입니다.
복사해서 쓰는 프롬프트
citation-management 스킬로 아래 참고문헌 목록을 검증해 줘. 항목마다 실제 논문이 있는지, DOI·저자·연도·학술지가 맞는지 확인하고 틀린 곳은 고친 값을, 찾을 수 없는 항목은 '확인 불가'로 표시해 줘. 목록: [붙여 넣기]

STEP 4표본 수와 통계 · statistical-power3분

연구를 시작하기 전에 필요한 표본 수와 검정력을 계산합니다.

분석 단계에서는 같은 저장소의 statistical-analysis가 검정 선택, 가정 확인, 효과 크기, APA 형식 보고까지 안내합니다. 저장소는 K-Dense-AI/scientific-agent-skills이고 별 약 5만 5천, 라이선스 MIT, 마지막 커밋은 11월 2일입니다.
복사해서 쓰는 프롬프트
statistical-power 스킬로 두 집단 평균 비교 연구의 표본 수를 계산해 줘. 예상 효과 크기는 [d=0.4], 유의수준 [0.05], 검정력 [0.8], 탈락률 [15%]를 반영해 줘. 계산 근거와 파이썬 코드를 함께 보여 줘.

STEP 5논문 쓰기 · scientific-writing3분

원고 초안을 쓰고 고치며 주장마다 근거 출처를 남깁니다.

연구 보고 지침(예: 임상시험의 CONSORT) 항목을 빠뜨렸는지도 점검하도록 설계돼 있습니다. 투고 형식은 venue-templates, 포스터는 latex-posters나 pptx-posters가 맡습니다. 저장소는 K-Dense-AI/scientific-agent-skills이고 별 약 5만 5천, 라이선스 MIT, 마지막 커밋은 11월 2일입니다.
복사해서 쓰는 프롬프트
scientific-writing 스킬로 아래 결과 메모를 바탕으로 논문의 '결과' 절 초안을 써 줘. 숫자는 메모에 있는 값만 쓰고, 해석은 '고찰'로 미뤄 줘. 문장마다 근거가 된 표·그림 번호를 괄호로 붙여 줘. 메모: [붙여 넣기]

STEP 6동료 평가 초안 · peer-review3분

투고 전 자기 원고 점검이나 심사 의견 초안을 구조화해 만듭니다.

승인받은 검토 작업에만 쓰도록 설명돼 있습니다. 남의 원고를 심사할 때는 학술지가 AI 사용을 허용하는지 먼저 확인합니다. 주장의 근거 수준을 따지려면 scientific-critical-thinking 스킬을 함께 씁니다. 저장소는 K-Dense-AI/scientific-agent-skills이고 별 약 5만 5천, 라이선스 MIT, 마지막 커밋은 11월 2일입니다.
복사해서 쓰는 프롬프트
peer-review 스킬로 내 원고를 투고 전에 점검해 줘. 심사위원 관점에서 주요 문제(방법·통계·결론의 비약)와 사소한 문제를 나누고, 각 지적에 고칠 방법을 붙여 줘.

STEP 7함께 쓰는 문서 · doc-coauthoring3분

제안서, 기술 문서, 의사결정 문서처럼 긴 글을 질문과 초안을 주고받으며 함께 씁니다.

앤트로픽 공식 예시 스킬입니다. 연구 계획서나 연구비 신청서의 뼈대를 잡을 때 맞고 미국 연구비 형식(NSF·NIH 등)은 K-Dense의 research-grants 스킬이 더 구체적입니다. 저장소는 anthropics/skills이고 별 약 18만, 라이선스 대부분 Apache 2.0(docx·pdf·pptx·xlsx는 소스 공개), 마지막 커밋은 10월 28일입니다.
클로드 코드
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
doc-coauthoring 스킬로 [학위 논문 연구 계획서] 초안을 같이 쓰자. 먼저 필요한 정보를 질문하고, 목차를 확정한 뒤 장별로 초안을 써 줘.

STEP 8PDF 읽기⁠·추출 · pdf3분

논문 PDF에서 글과 표를 뽑고 합치고 나눕니다.

앤트로픽 문서 스킬 중 하나로 claude.ai 유료 요금제에는 이미 들어 있습니다. 스캔본이라 글자가 안 나오면 SHIFT AI의 '사진 속 글자 뽑기'나 OCR 기능이 필요합니다. 저장소는 anthropics/skills이고 별 약 18만, 라이선스 대부분 Apache 2.0(docx·pdf·pptx·xlsx는 소스 공개), 마지막 커밋은 10월 28일입니다.
클로드 코드
/plugin install document-skills@anthropic-agent-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
pdf 스킬로 이 폴더의 논문 PDF 10편에서 저자, 연도, 표본 수, 주요 결과 숫자를 뽑아 표(CSV)로 만들어 줘. 표에서 가져온 값은 쪽 번호를 함께 적어 줘.
솔직히 한계
  • 별 수와 마지막 커밋은 2026년 11월 5일 기준입니다. 스킬 이름과 설치 명령은 저장소 쪽에서 자주 바뀌니 설치 전에 README를 한 번 더 확인하세요.
  • 편집부는 각 스킬의 SKILL.md와 README를 읽고 골랐고 모든 스킬을 실제 업무 자료로 돌려 보지는 않았습니다.
  • 학술 데이터베이스를 검색하는 스킬도 검색 결과를 잘못 요약할 수 있습니다. 인용과 숫자는 원문에서 직접 확인하세요.
  • 학교·학술지마다 AI 사용 규정이 다릅니다. 학위 논문과 투고 원고는 소속 기관과 학술지의 규정을 먼저 확인하세요.
  • 일부 스킬은 외부 API 키나 파이썬 패키지 설치가 필요합니다. SKILL.md의 compatibility 항목을 확인하세요.
