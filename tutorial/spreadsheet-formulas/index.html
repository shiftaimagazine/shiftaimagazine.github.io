왜 필요한가요AI가 수식 질문에서 가장 많이 틀리는 까닭은 내 표가 어떻게 생겼는지 모르기 때문입니다. 열 위치와 예시 데이터를 함께 주면 고치지 않고 바로 쓸 수 있는 수식이 나옵니다.
'매출 합계 수식 알려줘'라고만 물으면 A1:A10 같은 예시 수식이 나오고 내 표에 맞게 고치다가 다시 막히기 쉽습니다. AI에게는 ① 어떤 프로그램인지(엑셀 버전, 구글 시트), ② 어느 열에 무엇이 있는지, ③ 첫 몇 줄의 예시 데이터, ④ 원하는 결과를 함께 알려 줘야 합니다. 예시 데이터는 실제 값 대신 비슷한 가짜 값으로 바꿔 넣어도 충분합니다. 받은 수식은 손으로 계산할 수 있는 몇 줄에서 먼저 맞는지 확인한 뒤 전체에 적용합니다.

프롬프트 1내 표를 설명하는 기본 틀

'내 표 설명'은 모든 수식 질문 앞에 붙입니다. 이것만 잘 써도 수식이 한 번에 맞습니다.

이렇게 쓰세요머리글 줄과 예시 3줄을 복사해 넣고 데이터가 몇 행까지인지, 빈칸이 있는지도 함께 적습니다. 프로그램과 버전을 적어 두면 내 환경에서 안 되는 함수를 피할 수 있습니다.
복사해서 쓰는 프롬프트
[엑셀 365 / 엑셀 2019 / 구글 시트]를 쓰고 있어. 시트 이름은 [시트 이름]이고 1행은 머리글, 데이터는 2행부터 [500]행까지야. 열 구성: A열 [ ], B열 [ ], C열 [ ], D열 [ ]. 예시 3줄: [예시 데이터]. 빈칸이 [있음/없음]. 원하는 결과: [결과]. 1) 바로 붙여 넣을 수식, 2) 수식을 넣을 셀, 3) 수식의 각 부분이 하는 일을 한 줄씩 설명해 줘. 내 버전에서 안 되는 함수는 쓰지 마.

프롬프트 2조건 맞는 것만 합계·개수

'서울 지역 10월 매출 합계'처럼 조건이 여러 개인 합계와 개수를 구합니다.

이렇게 쓰세요조건을 문장으로 하나씩 나열합니다. 날짜 조건은 '>='&DATE(2026,10,1)처럼 DATE 함수로 넣으면 엑셀과 구글 시트 모두에서 안정적으로 동작하고 날짜에 시간이 섞여 있을 수 있으면 끝 조건은 '다음 달 1일 미만'으로 잡습니다.
복사해서 쓰는 프롬프트
B열은 지역, C열은 날짜, D열은 매출이야(2~500행). 지역이 [서울]이고 날짜가 [2026년 10월]인 행의 매출 합계와 행 개수를 각각 구하는 수식을 줘. 지역 이름을 [G1] 셀에 적으면 그 지역으로 바뀌게 만들어 줘. SUMIFS와 COUNTIFS를 써 주고, 날짜가 텍스트로 들어가 있을 때 생기는 문제와 확인 방법도 알려줘.
넣는 것 (예시)
B열 지역, C열 날짜, D열 매출 / 10월 서울 매출 합계
나오는 것 (예시)
합계: =SUMIFS(D2:D500,B2:B500,"서울",C2:C500,">="&DATE(2026,10,1),C2:C500,"<"&DATE(2026,11,1))
개수: =COUNTIFS(B2:B500,"서울",C2:C500,">="&DATE(2026,10,1),C2:C500,"<"&DATE(2026,11,1))
G1 셀로 바꾸려면 "서울" 자리에 G1

프롬프트 3중복 찾기

같은 이메일·주문번호가 두 번 이상 들어간 행을 표시하거나 셉니다.

이렇게 쓰세요처음 나온 것은 두고 두 번째부터 표시할지, 중복된 모든 행을 표시할지 먼저 정합니다. 같은 조건을 조건부 서식에 넣으면 색으로 바로 보입니다. 같은 값이 앞뒤 공백 때문에 다르게 인식되는 경우도 많으니 함께 묻습니다.
복사해서 쓰는 프롬프트
A열에 [이메일 주소]가 2행부터 [1000]행까지 있어. 1) 중복된 값이 있는 모든 행에 '중복'이라고 표시하는 수식, 2) 처음 나온 행은 그대로 두고 두 번째부터만 '중복'이라고 표시하는 수식, 3) 같은 조건으로 중복 행에 색을 칠하는 조건부 서식 규칙을 알려줘. 앞뒤 공백이나 보이지 않는 문자 때문에 중복을 놓치는 경우를 막는 방법도 알려줘.
넣는 것 (예시)
A열 이메일 / 두 번째로 나온 것부터 표시
나오는 것 (예시)
B2에 입력 후 아래로 채우기:
=IF(COUNTIF($A$2:A2,A2)>1,"중복","")
중복된 모든 행 표시:
=IF(COUNTIF($A$2:$A$1000,A2)>1,"중복","")

프롬프트 4날짜 계산

근속 기간, 마감까지 남은 영업일, 3개월 뒤 날짜처럼 자주 쓰는 날짜를 계산합니다.

이렇게 쓰세요주말 말고 공휴일까지 빼려면 공휴일 날짜 목록을 별도 범위에 적어 두고 그 범위를 알려줍니다. 마이크로소프트 도움말에 따르면 DATEDIF는 시작일이 종료일보다 늦으면 #NUM! 오류를 내고 'MD' 단위는 부정확한 결과를 낼 수 있어 권장하지 않습니다.
복사해서 쓰는 프롬프트
B열은 입사일, C열은 마감일이야. 1) 오늘 기준 근속 기간을 '3년 2개월' 형태로 보여 주는 수식, 2) 오늘부터 마감일까지 주말과 공휴일을 뺀 영업일 수(공휴일 목록은 [H2:H20]), 3) 입사일로부터 정확히 3개월 뒤 날짜를 구하는 수식을 알려줘. 각 수식이 엑셀과 구글 시트에서 똑같이 동작하는지도 알려줘.
넣는 것 (예시)
B2 입사일 2023-08-14 / 오늘 2026-10-26 기준 근속 기간
나오는 것 (예시)
=DATEDIF(B2,TODAY(),"Y")&"년 "&DATEDIF(B2,TODAY(),"YM")&"개월" → 3년 2개월
영업일: =NETWORKDAYS(TODAY(),C2,$H$2:$H$20)
3개월 뒤: =EDATE(B2,3) (결과 셀 서식을 날짜로)

프롬프트 5다른 표에서 값 찾아오기

사번으로 이름을, 상품코드로 가격을 다른 시트에서 불러옵니다.

이렇게 쓰세요XLOOKUP은 엑셀 365·2021 이후 버전과 구글 시트에서 쓸 수 있습니다. 버전을 모르면 VLOOKUP 버전도 함께 달라고 합니다. 찾는 값이 없을 때 보여 줄 문구도 정해 두면 빈칸과 오류가 쉽게 구분됩니다.
복사해서 쓰는 프롬프트
[주문] 시트의 A열에 상품코드가 있고, [상품] 시트의 A열에 상품코드, C열에 가격이 있어. 주문 시트 B열에 가격을 불러오는 수식을 1) XLOOKUP 버전, 2) VLOOKUP 버전으로 줘. 상품코드가 없으면 '코드 확인'이라고 표시하게 해 줘. 상품코드가 숫자와 텍스트로 섞여 있어서 못 찾는 경우를 확인하는 방법도 알려줘.

프롬프트 6오류 메시지 해석

#N/A, #VALUE!, #REF!, #DIV/0!, #NAME? 같은 오류가 왜 났는지, 어떻게 고치는지 묻습니다.

이렇게 쓰세요수식만 보내면 AI는 원인을 추측만 합니다. 오류가 난 수식을 그대로 복사하고 참조하는 셀에 실제로 무엇이 들어 있는지 함께 적습니다.
복사해서 쓰는 프롬프트
[셀 주소]에 아래 수식을 넣었더니 [오류 표시, 예: #N/A]가 나와. 수식: [수식 붙여 넣기]. 참조하는 셀 값: [예: A2='P-001', 상품!A:A에는 'P-001 '처럼 끝에 공백이 있음]. 1) 이 오류가 뜻하는 것, 2) 내 경우 가능성 높은 원인을 순서대로, 3) 원인을 하나씩 확인하는 방법, 4) 고친 수식을 알려줘. 오류를 IFERROR로 가리기만 하는 방법은 마지막에 따로, 언제 써도 되는지와 함께 알려줘.

프롬프트 7남이 만든 긴 수식 풀어 읽기

전임자가 남긴 길고 복잡한 수식이 무엇을 계산하는지 한 단계씩 풀어 봅니다.

이렇게 쓰세요고치기 전에 먼저 이해하는 용도라서 수식과 함께 그 수식이 있는 표의 열 구성을 알려줍니다.
복사해서 쓰는 프롬프트
아래는 전임자가 만든 수식이야. 표의 열 구성은 [열 구성]이야. 1) 이 수식이 결국 무엇을 계산하는지 한 문장으로, 2) 안쪽 함수부터 바깥쪽으로 단계별로 풀어서, 3) 이 수식이 틀린 결과를 낼 수 있는 경우(빈칸, 범위 밖 데이터 등), 4) 같은 결과를 더 짧고 읽기 쉽게 쓰는 방법을 알려줘. 수식: [수식 붙여 넣기]

프롬프트 8피벗 테이블 설계

보고 싶은 표를 말하면 AI가 피벗 테이블의 행·열·값·필터 배치를 설계해 줍니다.

이렇게 쓰세요피벗을 만들기 전에 원본 데이터가 '한 행에 한 건' 형태인지부터 보고 병합된 셀이나 중간 합계 행이 있으면 먼저 정리합니다.
복사해서 쓰는 프롬프트
원본 데이터 열은 [날짜, 지역, 담당자, 상품, 수량, 매출]이고 한 행이 주문 한 건이야. 내가 보고 싶은 표는 '[예: 지역별·월별 매출 합계와 전월 대비 증감]'이야. 1) 피벗 테이블의 행, 열, 값, 필터에 각각 어떤 필드를 넣을지, 2) 날짜를 월 단위로 묶는 방법, 3) 값 표시 형식(합계/개수/비율) 설정, 4) [엑셀 / 구글 시트]에서 메뉴를 찾아가는 순서를 알려줘. 원본 데이터에서 피벗 전에 정리해야 할 문제도 짚어 줘.

프롬프트 9엑셀 ↔ 구글 시트로 옮길 때 깨지는 수식

엑셀 파일을 구글 시트로, 또는 반대로 옮겼을 때 동작하지 않는 함수를 찾아 바꿉니다.

이렇게 쓰세요두 프로그램은 대부분의 함수가 같지만 일부 함수와 여러 칸에 결과를 펼치는 수식은 동작이 다를 수도 있습니다. 깨진 수식은 모아서 한 번에 넣습니다.
복사해서 쓰는 프롬프트
[엑셀에서 구글 시트로 / 구글 시트에서 엑셀로] 파일을 옮겼더니 아래 수식들이 오류가 나거나 결과가 달라. 1) 수식마다 옮긴 프로그램에서 지원하지 않거나 다르게 동작하는 함수를 찾고, 2) 같은 결과를 내는 대체 수식을 주고, 3) 바꾼 뒤 결과가 같은지 확인하는 방법을 알려줘. 내 엑셀 버전은 [버전]이야. 수식 목록: [수식들]
보너스 · 수식 적용 전 체크리스트
  1. 손으로 계산할 수 있는 3~5줄에서 수식 결과를 먼저 맞춰 봤습니다
  2. 고정해야 하는 범위에 $를 붙였습니다(예: $A$2:$A$1000)
  3. 날짜·숫자가 텍스트로 들어간 셀이 없는지 확인했습니다
  4. 원본 파일을 복사해 두고 사본에서 작업했습니다
  5. 실제 고객·직원 데이터 대신 가짜 예시 값으로 질문했습니다
  6. IFERROR로 오류를 가리기 전에 원인을 확인했습니다
솔직히 한계
  • AI가 내 엑셀 버전에서 쓸 수 없는 함수를 내놓을 수 있으니 버전을 꼭 적고 결과를 직접 확인해야 합니다.
  • 날짜나 숫자가 텍스트로 들어간 셀, 앞뒤 공백 같은 데이터 문제는 원본을 직접 살펴봐야 합니다. 수식만 봐서는 드러나지 않습니다.
  • 한쪽에서 맞던 수식도 옮긴 뒤에는 다시 확인해야 합니다. 엑셀과 구글 시트는 일부 함수의 동작이 다릅니다.
