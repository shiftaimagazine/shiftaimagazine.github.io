걸리는 시간20분
왜 필요한가요AI에게 대본을 맡기면 누가 써도 비슷한 말투가 나옵니다. 내 글 샘플로 말투 문서를 먼저 만들고 형식별 스킬을 쓰면 '내가 쓴 것 같은' 초안이 나오고 영상·음성 작업도 같은 대화 안에서 이어 갈 수 있습니다.
charlie947/social-media-skills는 크리에이터 찰리 힐스가 공개한 스킬 17개 모음입니다. 말투 학습, 훅 만들기, 게시물 쓰기, 릴스 대본, 유튜브 썸네일 기획이 들어 있습니다. 영상을 코드로 만드는 리모션은 공식 스킬 13개를, 음성 AI 회사 일레븐랩스는 음성 합성·받아쓰기·더빙 스킬을 공개했습니다. 코리 헤인스 marketingskills의 video·social 스킬도 함께 쓸 만합니다. 리모션으로 쇼츠를 만드는 전체 과정은 '편집 프로그램 없이 코드로 만드는 15초 쇼츠' 튜토리얼에 있습니다.

STEP 1설치 전에 알아 둘 것5분

스킬은 SKILL.md 설명서와 보조 파일이 든 폴더이고 필요한 순간에만 AI가 꺼내 읽습니다.

클로드 코드에서는 저장소를 플러그인 마켓플레이스로 등록한 뒤 필요한 플러그인만 설치합니다. claude.ai에서는 프로 이상 요금제에서 설정 → Capabilities의 Skills 칸에 스킬 폴더를 ZIP으로 올립니다. 이때 코드 실행과 파일 만들기가 켜져 있어야 합니다. 앤트로픽 도움말은 믿을 수 있는 곳의 스킬만 설치하고 그렇지 않은 스킬은 안에 든 스크립트와 외부 접속 지시를 먼저 읽어 보라고 안내합니다. 크리에이터 스킬 일부는 이미지·영상 분석에 외부 서비스 API 키를 요구합니다. 키가 없으면 그 단계는 건너뛰고 내가 직접 넣은 자료로 진행합니다.

스킬 설명은 대부분 영어지만 한국어로 요청해도 상황에 맞는 스킬이 불려 나옵니다. 잘 안 불리면 '○○ 스킬을 써서'라고 이름을 적어 줍니다. 설치와 삭제 방법은 '클로드 코드에 스킬·MCP 붙이는 법, 설치부터 떼기까지 8단계'에 자세히 정리했습니다.

어디서 쓰나설치 방법조건
클로드 코드/plugin marketplace add 저장소 → /plugin install 플러그인@마켓플레이스클로드 프로 이상 또는 Console 계정
claude.ai(웹·앱)설정 → Capabilities → Skills에서 스킬 폴더 ZIP을 'Upload skill'프로·맥스·팀·엔터프라이즈, 코드 실행 켜기

STEP 2내 말투 학습 · voice-builder10분

짧은 인터뷰와 내 글 3~5편으로 '나에 대한 문서'와 '말투 문서'를 만듭니다.

결과로 about-me.md와 voice.md 두 파일이 프로젝트 폴더에 생기고 같은 저장소의 다른 스킬이 이 파일을 참고해 글을 씁니다. 클로드나 챗GPT 프로젝트 지침에 이 내용을 붙여 넣어 써도 됩니다. 저장소는 charlie947/social-media-skills이고 별 약 4,400, 라이선스 MIT, 마지막 커밋은 10월 18일입니다.
클로드 코드
/plugin marketplace add charlie947/social-media-skills
/plugin install social-media-skills@social-media-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
voice-builder 스킬로 내 말투 문서를 만들어 줘. 아래는 내가 쓴 영상 대본 3편과 커뮤니티 글 2편이야. 인터뷰 질문은 한 번에 하나씩 해 줘. 샘플: [붙여 넣기]

STEP 3첫 줄 훅 · hook-generator3분

주제 하나로 첫 두 줄 훅 6가지를 만듭니다.

원래 링크드인 게시물용으로 만들어져 글자 수 기준이 영어 40자입니다. 쇼츠·릴스 첫 문장으로 쓰려면 '한국어 20자 안팎, 말로 했을 때 자연스럽게'라고 조건을 바꿔 줍니다. 저장소는 charlie947/social-media-skills이고 별 약 4,400, 라이선스 MIT, 마지막 커밋은 10월 18일입니다.
복사해서 쓰는 프롬프트
hook-generator 스킬로 '[직장인 엑셀 단축키 5개]' 쇼츠의 첫 문장 6개를 만들어 줘. 한국어로, 말로 했을 때 3초 안에 끝나게, 숫자는 내가 준 것만 써 줘. 낚시성 과장은 빼 줘.

STEP 4릴스 대본 · reels-scripting3분

잘된 레퍼런스 릴스의 훅·구조를 분석해 내 주제로 새 대본을 씁니다.

릴스 주소로 영상을 자동 분석하는 단계는 Apify와 구글 AI API 키가 필요하다고 SKILL.md에 적혀 있습니다. 키가 없으면 레퍼런스 영상의 자막이나 구성을 직접 적어 넣으면 그 단계를 건너뜁니다. 남의 영상 장면을 그대로 쓰지 말고 구조만 참고합니다. 저장소는 charlie947/social-media-skills이고 별 약 4,400, 라이선스 MIT, 마지막 커밋은 10월 18일입니다.
복사해서 쓰는 프롬프트
reels-scripting 스킬로 대본을 써 줘. 레퍼런스 릴스 구성은 [1초 질문 → 3단계 팁 → 마지막 반전]이고, 내 주제는 [회의록 자동 정리]야. voice.md 말투로 25초 분량, 장면마다 화면에 띄울 글자도 적어 줘.

STEP 5썸네일 기획 · youtube-thumbnail3분

영상 제목과 내 사진, 브랜드 색으로 썸네일 이미지 생성 프롬프트를 만듭니다.

썸네일을 먼저 정하고 대본을 쓰는 순서를 권합니다. 실제 이미지는 제미나이 같은 이미지 생성 도구에서 만들고 글자는 디자인 도구에서 얹는 편이 깔끔합니다(이미지 생성 시안 튜토리얼 참고). 저장소는 charlie947/social-media-skills이고 별 약 4,400, 라이선스 MIT, 마지막 커밋은 10월 18일입니다.
복사해서 쓰는 프롬프트
youtube-thumbnail 스킬로 '[클로드 코드로 엑셀 100개 합치기]' 영상 썸네일 프롬프트 3안을 만들어 줘. 브랜드 색은 [노랑·검정], 내 얼굴 사진은 첨부했어. 안마다 큰 글자 문구(8자 이내)도 제안해 줘.

STEP 6코드로 영상 만들기 · remotion3분

리모션 공식 스킬로 새 영상 만들기, 자막, 미리 보기, 렌더링을 에이전트에게 맡깁니다.

remotion-best-practices가 다른 리모션 스킬을 안내하는 길잡이 역할을 하고 remotion-captions가 자막을, remotion-render가 MP4 내보내기를 맡습니다. 리모션은 개인과 3명 이하 회사는 무료이고 그보다 큰 회사는 라이선스가 필요하며 remotion-license 스킬로 조건을 확인할 수 있습니다. 저장소는 remotion-dev/skills이고 별 약 5,500, 라이선스 저장소에 라이선스 파일 없음, 마지막 커밋은 11월 2일입니다.
터미널
npx skills add remotion-dev/skills -a claude-code

확인문서 기준: 리모션 스킬이 클로드 코드용 폴더에 설치됩니다

복사해서 쓰는 프롬프트
리모션 스킬로 1080×1920, 15초 세로 영상을 새로 만들어 줘. 장면은 [제목 3초 → 팁 3개 각 3초 → 구독 안내 3초], 자막은 화면 가운데 큰 글씨로. 스튜디오에서 미리 보게 한 뒤 MP4로 렌더링해 줘.

STEP 7AI 음성⁠·더빙 · elevenlabs3분

대본을 음성으로 바꾸고 녹음을 받아쓰고 다른 언어로 더빙합니다.

일레븐랩스 API 키가 필요하고 사용량에 따라 요금이 듭니다(무료 체험 한도는 일레븐랩스 요금 페이지 기준). 실제 사람 목소리를 복제할 때는 본인 동의가 있어야 하고 AI 음성을 쓴 영상은 플랫폼의 AI 표시 규칙을 따릅니다. 저장소는 elevenlabs/skills이고 별 약 500, 라이선스 MIT, 마지막 커밋은 11월 4일입니다.
터미널
npx skills add elevenlabs/skills -a claude-code

확인문서 기준: 일레븐랩스 스킬이 설치되고, 처음 쓸 때 API 키 설정을 안내합니다

복사해서 쓰는 프롬프트
text-to-speech 스킬로 이 대본을 한국어 여성 목소리로 읽어 MP3로 저장해 줘. 속도는 조금 빠르게, 문장 사이 쉼은 짧게. 키가 없으면 설정 방법부터 알려줘. 대본: [붙여 넣기]

STEP 8영상⁠·소셜 전략 · video⁠·social3분

영상 제작 계획과 플랫폼별 게시물 일정, 반응 분석을 돕습니다.

video 스킬은 AI 영상 도구와 코드 기반 영상 제작을 함께 다루고 social 스킬은 플랫폼별 게시물 작성과 예약, 소셜 리스닝을 다룹니다. 채널 전체 전략을 세울 때 씁니다. 저장소는 coreyhaines31/marketingskills이고 별 약 4만 5천, 라이선스 MIT, 마지막 커밋은 10월 30일입니다.

복사해서 쓰는 프롬프트
social 스킬로 다음 2주 동안 유튜브 쇼츠·인스타 릴스·쓰레드에 올릴 일정을 짜 줘. 주제는 [AI 업무 팁], 주 3회, 플랫폼마다 같은 내용을 어떻게 다르게 바꿀지 표로 보여 줘.

  • API 키가 필요한 스킬은 키를 대화창에 붙여 넣지 말고 스킬이 안내하는 설정 방법(환경 변수 등)으로 넣으세요.
