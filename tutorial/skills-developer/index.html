걸리는 시간20분
왜 필요한가요코딩 에이전트의 흔한 실패는 요구 사항을 다 듣기 전에 코드를 쓰고 테스트 없이 '고쳤다'고 말하는 것입니다. 작업 순서를 강제하는 스킬을 깔아 두면 같은 모델로도 결과물이 눈에 띄게 안정됩니다.
obra/superpowers는 브레인스토밍, 계획 쓰기, 테스트 주도 개발, 체계적 디버깅, 완료 전 검증 같은 스킬 15개를 묶은 개발 방법론입니다. 앤트로픽 공식 마켓플레이스에서 바로 설치할 수 있습니다. 앤트로픽 skills 저장소에는 웹앱 테스트(webapp-testing)와 MCP 서버 만들기(mcp-builder), 스킬 만들기(skill-creator)가 있고 버셀은 React·Next.js 성능 규칙을, 보안 회사 트레일 오브 비츠는 코드 보안 점검 스킬을 공개했습니다.

STEP 1설치 전에 알아 둘 것5분

스킬은 SKILL.md 설명서와 보조 파일이 든 폴더이고 필요한 순간에만 AI가 꺼내 읽습니다.

클로드 코드에서는 저장소를 플러그인 마켓플레이스로 등록한 뒤 필요한 플러그인만 설치합니다. claude.ai에서는 프로 이상 요금제에서 설정 → Capabilities의 Skills 칸에 스킬 폴더를 ZIP으로 올립니다. 이때 코드 실행과 파일 만들기가 켜져 있어야 합니다. 앤트로픽 도움말은 믿을 수 있는 곳의 스킬만 설치하고 그렇지 않은 스킬은 안에 든 스크립트와 외부 접속 지시를 먼저 읽어 보라고 안내합니다. 개발용 스킬은 명령을 실행하는 경우가 많으니 처음에는 허락을 묻는 권한 모드로 둡니다.

스킬 설명은 대부분 영어지만 한국어로 요청해도 상황에 맞는 스킬이 불려 나옵니다. 잘 안 불리면 '○○ 스킬을 써서'라고 이름을 적어 줍니다. 설치와 삭제 방법은 '클로드 코드에 스킬·MCP 붙이는 법, 설치부터 떼기까지 8단계'에 자세히 정리했습니다.

어디서 쓰나설치 방법조건
클로드 코드/plugin marketplace add 저장소 → /plugin install 플러그인@마켓플레이스클로드 프로 이상 또는 Console 계정
claude.ai(웹·앱)설정 → Capabilities → Skills에서 스킬 폴더 ZIP을 'Upload skill'프로·맥스·팀·엔터프라이즈, 코드 실행 켜기
코덱스·커서 등 다른 에이전트npx skills add 저장소 (-a 로 대상 에이전트 지정)Node.js 22.20 이상

STEP 2개발 방법론 묶음 · superpowers3분

요구 사항 정리 → 계획 → 테스트 먼저 → 구현 → 검증 순서를 에이전트에게 지키게 합니다.

brainstorming 스킬이 코드 전에 질문으로 요구 사항을 좁히고 writing-plans가 단계별 계획을, test-driven-development가 실패하는 테스트부터 쓰게 합니다. 하위 에이전트로 일을 나누는 subagent-driven-development도 들어 있습니다. 저장소는 obra/superpowers이고 별 약 30만, 라이선스 MIT, 마지막 커밋은 11월 3일입니다.
클로드 코드
/plugin install superpowers@claude-plugins-official

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
[결제 내역 CSV 내보내기] 기능을 추가하고 싶어. 코드를 쓰기 전에 brainstorming으로 요구 사항을 질문해서 정리하고, writing-plans로 단계별 계획을 보여 줘. 내가 승인하면 테스트부터 써.

STEP 3버그 찾기 · systematic-debugging3분

추측으로 고치지 않고 재현 → 원인 좁히기 → 수정 → 확인 순서로 버그를 다룹니다.

같은 저장소의 verification-before-completion은 '고쳤습니다'라고 말하기 전에 테스트를 실제로 돌려 결과를 보이게 합니다. 둘을 함께 쓰면 고쳤다고 했는데 그대로인 일이 줄어듭니다. 저장소는 obra/superpowers이고 별 약 30만, 라이선스 MIT, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
systematic-debugging 스킬로 [로그인 후 가끔 빈 화면이 뜨는] 문제를 찾아 줘. 먼저 재현 방법을 만들고, 원인 후보를 좁혀 가는 과정을 보여 준 뒤 고쳐. 끝나면 verification-before-completion으로 확인 결과를 보여 줘.

STEP 4웹앱 테스트 · webapp-testing3분

플레이라이트로 로컬 웹앱을 열어 동작을 확인하고 화면을 찍습니다.

앤트로픽 공식 예시 스킬입니다. 화면이 실제로 그려지는지, 버튼이 동작하는지, 콘솔 오류가 있는지를 에이전트가 직접 확인하게 할 때 씁니다. 저장소는 anthropics/skills이고 별 약 18만, 라이선스 대부분 Apache 2.0(docx·pdf·pptx·xlsx는 소스 공개), 마지막 커밋은 10월 28일입니다.
클로드 코드
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
webapp-testing 스킬로 localhost:3000의 회원가입 흐름을 확인해 줘. 빈칸 제출, 잘못된 이메일, 정상 가입 세 경우를 돌리고 화면 캡처와 콘솔 오류를 정리해 줘.

STEP 5MCP 서버 만들기 · mcp-builder3분

AI가 외부 서비스를 쓰도록 연결하는 MCP 서버를 설계하고 만듭니다.

도구 이름과 설명을 어떻게 지어야 AI가 잘 고르는지 같은 설계 지침이 담겨 있습니다. 스킬 자체를 새로 만들 때는 같은 저장소의 skill-creator를 씁니다. 저장소는 anthropics/skills이고 별 약 18만, 라이선스 대부분 Apache 2.0(docx·pdf·pptx·xlsx는 소스 공개), 마지막 커밋은 10월 28일입니다.
복사해서 쓰는 프롬프트
mcp-builder 스킬로 우리 사내 [재고 조회 API]를 쓰는 MCP 서버를 설계해 줘. 먼저 도구 목록과 각 도구의 입력·출력을 제안하고, 내가 확인하면 타입스크립트로 만들어.

STEP 6React⁠·Next.js 규칙 · react-best-practices3분

버셀 엔지니어링이 정리한 React·Next.js 성능 규칙으로 코드를 쓰고 검토합니다.

같은 저장소에 UI 코드가 웹 인터페이스 지침을 지키는지 보는 web-design-guidelines와 버셀 배포 스킬도 있습니다. 이 저장소는 플러그인 마켓플레이스 대신 skills 명령으로 설치합니다. 저장소는 vercel-labs/agent-skills이고 별 약 3만 3천, 라이선스 MIT(README 표기), 마지막 커밋은 10월 27일입니다.
터미널
npx skills add vercel-labs/agent-skills --skill react-best-practices -a claude-code

확인문서 기준: 고른 스킬이 클로드 코드용 폴더에 설치됩니다(Node.js 22.20 이상)

복사해서 쓰는 프롬프트
react-best-practices 스킬로 app/ 폴더의 페이지 컴포넌트를 검토해 줘. 불필요한 다시 그리기, 클라이언트로 넘어가는 큰 번들, 데이터 요청 순서 문제를 찾아 우선순위와 함께 알려줘.

STEP 7보안 점검 · trailofbits/skills3분

보안 회사 트레일 오브 비츠가 공개한 정적 분석, 변경분 보안 리뷰, 의존성 위험 점검 스킬입니다.

플러그인이 46개라 필요한 것만 고릅니다. 일반 웹 서비스라면 differential-review(변경분 보안 리뷰), insecure-defaults(위험한 기본 설정 찾기), supply-chain-risk-auditor(npm·PyPI 의존성 점검)부터 보면 됩니다. 라이선스는 CC BY-SA 4.0입니다. 저장소는 trailofbits/skills이고 별 약 7,900, 라이선스 CC BY-SA 4.0, 마지막 커밋은 11월 4일입니다.
클로드 코드
/plugin marketplace add trailofbits/skills
/plugin install differential-review@trailofbits

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
differential-review 스킬로 이번 브랜치에서 main 대비 바뀐 코드를 보안 관점에서 검토해 줘. 인증·권한·입력 검증·비밀 값 노출 문제를 심각도별로 정리해 줘.

STEP 8코드 리뷰 · code-review3분

PR이나 변경분을 보안·성능·정확성 기준으로 검토합니다.

앤트로픽 직무별 플러그인 가운데 engineering에 들어 있습니다. 같은 플러그인에 장애 대응(incident-response), 배포 전 점검(deploy-checklist), 기술 부채 정리(tech-debt) 스킬이 있습니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
클로드 코드
/plugin marketplace add anthropics/knowledge-work-plugins
/plugin install engineering@knowledge-work-plugins

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
code-review 스킬로 이 PR을 검토해 줘. 머지 전에 꼭 고칠 것과 나중에 해도 되는 것을 나누고, 지적마다 파일과 줄 번호를 붙여 줘.
솔직히 한계
  • 별 수와 마지막 커밋은 2026년 11월 5일 기준입니다. 스킬 이름과 설치 명령은 저장소 쪽에서 자주 바뀌니 설치 전에 README를 한 번 더 확인하세요.
  • 편집부는 각 스킬의 SKILL.md와 README를 읽고 골랐고 모든 스킬을 실제 업무 자료로 돌려 보지는 않았습니다.
  • superpowers처럼 작업 순서를 강하게 정하는 스킬은 작은 수정에도 계획 단계를 거쳐 시간이 더 걸릴 수 있습니다. 간단한 일은 '계획 없이 바로 고쳐'라고 적어 줍니다.
  • 보안 스킬의 결과는 출발점일 뿐 전문 보안 감사를 대신하지 않습니다.
