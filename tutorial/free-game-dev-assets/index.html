게임 만들 때 쓰는 무료 자료 459개, 상업용만 골라 쓰는 4단계

3D 모델⁠·효과음⁠·폰트⁠·셰이더까지 게임 제작용 무료 자료 459곳을 모은 Free Game Dev Assets에서 상업용으로 쓸 수 있는 자료만 골라내는 방법입니다. 마지막 단계에서는 고른 자료를 클로드에 넘겨 라이선스 표와 크레딧 문구를 만듭니다.

  3. 받기 전에 'Open source' 링크로 원래 사이트에 들어가 라이선스를 한 번 더 확인합니다.

통째로 맡기는 프롬프트Claude에 붙여 넣으면 이 글의 단계를 대신 진행합니다
역할: 너는 인디 게임 팀에서 무료 자료의 라이선스를 정리하는 담당자야. 맥락: Free Game Dev Assets(https://tmhsdigital.github.io/Free-Game-Dev-Assets/)⁠에서 게임에 쓸 무료 자료를 골랐어. 이 목록의 라이선스 표시는 사이트가 원본을 읽고 정리한 것이라 원래 사이트에서 다시 확인해야 해. 입력: [자료 이름 · 원래 사이트 주소를 한 줄에 하나씩] 작업: 1) 자료마다 원래 사이트를 열어 라이선스 이름, 상업적 사용 가능 여부, 출처 표기 필요 여부, 요구하는 표기 문구를 확인해. 2) 표로 정리해. 칸은 자료 이름 · 라이선스 · 상업용 가능 · 출처 표기 필요 · 표기 문구 · 확인한 주소. 3) 출처 표기가 필요한 자료만 모아 게임 크레딧 화면에 넣을 문구를 만들어. 제약: 원래 사이트에서 확인하지 못한 칸은 '확인 못 함'으로 두고 추측하지 마. 법률 판단은 하지 마. 출력: 표 하나와 크레딧 문구. 검증: 표의 라이선스 이름이 원래 사이트 문구와 같은지 한 번 더 대조하고, 다르면 고친 뒤 보여 줘.
필요한 것크롬 같은 브라우저, 클로드 계정(마지막 단계만, 웹 검색 기능이 켜져 있어야 합니다)
걸리는 시간15분
왜 필요한가요무료 자료를 받을 때 가장 자주 막히는 곳은 라이선스입니다. 이 목록은 자료마다 라이선스와 확인한 날짜를 붙여 두어서 상업용 가능 여부와 출처 표기 필요 여부로 바로 거를 수 있습니다.
Free Game Dev Assets는 TMHSDigital이 GitHub에 공개한 무료 게임 자료 목록입니다. 2026년 11월 23일에 만든 목록 기준으로 459곳이 올라와 있고, 그중 399곳에 'active', 45곳에 'needs review', 15곳에 'per item' 표시가 붙어 있습니다. 설치나 가입 없이 웹페이지에서 바로 찾을 수 있습니다. SHIFT 릴스 '게임 무료 자료 459개' 편에서 보여 드린 사이트가 이곳입니다.

STEP 1사이트 열고 분류 고르기2분

필요한 자료가 어느 칸에 있는지부터 봅니다.

주소창에 tmhsdigital.github.io/Free-Game-Dev-Assets 를 넣으면 목록이 바로 열립니다. 위쪽 분류 버튼 옆의 숫자가 그 칸에 든 자료 수입니다. 키보드에서 '/'를 누르면 검색칸으로 바로 갑니다.

숫자는 2026년 11월 23일에 만든 목록 기준입니다. 최근 30일 사이에 44곳이 새로 들어왔다고 사이트에 적혀 있습니다.

STEP 2상업용⁠⁠·출처 표기 없음으로 거르기3분

목록이 길어서 위쪽 상태 버튼 두 개로 먼저 줄입니다.

'Commercial OK'를 켜면 상업적으로 쓸 수 있다고 표시된 자료만 남고, 'No attribution'까지 켜면 출처를 적지 않아도 된다고 표시된 자료만 남습니다. 쓰는 게임 엔진이나 파일 형식이 정해져 있다면 'Engine'과 'Format'에서 같이 고릅니다.

정렬을 'Licence, least owed first'로 바꾸면 지켜야 할 조건이 가벼운 자료부터 위로 올라옵니다.

자료 줄마다 'commercial OK · CC0'처럼 상업용 여부와 라이선스 이름이 붙어 있어서 목록에서 바로 비교할 수 있습니다.

용어 · CC0저작자가 권리를 최대한 포기해 누구나 조건 없이 쓸 수 있게 한 공개 선언입니다.
용어 · 출처 표기(attribution)자료를 쓸 때 만든 사람 이름이나 출처를 적어야 하는 조건입니다.

STEP 3원래 사이트에서 라이선스 다시 보기5분

목록에 적힌 라이선스는 이 사이트가 원본을 읽고 정리한 내용입니다.

자료마다 'verified 2026-10-23 (31d ago)'처럼 마지막으로 확인한 날짜가 붙어 있습니다. 'Open source'를 누르면 자료를 올린 원래 사이트로, 'Entry and evidence'를 누르면 목록이 라이선스를 판단한 근거로 갑니다. 사이트도 이 표시는 법률 조언이 아니니 게임을 내기 전에 원래 사이트를 다시 확인하라고 적어 두었습니다.

'needs review'나 'per item' 표시가 붙은 곳은 원래 사이트에서 자료별 조건을 따로 확인합니다.

이렇게 말고목록에 commercial OK라고 적혀 있으니 바로 받아서 출시한다
이렇게원래 사이트의 라이선스 문구를 확인하고 주소와 확인한 날짜를 메모해 둔다

STEP 4고른 자료로 클로드에 라이선스 표 만들게 하기5분

자료가 여러 개면 출처 표기 문구를 손으로 모으는 데 시간이 꽤 듭니다.

클로드(claude.ai) 새 대화에서 웹 검색이 켜져 있는지 확인하고 아래 프롬프트를 붙여 넣습니다. 대괄호 안에는 고른 자료 이름과 원래 사이트 주소를 한 줄에 하나씩 넣습니다. 클로드가 원래 사이트를 열어 라이선스를 확인한 뒤 표와 크레딧 문구를 돌려줍니다.

클로드가 열지 못한 사이트는 표에 '확인 못 함'으로 남습니다. 그 자료는 직접 원래 사이트에서 확인합니다.

복사해서 쓰는 프롬프트
아래 무료 게임 자료들의 라이선스를 원래 사이트에서 확인해서 표로 정리해 줘. 자료 목록(이름 · 원래 사이트 주소): [자료 1 · 주소] [자료 2 · 주소] 표 칸: 자료 이름 · 라이선스 · 상업용 가능 · 출처 표기 필요 · 표기 문구 · 확인한 주소 - 원래 사이트에서 확인하지 못한 칸은 '확인 못 함'으로 두고 추측하지 마 - 표 아래에 출처 표기가 필요한 자료만 모아 게임 크레딧 화면에 넣을 문구를 만들어 줘
할 수 없는 것
  • 목록의 라이선스는 사이트가 원본을 읽고 정리한 내용이고 법률 조언이 아닙니다. 게임을 내기 전에는 원래 사이트 조건을 다시 확인합니다.
  • 자료 수와 분류별 숫자는 2026년 11월 23일 목록 기준이라 바뀔 수 있습니다.
  • 목록의 미리보기 그림은 각 제작자의 것이라 영상이나 홍보물에 그대로 쓰지 않습니다.
  • 클로드의 웹 검색이 꺼져 있거나 사이트가 막혀 있으면 표에 '확인 못 함'이 남습니다.
