걸리는 시간20분
왜 필요한가요같은 프롬프트를 매번 다시 쓰는 대신 검증된 작업 순서와 체크리스트가 담긴 스킬을 깔아 두면 AI가 마케팅 실무 틀에 맞춰 답합니다. 스킬마다 '이럴 때 써라'가 정해져 있어 요청만 하면 알아서 불려 나옵니다.
이 글은 두 저장소를 기준으로 합니다. 앤트로픽의 knowledge-work-plugins 저장소에 든 marketing 플러그인은 콘텐츠 초안, 캠페인 기획, 브랜드 검수, 경쟁사 브리프, 이메일 시퀀스, 성과 보고·SEO 점검까지 스킬 8개로 구성돼 있습니다. 코리 헤인스의 marketingskills는 카피라이팅, 전환율 개선, SEO, 분석, 그로스 엔지니어링을 다루는 스킬 53개를 담았습니다. 시작할 때 product-marketing 스킬로 우리 제품 설명 문서를 한 번 만들어 두면 다른 스킬이 그 문서를 참고합니다.

STEP 1설치 전에 알아 둘 것5분

스킬은 SKILL.md 설명서와 보조 파일이 든 폴더이고 필요한 순간에만 AI가 꺼내 읽습니다.

클로드 코드에서는 저장소를 플러그인 마켓플레이스로 등록한 뒤 필요한 플러그인만 설치합니다. claude.ai에서는 프로 이상 요금제에서 설정 → Capabilities의 Skills 칸에 스킬 폴더를 ZIP으로 올립니다. 이때 코드 실행과 파일 만들기가 켜져 있어야 합니다. 앤트로픽 도움말은 믿을 수 있는 곳의 스킬만 설치하고 그렇지 않은 스킬은 안에 든 스크립트와 외부 접속 지시를 먼저 읽어 보라고 안내합니다.

스킬 설명은 대부분 영어지만 한국어로 요청해도 상황에 맞는 스킬이 불려 나옵니다. 잘 안 불리면 '○○ 스킬을 써서'라고 이름을 적어 줍니다. 설치와 삭제 방법은 '클로드 코드에 스킬·MCP 붙이는 법, 설치부터 떼기까지 8단계'에 자세히 정리했습니다.

어디서 쓰나설치 방법조건
클로드 코드/plugin marketplace add 저장소 → /plugin install 플러그인@마켓플레이스클로드 프로 이상 또는 Console 계정
claude.ai(웹·앱)설정 → Capabilities → Skills에서 스킬 폴더 ZIP을 'Upload skill'프로·맥스·팀·엔터프라이즈, 코드 실행 켜기
코덱스·커서 등 다른 에이전트npx skills add 저장소 (-a 로 대상 에이전트 지정)Node.js 22.20 이상

STEP 2우리 제품 맥락 문서 · product-marketing5분

다른 스킬이 함께 참고할 제품·고객·경쟁사 설명 문서를 먼저 만듭니다.

제품 소개, 주요 고객, 가격, 경쟁사, 쓰지 말아야 할 표현을 물어 가며 정리합니다. 한 번 만들어 두면 카피나 광고 스킬이 매번 처음부터 묻지 않습니다. 저장소는 coreyhaines31/marketingskills이고 별 약 4만 5천, 라이선스 MIT, 마지막 커밋은 10월 30일입니다.
클로드 코드
/plugin marketplace add coreyhaines31/marketingskills
/plugin install marketing-skills@marketingskills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
product-marketing 스킬로 우리 제품의 마케팅 맥락 문서를 만들어 줘. 제품: [한 줄 소개], 주요 고객: [누구], 가격: [요금제], 경쟁사: [2~3곳], 피하고 싶은 표현: [과장·단정 등]. 모르는 칸은 나에게 질문해 줘.

STEP 3랜딩 페이지 카피 · copywriting3분

홈페이지·랜딩·가격 페이지 문구를 새로 쓰거나 고칩니다.

헤드라인, 소제목, 혜택, 행동 유도 문구를 페이지 구조에 맞춰 제안합니다. 이미 쓴 문구를 다듬을 때는 같은 저장소의 copy-editing 스킬이 맞습니다. 저장소는 coreyhaines31/marketingskills이고 별 약 4만 5천, 라이선스 MIT, 마지막 커밋은 10월 30일입니다.
복사해서 쓰는 프롬프트
copywriting 스킬로 [신규 기능 소개] 랜딩 페이지 문구 초안을 써 줘. 읽는 사람은 [30대 직장인], 행동 목표는 [무료 체험 신청]이야. 헤드라인 3안과 각 안을 고른 이유를 함께 알려줘.

STEP 4SEO 점검 · seo-audit3분

키워드, 페이지 내 요소, 콘텐츠 빈틈, 기술 점검을 한 번에 봅니다.

앤트로픽 marketing 플러그인의 seo-audit은 키워드 조사, 페이지 분석, 경쟁사 비교를 묶어 빨리 고칠 것과 길게 볼 일을 나눠 줍니다. 생성형 검색(AI 답변)에 인용되는 쪽을 보고 싶다면 marketingskills의 ai-seo 스킬을 함께 씁니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
클로드 코드
/plugin marketplace add anthropics/knowledge-work-plugins
/plugin install marketing@knowledge-work-plugins

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
seo-audit 스킬로 [우리 사이트 주소]를 점검해 줘. 우리가 노리는 검색어는 [검색어 3개]야. 바로 고칠 수 있는 것 5개와 한 달 안에 할 일 3개로 나눠 줘.

STEP 5광고 소재 · ad-creative3분

검색·소셜 광고의 제목, 설명, 본문 변형을 여러 개 만듭니다.

플랫폼마다 글자 수 제한이 달라서 매체를 정해 주면 그 틀에 맞춰 냅니다. 광고 운영 전략까지 필요하면 ads 스킬이 따로 있습니다. 저장소는 coreyhaines31/marketingskills이고 별 약 4만 5천, 라이선스 MIT, 마지막 커밋은 10월 30일입니다.
복사해서 쓰는 프롬프트
ad-creative 스킬로 [메타 광고]용 본문 5안과 제목 5안을 만들어 줘. 상품은 [제품], 혜택은 [핵심 혜택], 금지 표현은 [최고·1위 같은 단정]이야. 안마다 노리는 고객 심리를 한 줄로 붙여 줘.

STEP 6이메일 시퀀스 · email-sequence3분

가입 환영, 체험 종료 안내, 재방문 유도처럼 여러 통짜리 메일 흐름을 설계합니다.

메일마다 보내는 시점, 조건, 그만 보낼 조건(예: 결제하면 중단)까지 함께 짜 줍니다. 짧은 단발 메일 초안은 draft-content 스킬이 맞습니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
email-sequence 스킬로 무료 체험 14일 동안 보낼 메일 4통을 설계해 줘. 목표는 [유료 전환], 중단 조건은 [결제 완료]야. 메일마다 보내는 날, 제목 2안, 본문 초안을 적어 줘.

STEP 7캠페인 기획 · campaign-plan3분

목표, 대상, 메시지, 채널, 일정, 성과 지표가 담긴 캠페인 브리프를 만듭니다.

주 단위 콘텐츠 일정까지 나오기 때문에 팀에 공유할 기획서 초안으로 바로 씁니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
campaign-plan 스킬로 [12월 연말 프로모션] 캠페인 브리프를 만들어 줘. 예산은 [범위], 채널은 [인스타그램·네이버 블로그·메일], 목표는 [신규 가입 500명]이야. 주차별 일정과 측정 지표를 표로 넣어 줘.

STEP 8브랜드 톤 검수 · brand-review3분

발행 전에 글이 우리 브랜드 말투와 금지 표현 규칙을 지켰는지 봅니다.

벗어난 곳을 심각도별로 표시하고 고친 문장을 함께 제시합니다. 근거 없는 주장이나 빠진 고지 문구 같은 법적 위험도 짚도록 설계돼 있습니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
brand-review 스킬로 아래 글을 검수해 줘. 우리 브랜드 규칙은 [존댓말, 과장 금지, 경쟁사 비방 금지]야. 심각도별로 고칠 곳과 고친 문장을 보여 줘. 글: [붙여 넣기]
솔직히 한계
  • 별 수와 마지막 커밋은 2026년 11월 5일 기준입니다. 스킬 이름과 설치 명령은 저장소 쪽에서 자주 바뀌니 설치 전에 README를 한 번 더 확인하세요.
  • 편집부는 각 스킬의 SKILL.md와 README를 읽고 골랐고 모든 스킬을 실제 업무 자료로 돌려 보지는 않았습니다.
  • marketingskills는 해외 SaaS 마케팅 기준으로 쓰여 있어 국내 채널(네이버·카카오) 사정은 요청에 직접 적어 줘야 합니다.
  • SEO·광고 스킬 일부는 분석 도구 연결(MCP)이 있을 때 더 많은 일을 합니다. 연결 없이 쓰면 내가 붙여 넣은 자료만 봅니다.
