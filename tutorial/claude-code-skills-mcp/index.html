STEP 1스킬과 MCP 서버 구분하기3분

이 단계에서는 스킬과 MCP 서버가 각각 무엇이고 언제 어느 쪽을 쓰는지 먼저 정리합니다.

스킬은 Claude에게 어떤 일을 어떤 순서로 하라고 알려 주는 파일 묶음입니다. 평소에는 스킬의 이름과 설명만 맥락에 올라가고 본문은 실제로 쓸 때 읽히기 때문에, 긴 참고 자료를 넣어 둬도 부담이 적습니다. MCP 서버는 Claude Code와 따로 실행되는 프로그램으로, 브라우저 조작이나 외부 서비스 조회 같은 도구를 Claude에게 건네줍니다. 마이크로소프트는 Playwright MCP README에서 코딩 에이전트라면 토큰을 덜 쓰는 CLI+스킬 방식이 나을 수 있고, 브라우저 상태를 오래 이어 가야 하는 작업에는 MCP가 여전히 맞는다고 설명합니다.
용어 · MCP(Model Context Protocol)AI 앱을 파일, 데이터베이스, 검색 엔진 같은 외부 시스템에 연결하는 오픈소스 표준입니다. 공식 사이트는 AI 앱용 USB-C 단자에 비유합니다.

STEP 2스킬 폴더 위치와 SKILL.md 구조 보기3분

이 단계에서는 스킬을 어디에 두면 어디서 쓰이는지, 폴더 안에 무엇을 넣는지 확인합니다.

스킬 하나는 폴더 하나이고, 그 안에 SKILL.md가 꼭 있어야 합니다. 개인 폴더에 두면 이 컴퓨터의 모든 프로젝트에서 쓰이고, 프로젝트 폴더에 두면 그 저장소에서만 쓰이며 저장소에 커밋하면 팀원도 같은 스킬을 받습니다. SKILL.md 맨 위의 --- 두 줄 사이에는 name과 description을 적고, 그 아래에 Claude가 따를 지침을 씁니다. 폴더 이름(name을 적었다면 name)이 / 뒤에 치는 명령 이름이 되고, description은 Claude가 이 스킬을 언제 꺼낼지 판단하는 근거가 됩니다.
용어 · 프런트매터(frontmatter)SKILL.md 첫 줄의 --- 와 다음 --- 사이에 적는 설정 칸입니다. 첫 줄이 --- 가 아니면 Claude Code는 이 칸을 설정으로 읽지 않습니다.
위치경로쓰이는 곳
개인~/.claude/skills/<스킬이름>/SKILL.md이 컴퓨터의 모든 프로젝트
프로젝트.claude/skills/<스킬이름>/SKILL.md이 저장소의 세션(커밋하면 팀과 공유)
플러그인<플러그인>/skills/<스킬이름>/SKILL.md플러그인을 켠 곳, /플러그인이름:스킬이름 으로 호출

STEP 3공식 스킬 저장소를 플러그인으로 설치하기3분

이 단계에서는 앤트로픽의 anthropics/skills 저장소를 Claude Code에 마켓플레이스로 등록하고 스킬 묶음을 설치합니다.

터미널에서 claude를 실행해 Claude Code를 연 뒤, 입력창에 아래 두 명령을 차례로 넣습니다. README가 안내하는 묶음은 엑셀·워드·파워포인트·PDF를 다루는 document-skills와, 디자인·웹앱 테스트·스킬 만들기 같은 예시를 묶은 example-skills 두 가지입니다(마켓플레이스 목록에는 claude-api 등 플러그인 3개가 더 있습니다). 설치 명령을 넣으면 플러그인 상세 화면이 열리고, 나만 모든 프로젝트에서 쓸지(User), 이 저장소 협업자가 다 같이 쓸지(Project), 이 저장소에서 나만 쓸지(Local) 고릅니다. 설치한 뒤에는 스킬 이름을 넣어 부탁하면 됩니다. PDF 스킬은 document-skills에 들어 있으므로, document-skills@anthropic-agent-skills를 설치했다면 'PDF 스킬로 이 파일의 양식 칸을 뽑아 줘'처럼 부탁합니다.

문서 처리 스킬이 필요하면 example-skills 대신 document-skills@anthropic-agent-skills를 넣습니다. /plugin만 입력해 Discover 탭에서 골라 설치해도 됩니다. README는 이 스킬들이 시연과 교육을 위한 것이라며, 중요한 일에 쓰기 전에 내 환경에서 충분히 시험해 보라고 안내합니다.

Claude Code 입력창
/plugin marketplace add anthropics/skills

확인마켓플레이스 목록을 내려받아 등록합니다. 이 단계에서는 아직 아무 플러그인도 설치되지 않습니다.

Claude Code 입력창
/plugin install example-skills@anthropic-agent-skills

확인설치 범위를 고르고 나면 'Plugin is now active.' 또는 'Run /reload-plugins to activate.'가 나옵니다.

STEP 4스킬 하나만 폴더째 넣기(선택)4분

이 단계에서는 묶음 전체 대신 마음에 드는 스킬 하나만 개인 스킬 폴더에 복사합니다.

저장소를 내려받은 뒤 skills 폴더 아래에서 원하는 스킬 폴더를 통째로 ~/.claude/skills/ 로 복사합니다. 아래는 frontend-design 스킬을 예로 든 맥·리눅스 터미널 명령입니다. Claude Code는 스킬 폴더의 변화를 지켜보다가 실행 중인 세션에도 바로 반영하는데, 세션을 연 뒤에 ~/.claude/skills 폴더를 처음 만들었다면 /reload-skills를 입력합니다. 이 폴더는 세션을 다시 시작하기 전까지 자동으로 지켜보지 않으므로, 그 뒤에 스킬을 더 넣거나 고칠 때마다 /reload-skills를 다시 입력합니다. 복사가 끝나면 /frontend-design을 입력하거나 Claude에게 'What skills are available?'라고 물어 목록에 있는지 확인합니다.

이 저장소의 예시 스킬은 상당수가 아파치 2.0(Apache 2.0) 라이선스입니다. docx·pdf·pptx·xlsx 문서 스킬은 소스만 공개한 것이라 조건이 다르니, 폴더 안 LICENSE.txt를 읽고 씁니다.

터미널(맥·리눅스)

cp -r skills/skills/frontend-design ~/.claude/skills/
ls ~/.claude/skills/frontend-design

확인마지막 줄 결과로 LICENSE.txt 와 SKILL.md 가 보이면 복사된 것입니다.

STEP 5MCP 서버 추가하기3분

이 단계에서는 터미널의 claude mcp add 명령으로 Playwright MCP 서버를 Claude Code에 등록합니다.

Playwright MCP는 마이크로소프트가 만든 브라우저 자동화용 MCP 서버로, Node.js 18 이상이 필요합니다. 이 명령은 Claude Code 입력창 말고 터미널에 입력합니다. README에 적힌 명령은 아래 첫 줄이고, playwright는 내가 붙이는 서버 이름, 그 뒤는 서버를 실행하는 명령입니다. 서버 쪽 옵션을 덧붙일 때는 문서의 기본 문법처럼 -- 뒤에 서버 명령을 적어야 Claude Code가 그 옵션을 자기 옵션으로 잘못 읽지 않습니다.
용어 · stdio 서버내 컴퓨터에서 프로세스로 실행되는 MCP 서버입니다. Playwright MCP처럼 npx 명령으로 띄우는 서버가 여기에 들어갑니다.
터미널 (Playwright MCP README의 명령)
claude mcp add playwright npx @playwright/mcp@latest

확인등록됐는지는 7단계의 claude mcp list 로 확인합니다.

터미널 (Claude Code 문서의 기본 문법)
claude mcp add [options] <name> -- <command> [args...]

확인-- 앞에는 Claude Code 옵션(--transport, --env, --scope)을, 뒤에는 서버에 그대로 넘길 명령을 씁니다.

터미널 (인터넷 주소로 접속하는 원격 서버)
claude mcp add --transport http <name> <url>

확인원격 HTTP 서버는 이 형식으로 추가합니다.

STEP 6MCP 서버를 쓸 범위 정하기2분

이 단계에서는 MCP 서버를 이 프로젝트에서만 쓸지, 팀과 나눌지, 내 모든 프로젝트에서 쓸지 고릅니다.

범위를 지정하지 않으면 local로 들어가서, 서버를 추가한 그 프로젝트에서 나만 씁니다. -s 또는 --scope 옵션으로 범위를 바꿀 수 있고, 아래 명령은 Claude Code 문서에 실린 user 범위 예시입니다. project 범위는 프로젝트 맨 위 폴더의 .mcp.json에 저장되므로 저장소에 함께 올리면 팀원도 같은 설정을 받습니다. 보안을 위해 Claude Code는 .mcp.json에 든 서버를 쓰기 전에 승인을 묻고, 이때 한 선택은 claude mcp reset-project-choices로 초기화할 수 있습니다.

같은 이름의 서버가 여러 범위에 있으면 local, project, user 순서로 앞선 한 곳의 설정만 씁니다. 여러 곳의 설정이 섞이지는 않습니다.

터미널 (Claude Code 문서에 실린 user 범위 예시, 원격 HTTP 서버)
claude mcp add --transport http hubspot --scope user https://mcp.hubspot.com/anthropic

확인user 범위 서버는 ~/.claude.json에 저장되어 이 컴퓨터의 모든 프로젝트에서 쓸 수 있습니다.

범위쓰이는 곳팀 공유저장 위치
local(기본)현재 프로젝트안 함~/.claude.json
project현재 프로젝트버전 관리로 공유프로젝트 루트의 .mcp.json
user내 모든 프로젝트안 함~/.claude.json

STEP 7연결 확인하고 지우기2분

이 단계에서는 붙인 MCP 서버와 스킬이 제대로 잡혔는지 보고, 필요 없어지면 지웁니다.

터미널에서 claude mcp list를 실행하면 서버마다 ✔ Connected, ! Needs authentication, ✘ Failed to connect 같은 상태가 나옵니다. Claude Code 안에서 /mcp를 입력하면 연결된 서버마다 도구 개수가 보이고, 로그인(OAuth)이 필요한 원격 서버는 여기서 인증하거나 'Clear authentication'으로 권한을 거둘 수 있습니다. 서버를 지울 때는 claude mcp remove 뒤에 서버 이름을 적으며, 원격 서버라면 저장해 둔 인증 토큰도 함께 지워집니다. 직접 복사한 스킬은 그 폴더를 지우면 되고, 플러그인으로 받은 스킬은 /plugin uninstall로 플러그인째 지웁니다.

마켓플레이스 자체를 /plugin marketplace remove로 지우면 그 마켓플레이스에서 설치한 플러그인도 모두 지워집니다.

터미널
claude mcp list

확인등록된 서버 목록과 서버별 연결 상태가 나옵니다.

Claude Code 입력창
/mcp

확인연결된 서버와 서버별 도구 개수가 보입니다.

터미널
claude mcp remove playwright

확인playwright 서버 등록이 지워집니다.

Claude Code 입력창
/plugin uninstall example-skills@anthropic-agent-skills

확인플러그인과 그 안의 스킬이 함께 지워집니다.

터미널(맥·리눅스)
rm -r ~/.claude/skills/frontend-design

확인4단계에서 직접 복사한 스킬 폴더가 지워집니다.

STEP 8믿을 수 있는 출처만 설치하기3분

이 단계에서는 스킬과 플러그인, MCP 서버를 넣기 전에 확인할 것을 정리합니다.

Claude Code 문서는 플러그인과 마켓플레이스가 내 컴퓨터에서 내 사용자 권한으로 어떤 코드든 실행할 수 있는 구성 요소라며, 믿을 수 있는 출처에서만 설치하라고 안내합니다. MCP 서버도 연결하기 전에 믿을 만한지 확인하라고 하고, 외부 콘텐츠를 가져오는 서버는 프롬프트 인젝션 위험이 있다고 적습니다. 스킬은 allowed-tools 칸으로 스스로 넓은 도구 권한을 가질 수 있으므로, 남의 저장소에 든 스킬은 이 칸과 !` 로 시작하는 명령 줄을 먼저 읽어 봅니다. Playwright MCP README도 이 서버가 보안 경계(security boundary)가 되지 못한다고 밝히고 있습니다.

사용자·프로젝트·플러그인 스킬 안의 !` 명령 실행을 막으려면 설정에 "disableSkillShellExecution": true를 넣습니다. 그러면 명령은 실행되지 않고 '[shell command execution disabled by policy]'라는 글로 바뀝니다. Claude Code에 기본으로 들어 있는 스킬과 관리 설정으로 배포된 스킬에는 적용되지 않습니다. 키가 필요한 서버를 project 범위로 추가하면 설정이 .mcp.json에 저장되어 저장소와 함께 공유됩니다. 공식 문서는 키가 든 서버는 local 범위로 두거나, .mcp.json에는 키 대신 ${API_KEY}처럼 환경 변수 이름을 적으라고 안내합니다.

이렇게 말고검색으로 찾은 낯선 저장소의 스킬과 MCP 서버를 내용을 보지 않고 한꺼번에 설치하기
이렇게공식 저장소에서 고르고(MCP 커넥터는 앤트로픽 디렉터리 claude.ai/directory, 플러그인은 공식 마켓플레이스 claude.com/plugins), SKILL.md의 allowed-tools와 서버 README의 보안 안내를 읽은 뒤 하나씩 설치하기
보너스 · 설치 전 체크리스트
  1. 스킬이나 서버를 만든 곳이 공식 저장소이거나 믿을 수 있는 회사인지 확인했습니다
  2. SKILL.md의 description, allowed-tools, !` 로 시작하는 명령 줄을 읽었습니다
  3. MCP 서버 범위(local·project·user)를 정했고, 키가 든 설정이 .mcp.json으로 공유되지 않는지 확인했습니다
  4. claude mcp list에서 ✔ Connected를 확인했습니다
  5. /mcp에서 서버별 도구 개수를 봤습니다
  6. 안 쓰는 서버와 스킬은 지워 두었습니다
솔직히 한계
  • 편집부는 이 작업 공간에서 claude 명령을 실행할 수 없어서 claude, /plugin, /mcp 명령은 2026년 10월 27일 기준 공식 문서와 README에서 옮겼고 실행해 보지는 못했습니다. 7단계의 claude mcp remove playwright처럼 문서의 문법에 이 글의 이름을 넣은 명령도 마찬가지입니다. 화면 이름과 출력은 버전에 따라 달라질 수 있습니다.
  • anthropics/skills의 스킬은 시연과 교육을 위한 것이고, Claude에 실제로 들어 있는 기능과 동작이 다를 수 있다고 README가 밝힙니다. 문서 스킬 4종(docx·pdf·pptx·xlsx)은 오픈소스가 아닌 소스 공개 라이선스입니다.
  • 스킬을 많이 깔면 스킬 목록이 매 턴 맥락을 차지하고, 설명이 잘려 Claude가 제때 꺼내지 못할 수 있습니다. MCP 도구 출력은 기본으로 25,000토큰까지만 받고, 10,000토큰을 넘으면 경고가 뜹니다.
  • 터미널 명령은 맥·리눅스 기준입니다. 윈도우에서는 경로 표기와 복사 명령이 다르므로 3단계의 플러그인 설치가 더 간단합니다.
