걸리는 시간20분
왜 필요한가요데이터 분석에서 AI가 가장 자주 틀리는 곳은 열을 잘못 이해하거나 검정을 잘못 고르는 단계입니다. 분석 순서와 점검 항목을 담은 스킬을 쓰면 AI가 데이터 품질부터 확인하고 방법을 설명한 뒤 결과를 내도록 이끌 수 있습니다.
앤트로픽 knowledge-work-plugins의 data 플러그인은 데이터 탐색, SQL 작성, 통계 분석, 시각화, 대시보드, 분석 검증 스킬로 이뤄져 있습니다. 스노우플레이크·빅쿼리 같은 데이터 웨어하우스와 연결할 수 있지만 파일을 올려도 쓸 수 있습니다. 엑셀 파일 자체를 만들고 고칠 때는 앤트로픽 공식 xlsx 스킬이, A/B 테스트와 코호트 분석은 파베우 후린 pm-skills의 pm-data-analytics가 맞습니다. 엑셀 파일을 올려 질문하는 기본 방법은 '엑셀 파일 올려서 요약·차트·이상한 숫자 찾기' 튜토리얼에 따로 정리했습니다.

STEP 1설치 전에 알아 둘 것5분

스킬은 SKILL.md 설명서와 보조 파일이 든 폴더이고 필요한 순간에만 AI가 꺼내 읽습니다.

클로드 코드에서는 저장소를 플러그인 마켓플레이스로 등록한 뒤 필요한 플러그인만 설치합니다. claude.ai에서는 프로 이상 요금제에서 설정 → Capabilities의 Skills 칸에 스킬 폴더를 ZIP으로 올립니다. 이때 코드 실행과 파일 만들기가 켜져 있어야 합니다. 앤트로픽 도움말은 믿을 수 있는 곳의 스킬만 설치하고 그렇지 않은 스킬은 안에 든 스크립트와 외부 접속 지시를 먼저 읽어 보라고 안내합니다.

스킬 설명은 대부분 영어지만 한국어로 요청해도 상황에 맞는 스킬이 불려 나옵니다. 잘 안 불리면 '○○ 스킬을 써서'라고 이름을 적어 줍니다. 설치와 삭제 방법은 '클로드 코드에 스킬·MCP 붙이는 법, 설치부터 떼기까지 8단계'에 자세히 정리했습니다.

어디서 쓰나설치 방법조건
클로드 코드/plugin marketplace add 저장소 → /plugin install 플러그인@마켓플레이스클로드 프로 이상 또는 Console 계정
claude.ai(웹·앱)설정 → Capabilities → Skills에서 스킬 폴더 ZIP을 'Upload skill'프로·맥스·팀·엔터프라이즈, 코드 실행 켜기
코덱스·커서 등 다른 에이전트npx skills add 저장소 (-a 로 대상 에이전트 지정)Node.js 22.20 이상

STEP 2처음 받은 데이터 훑기 · explore-data3분

표의 모양, 빈칸 비율, 열별 분포, 이상한 값을 먼저 확인합니다.

분석에 들어가기 전에 데이터가 믿을 만한지 보는 단계입니다. 결과를 보고 열 뜻을 바로잡아 주면 이후 분석이 덜 흔들립니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
클로드 코드
/plugin marketplace add anthropics/knowledge-work-plugins
/plugin install data@knowledge-work-plugins

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
explore-data 스킬로 올린 파일을 훑어봐 줘. 행·열 수, 열별 자료형과 빈칸 비율, 값이 이상한 열, 같은 뜻인데 표기가 다른 값을 표로 보여 주고 아직 분석은 하지 마.

STEP 3SQL 작성 · write-query3분

말로 설명한 분석을 우리 데이터베이스 문법에 맞는 SQL로 바꿉니다.

데이터베이스 종류(빅쿼리, PostgreSQL, MySQL 등)와 표 구조를 알려 주면 그 문법으로 씁니다. 같은 플러그인의 sql-queries 스킬은 자주 쓰는 패턴 모음 역할을 합니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
write-query 스킬로 [빅쿼리] SQL을 써 줘. 표는 orders(order_id, user_id, amount, created_at), users(user_id, signup_date, channel)야. 가입 채널별로 첫 주문까지 걸린 일수의 중앙값을 구하고, 쿼리 각 부분이 하는 일을 주석으로 달아 줘.

STEP 4통계 분석 · statistical-analysis3분

기술 통계, 추세, 이상치, 가설 검정을 맞는 방법으로 고릅니다.

왜 그 검정을 골랐는지와 결과를 어떻게 읽는지까지 설명하게 하면 보고서에 그대로 옮길 수 있습니다. 연구 논문 수준의 검정력 계산이 필요하면 연구자 편의 K-Dense 스킬이 더 깊습니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
statistical-analysis 스킬로 [신규 화면 A안·B안]의 전환율 차이가 의미 있는지 봐 줘. 데이터는 첨부 파일이야. 고른 검정과 이유, 가정을 만족하는지, 효과 크기, 결과를 한 문장으로 해석한 문장을 알려줘.

STEP 5차트 · create-viz3분

추세·비교·분포에 맞는 차트 종류를 고르고 파이썬으로 그립니다.

보고서에 넣을 차트라면 축 이름, 단위, 출처 문구까지 넣으라고 요청합니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
create-viz 스킬로 월별 매출 추세와 채널별 비중을 차트 2개로 그려 줘. 축 이름과 단위(원)를 넣고, 색은 4가지 이내로, 차트마다 한 줄 해석을 붙여 줘.

STEP 6대시보드 · build-dashboard3분

핵심 지표 카드, 차트, 필터, 표가 있는 HTML 대시보드를 한 파일로 만듭니다.

설치나 서버 없이 브라우저에서 열리는 파일이라 팀에 공유하기 쉽습니다. 대시보드 숫자는 만든 시점 기준이라 데이터 기준일을 화면에 적어 둡니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
build-dashboard 스킬로 첨부한 판매 데이터로 대시보드를 만들어 줘. 위쪽에 이번 달 매출·주문 수·객단가 카드, 가운데 월별 추세 차트, 아래에 지역 필터가 있는 표를 넣고 데이터 기준일을 표시해 줘.

STEP 7공유 전 검증 · validate-data3분

발표 전에 분석 방법, 계산, 편향을 점검합니다.

다른 사람이 한 분석을 검토할 때도 씁니다. 지적 사항을 심각도별로 나눠 달라고 하면 고칠 순서가 보입니다. 저장소는 anthropics/knowledge-work-plugins이고 별 약 3만 4천, 라이선스 Apache 2.0, 마지막 커밋은 11월 3일입니다.
복사해서 쓰는 프롬프트
validate-data 스킬로 아래 분석을 공유 전에 검증해 줘. 1) 방법이 질문에 맞는지, 2) 계산을 다시 해서 맞는지, 3) 표본·기간에서 생길 수 있는 편향을 심각도별로 알려줘. 분석: [붙여 넣기]

STEP 8엑셀 파일 만들기 · xlsx3분

수식과 서식이 살아 있는 엑셀 파일을 만들거나 고칩니다.

앤트로픽 문서 스킬 중 하나로 claude.ai 유료 요금제에는 이미 들어 있습니다. 클로드 코드에서는 document-skills 플러그인으로 설치합니다. 이 스킬의 라이선스는 소스 공개(source-available) 방식입니다. A/B 테스트·코호트 분석이 잦다면 phuryn/pm-skills의 pm-data-analytics 플러그인을 함께 씁니다. 저장소는 anthropics/skills이고 별 약 18만, 라이선스 대부분 Apache 2.0(docx·pdf·pptx·xlsx는 소스 공개), 마지막 커밋은 10월 28일입니다.
클로드 코드
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills

확인문서 기준: 설치가 끝나면 /plugin 목록에 나타나고, 관련 요청을 하면 스킬이 자동으로 쓰입니다

복사해서 쓰는 프롬프트
xlsx 스킬로 분석 결과를 엑셀 파일로 만들어 줘. 시트1은 원본, 시트2는 월별 요약(SUMIFS 수식이 살아 있게), 시트3은 차트야. 값을 직접 쓰지 말고 수식으로 계산해 줘.
솔직히 한계
  • 별 수와 마지막 커밋은 2026년 11월 5일 기준입니다. 스킬 이름과 설치 명령은 저장소 쪽에서 자주 바뀌니 설치 전에 README를 한 번 더 확인하세요.
  • 편집부는 각 스킬의 SKILL.md와 README를 읽고 골랐고 모든 스킬을 실제 업무 자료로 돌려 보지는 않았습니다.
  • AI가 실행한 계산도 틀릴 수 있습니다. 숫자 두세 개는 원본에서 직접 확인하세요.
  • 회사 데이터를 연결하거나 올리면 서비스 회사로 전달됩니다. 고객 개인정보가 든 열은 지우거나 가린 사본으로 분석하세요.
