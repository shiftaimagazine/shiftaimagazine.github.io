디자인 툴이 모델을 직접 만드는 이유

캔바가 첫 자체 이미지 모델 크래프트를 내놓았습니다. 구도와 글자를 먼저 설계한 뒤 결과를 레이어로 나눠 고칠 수 있게 한 모델입니다. 범용 이미지 모델과는 '잘 그리기'보다 '고치기 쉬움'으로 겨룹니다. 내년에는 디자인·문서 도구마다 자기 작업 방식에 맞춘 모델을 내놓을 것입니다.

SHIFT AI 편집장2026.10.231분 읽기

캔바(Canva)의 사내 연구 조직이 첫 이미지 생성 모델 '크래프트(Craft)'를 만들어 공개했는데 계획 모델이 구도·크기·위계·글자를 먼저 정하면 렌더링 모델이 그 설계대로 그리는 방식입니다. 해상도는 최대 2K이고 30종 이상의 화면비와 55개 언어의 글자를 지원하며 생성 결과는 매직 레이어스로 나눠 요소별로 편집할 수 있습니다.

왜 이렇게 보나

디자이너에게는 이미지 한 장이 나온 뒤부터 일이 시작됩니다. 글자를 바꾸고, 위치를 옮기고, 크기를 다른 판형으로 맞춰야 합니다. 범용 이미지 모델의 도움은 그 한 장에서 끝납니다. 캔바는 자기 편집기에서 '고칠 수 있는 결과'를 내려고 굳이 모델을 직접 만들었는데 이런 모델은 그 작업 흐름이 있는 회사만 만들 수 있습니다.

편집장의 전망
  1. 2027년 6월까지, 주요 디자인·문서·프레젠테이션 도구 두 곳 이상이 자체 또는 자사 특화 생성 모델을 발표합니다.
  2. 이미지 모델 비교의 기준에 '레이어·글자 편집 가능 여부'가 화질만큼 자주 등장합니다.
  3. 캔바는 크래프트를 MCP 등 외부 AI 연동으로 넓혀, 다른 챗봇 안에서도 편집 가능한 디자인을 만들게 합니다.

틀릴 수 있는 지점

범용 모델 회사들이 레이어 분리와 글자 편집을 기본 기능으로 넣으면 디자인 도구가 자체 모델을 둘 이유가 약해집니다. 캔바 뉴스룸 글에는 게시 날짜도, 경량 버전과 MCP 연동의 구체적 일정도 없습니다. 그래서 '중간'입니다.

캔바, 첫 자체 이미지 모델 '크래프트' 공개…구도부터 짜고 그린다

캔바가 직접 설계하고 학습시킨 첫 이미지 생성 모델 '캔바 크래프트'를 내놨습니다. 그리기 전에 배치·크기·글자를 먼저 계획하는 2단계 구조여서 이미지 속 글자가 뭉개지는 문제가 줄었다고 회사는 설명합니다. 결과물은 레이어별로 나눠 다시 편집할 수 있습니다.
