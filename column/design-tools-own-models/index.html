디자인 툴이 모델을 직접 만드는 이유

캔바가 첫 자체 이미지 모델 크래프트를 냈다. 구도와 글자를 먼저 설계하고, 결과를 레이어로 나눠 고칠 수 있게 했다. 범용 이미지 모델과의 승부처는 '잘 그리기'가 아니라 '고치기 쉬움'이다. 내년엔 디자인·문서 도구마다 자기 작업 방식에 맞춘 모델을 내놓을 것이다.

캔바(Canva)는 사내 연구 조직이 만든 첫 이미지 생성 모델 '크래프트(Craft)'를 공개했다. 계획 모델이 구도·크기·위계·글자를 먼저 정하고, 렌더링 모델이 그 설계대로 그린다. 최대 2K 해상도, 30종 이상의 화면비, 55개 언어의 글자를 지원하고, 생성 결과는 매직 레이어스로 편집 가능한 요소로 나눌 수 있다.

왜 이렇게 보나

디자이너에게 이미지 한 장은 끝이 아니라 시작이다. 글자를 바꾸고, 위치를 옮기고, 크기를 다른 판형으로 맞춰야 한다. 범용 이미지 모델은 한 장을 잘 그리지만 그다음을 돕지 못한다. 캔바가 굳이 모델을 직접 만든 이유는 자기 편집기에서 '고칠 수 있는 결과'를 내기 위해서다. 그 작업 흐름을 가진 회사만 만들 수 있는 모델이다.

편집장의 예측
  1. 2027년 6월까지, 주요 디자인·문서·프레젠테이션 도구 두 곳 이상이 자체 또는 자사 특화 생성 모델을 발표한다.
  2. 이미지 모델 비교의 기준에 '레이어·글자 편집 가능 여부'가 화질만큼 자주 등장한다.
  3. 캔바는 크래프트를 MCP 등 외부 AI 연동으로 넓혀, 다른 챗봇 안에서도 편집 가능한 디자인을 만들게 한다.

틀릴 수 있는 지점

범용 모델 회사들이 레이어 분리와 글자 편집을 기본 기능으로 넣으면, 디자인 도구가 자체 모델을 가질 이유가 약해진다. 캔바 뉴스룸 글에는 게시 날짜도, 경량 버전과 MCP 연동의 구체적 일정도 없다. 그래서 '중간'이다.
