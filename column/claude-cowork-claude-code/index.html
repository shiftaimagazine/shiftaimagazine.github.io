클로드·코워크·클로드 코드는 뭐가 다를까, 구독 하나로 쓰는 세 가지

클로드는 대화하고 문서를 만드는 앱이고 코워크는 여러 단계의 일을 맡기는 기능, 클로드 코드는 코드를 고치고 명령을 실행하는 개발 도구입니다. 셋은 프로(월 20달러) 구독 하나로 함께 쓰고 사용량 한도도 나눠 씁니다. 무료 요금제에서는 대화만 됩니다.

클로드 요금 페이지를 열면 클로드, 코워크, 클로드 코드라는 이름이 한꺼번에 나옵니다. 셋은 따로 결제하는 상품이 아니고 프로(월 20달러, 세금 별도) 이상 구독 하나로 함께 씁니다. 달라지는 것은 무엇을 맡길 수 있는지, 내 컴퓨터에 어디까지 손을 대는지입니다. 저는 대화로 시작해 반복되는 일이 생길 때 작업을 맡기고, 코드를 다룰 일이 있을 때 클로드 코드를 까는 순서가 맞다고 봅니다.

코워크는 이제 따로 고르는 메뉴가 아닙니다

코워크는 1월 12일 맥용 연구 미리보기로 처음 나왔습니다. 앤트로픽은 클로드 코드의 에이전트 능력을 코딩이 아닌 일에 가져왔다고 소개했습니다. 4월 9일 맥과 윈도우 데스크톱 앱에서 정식으로 열렸고 7월 7일에는 웹과 모바일로 넓어졌습니다.

9월 16일 앤트로픽은 코워크를 대화창에 합쳤습니다. 이제 쓰는 사람이 '대화'와 '작업' 중 하나를 고르지 않아도 클로드가 요청을 보고 바로 답할지 여러 단계 작업으로 처리할지 정합니다. 프로·맥스 계정부터 몇 주에 걸쳐 바뀌었고 엔터프라이즈는 10월 23일 정식으로 적용됐습니다. 팀과 무료 요금제는 '곧'이라고만 적혀 있어 아직 코워크 메뉴가 따로 보이는 계정도 있습니다.

10월 6일부터 프로·맥스에서 새로 시작하는 작업은 클라우드에서만 돕니다. 내 컴퓨터의 파일이나 내가 로그인한 크롬을 써야 하는 작업은 데스크톱 앱이 켜져 있어야 하고 파일을 지울 때는 매번 허락을 받습니다. 작업형 요청은 대화보다 사용량을 빨리 씁니다.

클로드 코드는 개발 도구로 남았습니다

클로드 코드는 코드 저장소를 읽고 파일을 고치고 명령을 실행합니다. 터미널에서 출발했지만 지금은 VS Code·커서·JetBrains 같은 편집기, 데스크톱 앱의 Code 탭, 웹(claude.ai/code), 아이폰·안드로이드 앱에서도 씁니다. 파일을 바꾸거나 명령을 실행하기 전에는 허락을 묻습니다.

무료 요금제에서는 쓸 수 없습니다. 프로·맥스에서는 대화와 같은 한도를 나눠 쓰기 때문에 클로드 코드로 오래 작업한 날은 대화 쪽 한도도 함께 줄어듭니다. 한도를 아끼는 방법은 매거진 튜토리얼에 따로 정리해 두었습니다.

튜토리얼클로드 코드 한도가 금방 바닥난다면, 기본 기능만으로 오래 쓰는 7단계

어떤 요금제에서 시작할까

  • 대화와 글쓰기만. 무료로 충분합니다. 웹 검색, 파일 만들기, 메모리, 프로젝트 5개까지 됩니다
  • 일을 맡기고 싶다면. 프로(월 20달러, 연간 결제 시 월 17달러)에서 작업 기능, 클로드 코드, 크롬 확장, 리서치가 열립니다
  • 클로드 코드를 하루 종일 쓴다면. 맥스 5배(월 100달러) 또는 20배(월 200달러)입니다. 5시간 한도가 프로의 5배·20배이고 매달 같은 금액의 API 크레딧이 붙습니다
  • 회사에서 함께 쓴다면. 팀 스탠더드는 1인 월 25달러(연간 20달러)이고 2명부터 150명까지 가입합니다. 대화 내용을 모델 학습에 쓰지 않는 것이 기본값입니다

편집장의 전망
  1. 2026년 안에 팀과 무료 요금제에서도 코워크 메뉴가 사라지고 대화창 하나로 바뀝니다.
  2. 내년 상반기에는 요금 표에서도 '코워크'라는 이름이 빠지고 '클로드'와 '클로드 코드' 두 이름만 남습니다.

틀릴 수 있는 지점

앤트로픽은 아직 팀 요금 표에 '클로드 코드와 클로드 코워크'를 함께 적고 있습니다. 회사 고객에게 익숙한 이름이라 오래 남겨 둘 수도 있습니다. 개발자 쪽에서 코드 작업도 대화창 하나로 하길 원하면 클로드 코드가 먼저 대화창으로 들어오는 쪽으로 흐를 수도 있습니다.
