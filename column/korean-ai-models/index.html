하이퍼클로바X⁠⁠·엑사원⁠⁠·카나나⁠⁠·솔라⁠⁠·A.X, 국산 AI 모델 한 번에 정리

국산 AI 모델은 회사마다 이름과 버전 체계가 달라 한 번에 보기 어렵습니다. 네이버 하이퍼클로바X, LG 엑사원, 카카오 카나나, 업스테이지 솔라, SK텔레콤 A.X⁠(에이닷엑스)⁠를 2026년 11월 11일 각 사 공식 페이지와 보도자료 기준으로 정리했습니다.

SHIFT 편집장 기획 · AI 에디터 작성2026.11.113분 읽기

LG AI연구원은 11월 9일 K-엑사원 2.5의 API를 누구나 무료로 쓸 수 있게 열었고 카카오는 11월 6일 카나나의 새 모델을 허깅페이스에 공개했습니다. 국산 모델 소식은 이렇게 자주 나오지만 이름이 비슷해 어느 회사의 무엇인지 헷갈리기 쉽습니다. 다섯 회사의 공식 페이지와 보도자료를 열어 지금 기준으로 맞춰 봤습니다.

회사별로 지금 나와 있는 것

독파모 2차 모델이라는 말

엑사원과 A.X 소식에는 독파모라는 말이 함께 나옵니다. 정부의 독자 AI 파운데이션 모델 프로젝트를 줄인 말입니다. LG AI연구원은 K-엑사원 2.0을, SK텔레콤은 A.X K2를 이 프로젝트의 2차 모델로 공개했습니다. LG AI연구원은 3차 모델을 개발하고 있고 2027년 1월까지 프런티어급 성능의 엑사원 모델을 완성하겠다는 목표를 밝혔습니다.

AI 사전독자 AI 파운데이션 모델 뜻줄여서 독파모라고 부르는 정부 사업입니다.

직접 써 보려면

개발자가 아니라면 업스테이지의 솔라챗(SolarChat)⁠이 가장 쉽습니다. 업스테이지는 설치나 API 키 없이 브라우저에서 솔라 프로 4를 써 볼 수 있다고 설명합니다. 개발자에게는 API를 무료로 연 K-엑사원 2.5가 문턱이 낮습니다. docs.exaone.ai에서 API 키를 발급받으면 개발자와 스타트업, 기업, 연구 기관 누구나 비용 없이 쓸 수 있습니다. 가중치가 공개된 K-엑사원 2.0과 A.X K2, 카나나는 허깅페이스에서 내려받아 자기 서버에서 돌리는 방식이라 큰 모델일수록 GPU가 많이 필요합니다. SK텔레콤은 A.X K1을 API 형태로 전국민 AI 경진대회 참가자와 선정된 스타트업 등에 제공한다고 밝혔습니다.
