챗GPT vs 클로드

챗GPT와 클로드 모두 무료 요금제가 있고, 많이 쓰는 유료 요금제는 둘 다 한 달 20달러(약 2만 6,500원)⁠입니다. 챗GPT는 8달러짜리 고 요금제와 원화 결제가 있고, 클로드는 무료에서도 파일 만들기와 지메일⁠·캘린더 연결이 열려 있습니다.

챗GPT 쪽이 맞는 사람

무료 대화 폭이 가장 넓고 도움말 기준으로 카카오페이⁠·네이버페이 원화 결제를 지원합니다. 대화, 일 맡기기⁠(워크), 코딩⁠(코덱스)⁠이 데스크톱 앱 하나에 모여 있어 처음 쓰는 분에게 무난합니다. 무료에 광고가 붙는 점은 감안해야 합니다.

클로드 쪽이 맞는 사람

무료에서도 파일 만들기와 문서⁠·슬라이드 만들기가 열려 있어 글과 문서를 많이 다루는 분에게 맞습니다. 대화와 클로드 코드가 같은 한도를 나눠 쓰니 개발까지 하실 분은 프로에서 시작해 한도가 모자랄 때 맥스로 올리면 됩니다. 가격이 달러로만 나오고 세금이 따로 붙습니다.

챗GPT 무료로 되는 것

챗GPT 무료는 GPT-⁠6 루나 모델로 글 대화를 횟수 제한 없이 씁니다(남용 방지 제한은 있습니다). 파일 올리기⁠·이미지 만들기⁠·음성⁠·딥리서치⁠·코덱스는 조금씩만 열려 있고 맞춤형 GPT는 만들 수 없습니다. 한국의 무료⁠·고 요금제에는 광고가 붙고, 플러스부터는 광고가 없습니다.

클로드 무료로 되는 것

클로드 무료는 소네트⁠·하이쿠 모델을 5시간마다 다시 채워지는 한도 안에서 씁니다. 웹 검색, 파일 만들기와 코드 실행, 메모리, 지메일⁠·캘린더⁠·드라이브 연결, 프로젝트 5개까지 됩니다. 클로드 코드, 크롬 확장, 리서치, 오퍼스 모델은 프로부터입니다.

돈을 내야 하는 순간

  • 일을 통째로 맡기고 싶을 때 챗GPT 워크(웹⁠·모바일은 플러스부터), 클로드 작업 기능⁠(유료만), 제미나이 태스크(AI 프로부터), 그록 봇(새 X 구독 프리미엄부터)⁠은 모두 유료 기능입니다.
  • 매일 코딩 도구를 돌릴 때 클로드 코드는 프로부터입니다. 코덱스와 안티그래비티는 무료로 맛보기가 되지만 하루 종일 쓰면 한도가 금방 찹니다.
  • 영상을 만들 때 제미나이는 AI 플러스부터 앱에서 영상을 만듭니다. 오픈AI의 소라는 4월 26일 웹⁠·앱 서비스를 끝냈습니다.
  • 광고가 싫을 때 챗GPT는 플러스 이상에 광고가 없습니다. 무료 이용자는 메시지 한도를 줄이는 대신 광고를 끄는 선택지도 있습니다.

자주 묻는 질문

무료로 더 많이 쓸 수 있는 쪽은 어디인가요?

두 서비스 모두 무료 한도를 숫자로 공개하지 않고 '제한적' 또는 '기본 사용량'이라고만 적어 둡니다. 숫자보다는 위 표처럼 무료로 열린 기능의 종류를 보고 고르는 편이 정확합니다.

원화로 결제할 수 있나요?

챗GPT: 도움말상 원화 결제 지원 (카카오페이⁠·네이버페이). 클로드: 한국 페이지도 달러, 세금 별도. 달러 요금에는 세금이 따로 붙을 수 있습니다.

API로 쓰면 요금이 어떻게 되나요?

앱 구독료와 API 요금은 따로 매깁니다. API로 직접 쓸 때 한 달에 얼마가 드는지는 AI 요금 계산기에서 원화로 비교할 수 있습니다.

틀릴 수 있는 지점

이 비교는 2026년 10월 29일 각 사 공식 요금 페이지 기준입니다. 네 회사 모두 올해 한 번 이상 요금제를 바꿨고 무료 한도는 숫자 없이 수시로 조정됩니다. 결제하기 전에 각 사 요금 페이지에서 원화 금액과 세금 포함 여부를 한 번 더 확인하세요.

  • 챗GPT⁠·클로드⁠·제미나이⁠·그록 요금제 비교 (네 서비스 한 번에)
  • 챗GPT 서비스 한 번에 정리
  • 클로드 서비스 한 번에 정리
  • 챗GPT 최신 소식 · 클로드 최신 소식

다른 비교

챗GPT vs 제미나이가장 싼 유료 요금제는 제미나이 AI 플러스가 월 7,500원, 챗GPT 고가 8달러(약 1만 600원)⁠입니다. 무료로는 챗GPT가 글 대화를 횟수 제한 없이 열어 두었고, 제미나이는 딥리서치와 이미지 만들기, 제미나이 노트북까지 무료로 씁니다.클로드 vs 제미나이클로드의 첫 유료 요금제는 프로 20달러(연간 결제 시 월 17달러)⁠이고, 제미나이는 AI 플러스 7,500원부터 시작합니다. 무료로는 클로드가 웹 검색⁠·파일 만들기⁠·지메일 연결을 쓰고, 제미나이가 딥리서치와 이미지 만들기를 씁니다.챗GPT vs 그록두 서비스 모두 가장 싼 유료 요금제가 8달러(챗GPT 고⁠·그록 플러스)⁠입니다. 챗GPT는 무료 대화 폭이 넓고 원화 결제를 지원하고, 그록은 X 게시물 실시간 검색이 강점이며 새 X 구독에 X 프리미엄 혜택이 묶여 있습니다.
