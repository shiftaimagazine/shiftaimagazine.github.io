챗GPT vs 그록

두 서비스 모두 가장 싼 유료 요금제가 8달러(챗GPT 고·그록 플러스)입니다. 챗GPT는 무료 대화 폭이 넓고 원화 결제를 지원하고, 그록은 X 게시물 실시간 검색이 강점이며 새 X 구독에 X 프리미엄 혜택이 묶여 있습니다.

챗GPT 쪽이 맞는 사람

무료 대화 폭이 가장 넓고 도움말 기준으로 카카오페이·네이버페이 원화 결제를 지원합니다. 대화, 일 맡기기(워크), 코딩(코덱스)이 데스크톱 앱 하나에 모여 있어 처음 쓰는 분에게 무난합니다. 무료에 광고가 붙는 점은 감안해야 합니다.

그록 쪽이 맞는 사람

X 게시물을 실시간으로 찾는 데 강하고 새 X 구독 플러스(월 8달러)에 X 프리미엄 혜택과 커서 사용량까지 묶여 있습니다. 10월 12일 새 구독이 나온 뒤에도 공식 요금 페이지에 예전 슈퍼그록 요금제가 함께 남아 있어 무엇을 사야 할지 헷갈리기 쉽습니다. 국내 앱스토어 연령 등급은 15세 이상입니다.

챗GPT 무료로 되는 것

챗GPT 무료는 GPT-6 루나 모델로 글 대화를 횟수 제한 없이 씁니다(남용 방지 제한은 있습니다). 파일 올리기·이미지 만들기·음성·딥리서치·코덱스는 조금씩만 열려 있고 맞춤형 GPT는 만들 수 없습니다. 한국의 무료·고 요금제에는 광고가 붙고, 플러스부터는 광고가 없습니다.

그록 무료로 되는 것

그록 무료는 웹과 X 게시물 실시간 검색, 음성 대화, 외부 앱 연결을 씁니다. 8월 19일부터는 대화로 앱이나 웹사이트를 만드는 그록 빌드도 모든 요금제에 열렸습니다. 이미지·영상 만들기 기능은 유료 쪽에 적혀 있습니다.

돈을 내야 하는 순간

  • 일을 통째로 맡기고 싶을 때 챗GPT 워크(웹·모바일은 플러스부터), 클로드 작업 기능(유료만), 제미나이 태스크(AI 프로부터), 그록 봇(새 X 구독 프리미엄부터)은 모두 유료 기능입니다.
  • 매일 코딩 도구를 돌릴 때 클로드 코드는 프로부터입니다. 코덱스와 안티그래비티는 무료로 맛보기가 되지만 하루 종일 쓰면 한도가 금방 찹니다.
  • 영상을 만들 때 제미나이는 AI 플러스부터 앱에서 영상을 만듭니다. 오픈AI의 소라는 4월 26일 웹·앱 서비스를 끝냈습니다.
  • 광고가 싫을 때 챗GPT는 플러스 이상에 광고가 없습니다. 무료 이용자는 메시지 한도를 줄이는 대신 광고를 끄는 선택지도 있습니다.

자주 묻는 질문

무료로 더 많이 쓸 수 있는 쪽은 어디인가요?

두 서비스 모두 무료 한도를 숫자로 공개하지 않고 '제한적' 또는 '기본 사용량'이라고만 적어 둡니다. 숫자보다는 위 표처럼 무료로 열린 기능의 종류를 보고 고르는 편이 정확합니다.

원화로 결제할 수 있나요?

챗GPT: 도움말상 원화 결제 지원 (카카오페이·네이버페이). 그록: 웹은 달러, 앱스토어는 원화. 달러 요금에는 세금이 따로 붙을 수 있습니다.

API로 쓰면 요금이 어떻게 되나요?

앱 구독료와 API 요금은 따로 매깁니다. API로 직접 쓸 때 한 달에 얼마가 드는지는 AI 요금 계산기에서 원화로 비교할 수 있습니다.
