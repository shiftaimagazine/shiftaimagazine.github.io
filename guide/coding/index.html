클로드 코드, 처음부터 시작하기

클로드 코드(Claude Code)⁠는 말로 시키면 코드를 읽고 고치고 명령까지 실행하는 앤트로픽의 코딩 에이전트입니다. 터미널을 처음 여는 사람 기준으로 설치하고, 스킬과 MCP 서버를 붙이고, 한도를 아끼는 순서로 묶었습니다.

이 순서로 하면 됩니다

  1. 설치하고 읽기 작업부터

    터미널을 열어 설치하고 연습용 폴더에서 로그인합니다. 첫 작업은 읽기만 시키고, 파일을 바꾸는 일은 허락을 묻는 화면을 보면서 맡깁니다. 자세히 보기 →

  2. 스킬과 MCP 서버 붙이기

    스킬은 일하는 방법을 알려 주는 SKILL.md 폴더이고 MCP 서버는 클로드 코드를 바깥 도구와 이어 주는 프로그램입니다. 공식 문서의 명령으로 설치부터 삭제까지 따라갑니다. 자세히 보기 →

  3. 한도와 토큰 아끼기

    따로 설치하는 도구 없이 클로드 코드에 들어 있는 명령과 설정만으로 한도를 아낍니다. 어디에 많이 쓰는지부터 보고 대화와 지시 파일을 가볍게 유지합니다. 자세히 보기 →

  4. 내 직무에 맞는 스킬 고르기

    개발자용은 계획 세우기, 테스트 먼저 짜기, 디버깅 습관을 잡는 스킬을 골랐습니다. 마케터⁠·기획자⁠·디자이너용 글도 튜토리얼에 따로 있습니다. 자세히 보기 →

자세히 따라 하기

코딩 몰라도 되는 클로드 코드 첫 설치와 첫 작업, 7단계터미널을 처음 여는 사람 기준으로 클로드 코드를 설치하고 로그인합니다. 폴더 속 파일 정리, CSV 합치기 같은 사무 작업을 맡겨 봅니다. 허락을 묻는 방식과 되돌리기 어려운 일을 막는 습관도 함께 다룹니다.클로드 코드에 스킬⁠⁠·MCP 붙이는 법, 설치부터 떼기까지 8단계스킬은 Claude에게 일하는 방법을 알려 주는 SKILL.md 폴더입니다. MCP 서버는 Claude Code를 바깥 도구와 이어 주는 프로그램입니다. 앤트로픽 공식 스킬 저장소와 Playwright MCP를 예로 설치부터 삭제까지 공식 문서의 명령으로 따라갑니다.클로드 코드 한도가 금방 바닥난다면, 기본 기능만으로 오래 쓰는 7단계따로 설치하는 도구 없이 클로드 코드에 들어 있는 명령과 설정만으로 한도와 토큰을 아낍니다. 어디에 많이 쓰는지부터 보고 대화와 지시 파일을 가볍게 유지하는 순서로 갑니다. 모두 공식 문서에서 확인했습니다.개발자가 깔아 두면 좋은 AI 스킬 7개, 계획⁠⁠·테스트⁠⁠·디버깅⁠⁠·보안 점검까지계획 세우기, 테스트 먼저 짜기, 체계적인 디버깅, 끝내기 전 확인까지 코딩 에이전트의 습관을 잡는 스킬을 골랐습니다. 별 30만 개의 superpowers와 앤트로픽⁠·버셀⁠·트레일 오브 비츠 공식 스킬이 중심입니다.기획자⁠⁠·PM이 깔아 두면 좋은 AI 스킬 7개, 기획서⁠⁠·인터뷰 정리⁠⁠·로드맵⁠⁠·보고까지기획서⁠(PRD) 쓰기, 사용자 인터뷰 정리, 로드맵, 이해관계자 보고에 쓰는 스킬을 골랐습니다. 앤트로픽 공식 product-management 플러그인과 별 2만 8천 개의 PM 스킬 모음이 중심입니다.마케터가 깔아 두면 좋은 AI 스킬 7개, 카피⁠⁠·SEO⁠⁠·캠페인⁠⁠·브랜드 검수까지랜딩 페이지 카피, SEO 점검, 광고 소재, 이메일 시퀀스, 캠페인 기획, 브랜드 톤 검수에 쓰는 GitHub 스킬을 골랐습니다. 앤트로픽 공식 마케팅 플러그인과 별 4만 개가 넘는 마케팅 스킬 모음이 중심입니다.
먼저 알아 둘 것
  • 명령은 공식 문서 기준이며 편집부가 이 글을 위해 새로 설치해 보지는 않았습니다. 설치 방식과 화면은 업데이트로 바뀔 수 있습니다.
  • 편집부는 이 작업 공간에서 claude 명령을 실행할 수 없어서 claude, /plugin, /mcp 명령은 2026년 10월 27일 기준 공식 문서와 README에서 옮겼고 실행해 보지는 못했습니다. 7단계의 claude mcp remove playwright처럼 문서의 문법에 이 글의 이름을 넣은 명령도 마찬가지입니다. 화면 이름과 출력은 버전에 따라 달라질 수 있습니다.
  • 명령과 설정은 2026년 10월 27일 공식 문서에서 확인했고 직접 실행해 보지는 않았습니다. 화면이나 이름이 다르면 claude -⁠-⁠version으로 버전을 확인하고 공식 문서를 다시 봅니다.

자주 묻는 질문

코딩을 몰라도 쓸 수 있나요?

첫 튜토리얼은 터미널을 처음 여는 사람 기준으로 썼습니다. 폴더 속 파일 정리나 CSV 합치기 같은 사무 작업부터 맡겨 봅니다.

스킬과 MCP 서버는 무엇이 다른가요?

스킬은 Claude에게 일하는 방법을 알려 주는 SKILL.md 폴더입니다. MCP 서버는 Claude Code를 바깥 도구와 이어 주는 프로그램입니다. 뜻은 AI 사전의 스킬과 MCP에서도 볼 수 있습니다.
