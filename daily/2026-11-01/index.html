클로드 코드 확장 변조, 우주 TPU 첫 응답, AI 학습 거부 표시 초안

커서 마켓플레이스에 클로드 코드 확장 변조판이 올라왔다가 내려갔고 구글 선캐처 위성은 궤도 위 TPU로 첫 AI 응답을 보냈으며, robots.txt로 AI 학습 선호를 적는 IETF 초안도 나왔습니다.

01
보안·안전

클로드 코드 확장 2.1.312·2.1.313 변조판, 커서 마켓플레이스에서 약 11시간 배포

클로드 코드 확장(Anthropic.claude-code) 2.1.312·2.1.313 변조판이 10월 29일(미국 태평양 시각) 커서의 VS Code 확장 마켓플레이스에서 약 11시간 배포됐습니다. 변조판은 공격자의 SSH 키를 심으려 했고 커서는 확인 명령과 정리 스크립트를 내놓았습니다.

02
연구

구글 프로젝트 선캐처, 궤도 위 TPU에서 젬마 4가 첫 응답 보내

구글 프로젝트 선캐처(Project Suncatcher) 시험 위성이 궤도 위 데이터센터급 TPU에서 젬마 4 모델을 돌려 첫 응답을 지상으로 보냈습니다. 구글은 10월 30일(미국 시각) 위성이 우주를 주제로 쓴 하이쿠를 공개했습니다.

03
정책·저작권

robots.txt로 AI 학습 거부 표시하는 IETF 초안 나와

웹사이트가 robots.txt로 AI 학습 사용에 대한 선호를 밝히는 IETF 초안 ‘Machine-Readable Training Preference Signal’이 10월 30일 올라왔습니다. 검색 크롤링 규칙과는 따로 학습 여부만 표시하는 방식입니다.
