AI가 찾은 구멍들: PHP와 Node.js가 같은 날 보안 패치

보안 공지 두 건과 광고·클라우드·연구 소식까지 여섯 건.

SHIFT AI 편집부소식 6건
오늘의 3줄
  1. 위즈, AI로 찾은 PHP 엔진 원격 코드 실행 결함 "PHP2Shell" 공개(CVSS 최고 9.2)
  2. Node.js 취약점 10건 패치, 고위험 1건은 오픈AI 코덱스 시큐리티가 보고
  3. 챗GPT 광고 26개국 추가해 89개국, 광고주 10만 곳 돌파(자체 발표 기준)
01
보안·안전

AI가 찾아낸 PHP 엔진 취약점, 웹의 70%가 영향권

위즈 리서치가 PHP 엔진 자체에서 로그인 없이 서버를 장악할 수 있는 취약점 묶음을 찾아 공개했다. 발견부터 공격 코드 검증까지 AI 모델을 썼고, PHP 5.4 이후 거의 모든 버전이 영향권이다. 해법은 PHP 보안 업데이트뿐이다.

02
보안·안전

Node.js 취약점 10건 패치, 고위험 1건은 오픈AI 코덱스가 찾았다

Node.js가 10월 21일 22·24·26 세 버전군에 보안 업데이트를 냈다. 고친 취약점 10건 중 4건이 고위험이고, 원격 코드 실행까지 이어질 수 있는 Brotli 압축 해제 결함은 오픈AI 코덱스 시큐리티 연구자 명의로 보고됐다.

03
비즈니스·일자리

챗GPT 광고, 26개국 늘려 89개국으로

오픈AI가 10월 21일 챗GPT 광고를 26개국에 추가로 열어 89개국으로 넓혔다. 광고주는 10만 곳을 넘었다. 광고는 무료·고 요금제에만 붙고, 18세 미만 계정과 건강·정치 같은 민감한 주제에는 나오지 않는다.

04
비즈니스·일자리

오픈AI 모델, 구글 클라우드에서 판다…“주 파트너는 여전히 MS”

오픈AI의 프런티어 모델과 코덱스가 구글 클라우드 ‘모델 가든’에서 팔린다. 기업은 이미 맺은 구글 클라우드 약정 금액으로 살 수 있고, 정식 출시는 수 주 안이다. 오픈AI는 마이크로소프트가 여전히 주된 클라우드 파트너라고 따로 밝혔다.

05
연구

AI 글이 읽기 어려운 이유, ‘정보 압축’ 학습의 흔적일 수 있다

AI가 쓴 글이 점점 읽기 어려워졌다는 체감을 언어학 지표로 따진 논문이 나왔다. 최신 모델 9종 모두 사람 글보다 드문 단어 조합과 어색한 주어 쓰기가 많았고, 연구진은 수학·코드 중심의 정보 밀도 최적화를 원인으로 지목했다.

06
비즈니스·일자리

트랜스포머 대신 새 구조로, 네이버 D2SF가 고른 온디바이스 AI ‘트레이스위브’

네이버 D2SF가 스마트폰 CPU만으로 여러 단계 에이전트를 돌리는 온디바이스 AI 스타트업 트레이스위브에 투자했다. 입력이 길어져도 메모리 사용량이 일정한 자체 구조 ‘페이즈-타이탄’을 내세웠고, 시드 라운드에서 약 30억 원을 모았다.
