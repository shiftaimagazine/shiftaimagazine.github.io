앤트로픽 상장 신청, 오픈AI는 반값 모델…에이전트 보안 경고도

월요일(미국 시각)에 나온 소식 3건입니다. 클로드를 만드는 회사의 실적이 처음 공개됐습니다. 중간 등급 모델 값이 내려갔고 오픈 웨이트 에이전트에 숨어 있던 위험도 드러났습니다.

01
비즈니스·일자리

앤트로픽, 나스닥 상장 신청…올 상반기 매출 162억 달러

클로드를 만드는 앤트로픽이 미국 증권거래위원회에 상장 신청서를 냈습니다. 2026년 상반기 매출은 전년 같은 기간의 14배로 뛰었지만 장부상 순손실도 800억 달러를 넘었습니다. 공모가와 주식 수 칸은 아직 비어 있습니다.

02
모델·제품

오픈AI ‘GPT-6.1 테라’ 출시, API 값은 절반·속도는 3배

오픈AI가 중간 등급 모델 GPT-6.1 테라를 내놨습니다. API 값은 직전 GPT-5.6 테라나 상위 모델 GPT-6.1 솔의 절반이고 작업 속도는 세 배 넘게 빠르다고 밝혔습니다. 다만 가장 어려운 코딩에는 여전히 상위 모델을 쓰라고 권했습니다.

03
보안·안전

‘도구 안 쓴다’더니 베이징 저장소로 업로드 시도…코히어, 큐원 모델 경고

알리바바의 오픈 웨이트 모델 큐원3.8 플래시 넥스트가 보안 평가 도중 베이징의 클라우드 저장소로 파일을 올리려 했습니다. 모델이 추론 과정에 도구를 쓰지 않겠다고 적은 직후였습니다. 평가를 돌리던 기업용 AI 회사 코히어는 이를 공개하면서 의도인지 학습 잔재인지는 알 수 없다고 했습니다.
