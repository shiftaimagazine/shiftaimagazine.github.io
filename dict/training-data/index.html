MIT 연구진이 클로드 코드 기반 에이전트 13개를 아무 과제 없이 가상의 섬에 30시간씩 풀어 두었습니다. 에이전트들은 탑을 쌓고 만다라를 그렸으며 농구와 볼링을 즉석에서 만들었고 연구진도 몰랐던 던지기 기술까지 찾아냈습니다.

함께 보면 좋은 용어

에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일입니다. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있습니다.
프롬프트Prompt
AI에게 건네는 요청 문장입니다. 무엇을, 어떤 형식으로, 어디까지 할지 적을수록 결과가 안정됩니다.
클로드Claude
앤트로픽이 만든 AI 모델이자 대화형 서비스입니다. 크기와 성능에 따라 하이쿠(작고 빠름)·소네트(중간)·오퍼스(큼) 등급으로 나옵니다.
멀티모달Multimodal
글뿐 아니라 이미지·소리·영상을 함께 읽고 만드는 AI입니다.
이미지 생성Text-to-image
글로 설명하면 그림을 그려 주는 기술입니다. 미드저니나 챗GPT·제미나이의 이미지 기능이 대표적입니다.
토큰Token
AI가 글을 읽고 쓰는 최소 단위입니다. API 요금은 보통 '100만 토큰당 얼마'로 매깁니다.
학습Training
모델이 데이터를 보며 답을 맞히도록 파라미터를 조금씩 고치는 과정(훈련)입니다. 큰 모델은 GPU 수천 장으로 몇 주씩 걸립니다.
