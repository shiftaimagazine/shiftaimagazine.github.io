엔비디아 Nemotron 3.5 Transcribe 공개…한국어 포함 40개 언어 받아쓰기

엔비디아가 10월 28일 음성 받아쓰기 모델 Nemotron 3.5 Transcribe를 허깅페이스에 공개했습니다. 한국어를 포함한 40개 언어를 받아쓰고 1시간 녹음에서 화자를 8명까지 나누며, 지시문으로 출력 형식을 바꿀 수 있습니다.

데이터셋Dataset
학습이나 평가에 쓰려고 모아 정리한 데이터 묶음입니다.
모델 카드Model card
모델의 성능·한계·안전 시험 결과를 정리해 공개하는 문서입니다. 새 모델이 나올 때 함께 냅니다(시스템 카드라고도 합니다).
양자화Quantization
모델의 숫자를 더 적은 자릿수로 줄여 가볍게 만드는 기술입니다. 품질을 조금 내주는 대신 메모리와 비용을 크게 줄여 노트북·폰에서도 돌릴 수 있게 합니다.
오픈 웨이트Open weight
학습이 끝난 모델의 가중치를 누구나 내려받아 쓸 수 있게 공개한 것입니다. 학습 데이터와 코드까지 다 여는 오픈소스와는 구분합니다.
음성 인식Speech-to-text
말을 글자로 바꾸는 기술(STT, 받아쓰기)입니다. 회의록·자막·음성 비서의 기본입니다.
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일입니다. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있습니다.
화자 분리Speaker diarization
녹음에서 누가 언제 말했는지 나눠 표시하는 기술입니다. 회의 받아쓰기에 말한 사람을 화자 1, 화자 2처럼 붙일 때 씁니다.
네모트론Nemotron
엔비디아가 공개하는 AI 모델 묶음의 이름입니다. 언어 모델과 음성 받아쓰기 모델, 화자 구분 모델 등이 이 이름으로 나옵니다.
