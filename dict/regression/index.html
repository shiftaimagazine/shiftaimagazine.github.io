회귀 버그 관련 기사 1건

연구지켜보세요

허깅페이스 MIC, PR 단계에서 버그 찾는다

허깅페이스(Hugging Face)⁠가 트랜스포머스 라이브러리에 모델 통합 계약⁠(MIC)⁠을 제안했습니다. 실제 모델의 설정으로 줄여 만든 작은 모델에 사용 경로를 돌려 보고, 사람이 검토한 기준 결과와 같은지 CPU에서 확인하는 방식입니다.

2026.11.044분 읽기

함께 보면 좋은 용어

지속적 통합Continuous Integration
코드가 바뀔 때마다 자동으로 빌드와 테스트를 돌려 문제를 빨리 찾는 개발 방식입니다. CI라고 줄여 부릅니다.
풀 리퀘스트⁠(PR)Pull request
내가 고친 코드를 원래 프로젝트에 합쳐 달라고 요청하는 것입니다. 다른 개발자와 자동 검사가 이 단계에서 코드를 살펴봅니다.
픽스처Fixture
테스트를 돌릴 때 미리 만들어 두고 고정해서 쓰는 준비 자료입니다. 허깅페이스의 MIC 제안에서는 실제 모델의 설정으로 줄여 만든 작은 모델을 가리킵니다.
트랜스포머Transformer
오늘날 LLM 대부분이 쓰는 신경망 구조입니다. 그 중심에는 문장 속 단어들의 관계를 한꺼번에 계산하는 '어텐션'이 있습니다.
파라미터Parameter
모델이 학습하며 조정하는 숫자⁠(매개변수)⁠입니다. '1조 파라미터 모델'처럼 모델 크기를 말할 때 씁니다. 많을수록 대체로 똑똑하지만 돌리는 비용도 커집니다.
허깅페이스Hugging Face
AI 모델과 데이터셋을 올리고 내려받는 공유 사이트입니다. 오픈 웨이트 모델 대부분이 여기에 공개됩니다.
LLMLarge Language Model
대규모 언어 모델입니다. 방대한 글로 학습해 글을 읽고 쓰는 AI로, 챗GPT⁠·클로드⁠·제미나이가 대표적입니다.
깃허브GitHub
코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.
