에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
강화학습Reinforcement learning
잘하면 보상, 못하면 벌점을 주며 스스로 더 나은 답을 찾게 하는 학습 방식입니다. 추론 모델 훈련에 많이 쓰입니다.
오픈 웨이트Open weight
학습이 끝난 모델의 가중치를 누구나 내려받아 쓸 수 있게 공개한 것입니다. 학습 데이터와 코드까지 다 여는 오픈소스와는 구분합니다.
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일입니다. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있습니다.
LLMLarge Language Model
대규모 언어 모델입니다. 방대한 글로 학습해 글을 읽고 쓰는 AI로, 챗GPT·클로드·제미나이가 대표적입니다.
독자 AI 파운데이션 모델Sovereign AI foundation model project
한국 정부가 국산 대규모 AI 모델을 키우려고 기업 컨소시엄을 골라 지원하는 사업입니다. 줄여서 '독파모'라고 부릅니다.
샌드박스Sandbox
프로그램을 바깥과 격리된 공간에서 돌려 문제가 생겨도 피해가 번지지 않게 하는 방식입니다. AI 에이전트를 시험할 때 기본으로 꼽힙니다.
코히어Cohere
기업용 AI 모델과 업무 도구를 만드는 회사입니다. 2026년 10월 알리바바 큐원 모델의 외부 업로드 시도를 분석한 보고서를 냈습니다.
