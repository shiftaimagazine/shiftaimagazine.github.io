딥시크 dsh-superagent 공개…깃허브 저장소 하나를 맡는 코딩 에이전트

딥시크(DeepSeek)가 코딩 에이전트 시제품 dsh-superagent를 깃허브에 MIT 라이선스로 공개했습니다. 저장소 하나를 맡아 허락받은 사람의 요청을 받으면 작업 항목을 열고 풀 리퀘스트로 답하는 구조이며, 딥시크는 공식 제품이 아닌 연구용 코드라고 적었습니다.

딥시크DeepSeek
중국 AI 회사이자 그 모델 이름입니다. 2025년 초 적은 비용으로 만들었다는 고성능 오픈 웨이트 모델을 내놓아 업계를 놀라게 했습니다.
깃허브GitHub
코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.
라이선스License
소프트웨어·모델·콘텐츠를 어디까지 써도 되는지 정한 이용 조건입니다. 오픈소스나 오픈 웨이트라도 상업적 이용을 제한하는 경우가 있어 확인이 필요합니다.
에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
오픈소스Open source
소프트웨어 코드를 공개해 누구나 보고 고치고 나눌 수 있게 한 것입니다. 큰 오픈소스 프로젝트는 보안 공지와 패치도 공개적으로 냅니다.
저장소Repository
프로젝트의 코드와 파일, 바뀐 기록을 한곳에 모아 둔 곳입니다. 깃허브에 올린 저장소는 '레포(repo)'라고도 부릅니다.
코딩 에이전트Coding agent
코드 저장소를 읽고 고친 뒤 테스트와 명령 실행까지 스스로 하는 AI 에이전트입니다. 클로드 코드·코덱스·커서가 대표적입니다.
가이디드 러닝Guided Learning
학생이 답으로 곧장 건너뛰지 않고 문제를 단계별로 풀어 가도록 돕는 구글의 학습 기능입니다. 구글 클래스룸과 검색에 들어갑니다.
