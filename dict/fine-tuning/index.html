함께 보면 좋은 용어

프롬프트Prompt
AI에게 건네는 요청 문장입니다. 무엇을, 어떤 형식으로, 어디까지 할지 적을수록 결과가 안정됩니다.
학습 데이터Training data
AI 모델을 만들 때 읽히는 글·그림·코드 뭉치입니다. 어디서 가져왔는지, 학습 중 외부와 연결되는지가 안전과 저작권 문제로 이어집니다.
LLMLarge Language Model
대규모 언어 모델입니다. 방대한 글로 학습해 글을 읽고 쓰는 AI로, 챗GPT·클로드·제미나이가 대표적입니다.
강화학습Reinforcement learning
잘하면 보상, 못하면 벌점을 주며 스스로 더 나은 답을 찾게 하는 학습 방식입니다. 추론 모델 훈련에 많이 쓰입니다.
단어 오류율(WER)Word error rate
음성 받아쓰기가 얼마나 틀렸는지 재는 지표입니다. 정답 문장과 비교해 빠지거나 바뀌거나 더해진 단어의 비율이고 낮을수록 정확합니다.
데이터셋Dataset
학습이나 평가에 쓰려고 모아 정리한 데이터 묶음입니다.
멀티모달Multimodal
글뿐 아니라 이미지·소리·영상을 함께 읽고 만드는 AI입니다.
모델 카드Model card
모델의 성능·한계·안전 시험 결과를 정리해 공개하는 문서입니다. 새 모델이 나올 때 함께 냅니다(시스템 카드라고도 합니다).
