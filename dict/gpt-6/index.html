GPT-⁠6

한 줄 소개

오픈AI의 6세대 GPT 모델 계열입니다. 아스트라⁠·솔⁠·테라⁠·루나처럼 등급마다 이름이 붙는데, 테라는 중간 등급이고 루나는 값이 싼 모델입니다.

GPT-⁠6 최신 소식 4건

모델⁠·제품써볼 만해요

GPT-⁠6.1 테라, API 값 절반⁠⁠·속도 3배

오픈AI가 중간 등급 모델 GPT-⁠6.1 테라를 내놨습니다. API 값은 직전 GPT-⁠5.6 테라나 상위 모델 GPT-⁠6.1 솔의 절반이고 작업 속도는 세 배 넘게 빠르다고 밝혔습니다. 다만 가장 어려운 코딩에는 여전히 상위 모델을 쓰라고 권했습니다.

10년 된 CNN, 피부암 진단서 GPT-⁠6 앞질러

영국 가이스병원 피부과 전문의 매그너스 린치가 2015년 공개된 구글 이미지 신경망을 20분가량 미세조정해 최신 LLM 두 종과 피부 병변 진단을 겨뤘습니다. 조직검사로 확진된 200건 가운데 CNN은 125건, LLM은 84⁠·85건을 맞혔습니다.

오픈AI ‘디시전스 API’ 출시, 출력은 무료

오픈AI가 정식 출시한 디시전스 API는 ‘예/아니오’⁠나 정해진 보기 중 하나를 고르는 식으로 답이 정해진 질문만 빠르게 판단합니다. GPT-⁠6 루나를 바탕으로 응답 API보다 최대 10배 빠르게 답하고 요금은 입력 100만 토큰당 0.1달러이며 출력 요금은 받지 않습니다(자체 발표 기준).

오픈AI, 코볼 이식 정확도 5%→87%

오픈AI가 코볼⁠·포트란처럼 공개 코드가 적은 프로그래밍 언어에서 새 모델의 코딩 성적이 크게 올랐다고 밝혔습니다. 20개 언어로 SQLite 호환 DB 엔진을 만드는 평가에서 GPT-⁠6 아스트라의 평균 통과율은 87.4%로, GPT-⁠5.6 솔⁠(26.8%)⁠의 3배가 넘었습니다(자체 발표 기준).

함께 보면 좋은 용어

GPTGenerative Pre-trained Transformer
오픈AI가 만든 대규모 언어 모델 계열의 이름입니다. '미리 학습한 생성형 트랜스포머'라는 뜻으로, 챗GPT가 이 모델 위에서 돌아갑니다.
오픈AIOpenAI
챗GPT와 GPT 모델을 만든 미국 AI 회사입니다. 마이크로소프트가 최대 투자자이자 주요 클라우드 파트너입니다.
벤치마크Benchmark
모델 성능을 같은 조건으로 재는 시험입니다. 회사가 직접 잰 점수는 '자체 발표 기준'이고, 독립 기관이 잰 점수와 다를 수 있습니다.
추론 비용Inference cost
만들어진 모델을 실제로 돌려 답을 받는 데 드는 돈입니다. 학습 비용과 달리 쓸 때마다 나갑니다. 작은 모델과 캐시가 이 비용을 줄이는 주된 방법입니다.
토큰Token
AI가 글을 읽고 쓰는 최소 단위입니다. API 요금은 보통 '100만 토큰당 얼마'로 매깁니다.
APIApplication Programming Interface
프로그램끼리 기능을 주고받는 창구입니다. AI 회사는 모델을 API로 팔고, 개발자는 이를 불러 자기 앱에 AI 기능을 붙입니다. 보통 쓴 만큼(토큰 단위) 돈을 냅니다.
챗GPTChatGPT
오픈AI의 대화형 AI 서비스입니다. 2022년 11월 공개돼 생성형 AI 붐을 일으켰습니다. 무료판과 유료 요금제가 있고, 무료판에는 광고가 붙기 시작했습니다.
코덱스Codex
오픈AI의 코딩 에이전트입니다. 코드를 쓰고 고치며 보안 취약점을 찾는 데도 쓰입니다.
