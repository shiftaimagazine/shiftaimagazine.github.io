API와 MCP, 무엇이 다른가요

API는 프로그램끼리 기능을 주고받는 창구 전반을 말하고 MCP는 AI가 바깥 앱과 도구에 접속할 때 쓰는 공통 규격입니다.

APIMCP
무엇인가프로그램끼리 기능을 주고받는 창구AI가 바깥 앱⁠·도구에 접속할 때 쓰는 공통 규격
누가 부르나개발자가 짠 프로그램AI 모델과 에이전트
연결 방식서비스마다 주소와 사용법이 다름한 가지 규격에 맞춘 MCP 서버를 붙임
주로 쓰는 사람앱에 AI 기능을 넣으려는 개발자AI에 드라이브⁠·메일 같은 도구를 붙이려는 사용자와 개발자

MCP가 나왔다고 API가 필요 없어지지는 않습니다. MCP 서버는 대개 그 앱의 API를 안에서 부르고 AI가 알아듣는 한 가지 모양으로 바꿔 내놓습니다.

클로드 코드에 MCP 서버를 붙이고 쓸 범위를 정하고 지우는 순서는 아래 튜토리얼에 있습니다. API를 직접 부를 때 드는 요금은 계산기로 원화로 볼 수 있습니다.

한 줄 뜻

APIApplication Programming Interface
프로그램끼리 기능을 주고받는 창구입니다. AI 회사는 모델을 API로 팔고, 개발자는 이를 불러 자기 앱에 AI 기능을 붙입니다. 보통 쓴 만큼(토큰 단위) 돈을 냅니다.
MCPModel Context Protocol
AI가 드라이브⁠·메일⁠·디자인 툴 같은 바깥 앱에 접속할 때 쓰는 공통 규격입니다.

자주 묻는 질문

MCP는 무엇의 약자인가요?

Model Context Protocol의 머리글자입니다.

MCP를 쓸 때도 API 키가 필요한가요?

MCP 서버가 붙는 앱에 따라 다릅니다. 그 앱의 계정 로그인이나 API 키를 요구하는 경우가 많습니다.

이어서 보기

클로드 코드에 스킬⁠⁠·MCP 붙이는 법, 설치부터 떼기까지 8단계튜토리얼AI 요금 계산기 (원화)무료 도구 API 키 뜻API를 쓸 때 내가 누구인지 증명하는 비밀 문자열입니다. 비밀번호처럼 다뤄야 하며, 코드나 화면에 노출되면 남이 내 돈으로 API를 쓸 수 있습니다.

다른 헷갈리는 말

에이전트와 챗봇 차이챗봇은 질문에 답을 돌려주는 데서 끝나고 에이전트는 목표를 받아 필요한 일을 여러 단계로 직접 처리합니다.RAG와 파인튜닝 차이RAG는 답할 때마다 자료를 찾아 읽게 하는 방식이고 파인튜닝은 모델 자체를 추가로 학습시키는 방식입니다.LLM과 생성형 AI 차이생성형 AI는 새 콘텐츠를 만들어 내는 AI 전체를 가리키고 LLM은 그 가운데 글을 읽고 쓰는 모델입니다.머신러닝과 딥러닝 차이머신러닝은 데이터에서 규칙을 스스로 찾게 하는 방법 전체이고 딥러닝은 그 가운데 여러 층의 신경망을 쓰는 방식입니다.
