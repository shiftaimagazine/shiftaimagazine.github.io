클로드 코드 확장 변조판, 커서서 11시간 배포

클로드 코드 확장(Anthropic.claude-code) 2.1.312⁠·2.1.313 변조판이 10월 29일(미국 태평양 시각) 커서의 VS Code 확장 마켓플레이스에서 약 11시간 배포됐습니다. 변조판은 공격자의 SSH 키를 심으려 했고 커서는 확인 명령과 정리 스크립트를 내놓았습니다.

앤트로픽, 비영리단체용 클로드 플러그인

앤트로픽이 비영리단체용 ‘클로드 포 논프로핏’ 플러그인을 내놨습니다. 모금 제안서, 이사회 자료, AI 사용 정책 점검 같은 반복 업무를 돕는 스킬과 연결 도구를 묶었고 팀 요금제 최소 인원도 2명으로 낮췄습니다.

함께 보면 좋은 용어

클로드Claude
앤트로픽이 만든 AI 모델이자 대화형 서비스입니다. 크기와 성능에 따라 하이쿠(작고 빠름)⁠·소네트⁠(중간)⁠·오퍼스⁠(큼) 등급으로 나옵니다.
클로드 코드Claude Code
앤트로픽의 코딩 에이전트입니다. 터미널이나 편집기에서 말로 시키면 코드를 읽고 고치고 명령까지 실행합니다.
마켓플레이스Marketplace
확장 프로그램⁠·플러그인⁠·앱을 모아 내려받게 해 주는 온라인 장터입니다. 2026년 10월 커서 마켓플레이스에는 변조된 클로드 코드 확장이 약 11시간 올라와 있었습니다.
스킬Skill
AI 에이전트에게 '이런 일은 이렇게 해'라고 적어 둔 작업 설명서 묶음입니다. 앤트로픽이 표준으로 공개했습니다.
앤트로픽Anthropic
클로드를 만드는 미국 AI 회사입니다. 오픈AI 출신 연구자들이 2021년 세웠고 AI 안전 연구를 앞세웁니다.
깃허브GitHub
코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.
확장 프로그램Extension
크롬 같은 브라우저나 VS Code 같은 편집기에 깔아 기능을 더하는 작은 프로그램입니다. 권한이 넓은 경우가 많아 공식 마켓플레이스에서도 게시자를 확인하고 설치해야 합니다.
훅Hook
세션 시작처럼 정해진 순간에 에이전트가 자동으로 실행하는 명령이나 안내문입니다. 코덱스 설정의 SessionStart 훅이 한 예입니다.
