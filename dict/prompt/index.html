함께 보면 좋은 용어

멀티모달Multimodal
글뿐 아니라 이미지·소리·영상을 함께 읽고 만드는 AI입니다.
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일입니다. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있습니다.
학습 데이터Training data
AI 모델을 만들 때 읽히는 글·그림·코드 뭉치입니다. 어디서 가져왔는지, 학습 중 외부와 연결되는지가 안전과 저작권 문제로 이어집니다.
MCPModel Context Protocol
AI가 드라이브·메일·디자인 툴 같은 바깥 앱에 접속할 때 쓰는 공통 규격입니다.
스킬Skill
AI 에이전트에게 '이런 일은 이렇게 해'라고 적어 둔 작업 설명서 묶음입니다. 앤트로픽이 표준으로 공개했습니다.
시스템 프롬프트System prompt
사용자 질문보다 먼저 AI에 주어지는 숨은 지시문입니다. 말투·역할·금지 사항을 정하며 사용자에게는 보통 보이지 않습니다.
영상 생성Text-to-video
글이나 사진을 바탕으로 짧은 영상을 만들어 주는 기술입니다. 오픈AI 소라, 구글 비오 같은 모델이 있습니다.
오픈 웨이트Open weight
학습이 끝난 모델의 가중치를 누구나 내려받아 쓸 수 있게 공개한 것입니다. 학습 데이터와 코드까지 다 여는 오픈소스와는 구분합니다.
