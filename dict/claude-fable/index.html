페이블 최신 소식 1건

연구지켜보세요

10년 된 CNN, 피부암 진단서 GPT-⁠6 앞질러

영국 가이스병원 피부과 전문의 매그너스 린치가 2015년 공개된 구글 이미지 신경망을 20분가량 미세조정해 최신 LLM 두 종과 피부 병변 진단을 겨뤘습니다. 조직검사로 확진된 200건 가운데 CNN은 125건, LLM은 84⁠·85건을 맞혔습니다.

함께 보면 좋은 용어

GPTGenerative Pre-trained Transformer
오픈AI가 만든 대규모 언어 모델 계열의 이름입니다. '미리 학습한 생성형 트랜스포머'라는 뜻으로, 챗GPT가 이 모델 위에서 돌아갑니다.
GPT-⁠6GPT-⁠6
오픈AI의 6세대 GPT 모델 계열입니다. 아스트라⁠·솔⁠·테라⁠·루나처럼 등급마다 이름이 붙는데, 테라는 중간 등급이고 루나는 값이 싼 모델입니다.
멀티모달Multimodal
글뿐 아니라 이미지⁠·소리⁠·영상을 함께 읽고 만드는 AI입니다.
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일입니다. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있습니다.
프롬프트Prompt
AI에게 건네는 요청 문장입니다. 무엇을, 어떤 형식으로, 어디까지 할지 적을수록 결과가 안정됩니다.
학습 데이터Training data
AI 모델을 만들 때 읽히는 글⁠·그림⁠·코드 뭉치입니다. 어디서 가져왔는지, 학습 중 외부와 연결되는지가 안전과 저작권 문제로 이어집니다.
CNNConvolutional Neural Network
이미지 속 무늬와 모양을 단계적으로 찾아내는 신경망 구조입니다. 의료 영상⁠·사진 분류에 오래 쓰여 왔습니다.
가이디드 러닝Guided Learning
학생이 답으로 곧장 건너뛰지 않고 문제를 단계별로 풀어 가도록 돕는 구글의 학습 기능입니다. 구글 클래스룸과 검색에 들어갑니다.
