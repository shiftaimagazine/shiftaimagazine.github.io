마이크로소프트 코파일럿 하네스, 파운드리에서 미리 보기…12월부터 과금

마이크로소프트가 10월 28일 깃허브 코파일럿 앱과 CLI, VS Code에서 쓰던 에이전트 실행 틀 ‘코파일럿 하네스’를 파운드리 에이전트 서비스에 공개 미리 보기로 열었습니다. 20개 넘는 모델을 고를 수 있고 12월 1일부터 사용량에 따라 요금을 받습니다.

함께 보면 좋은 용어

CLICommand Line Interface
마우스 대신 글자 명령으로 프로그램을 다루는 방식입니다. 코딩 에이전트 상당수가 터미널에서 CLI로 일합니다.
스킬Skill
AI 에이전트에게 '이런 일은 이렇게 해'라고 적어 둔 작업 설명서 묶음입니다. 앤트로픽이 표준으로 공개했습니다.
에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
마켓플레이스Marketplace
확장 프로그램·플러그인·앱을 모아 내려받게 해 주는 온라인 장터입니다. 2026년 10월 커서 마켓플레이스에는 변조된 클로드 코드 확장이 약 11시간 올라와 있었습니다.
에이전트 하네스Agent harness
AI 모델 바깥에서 지시문과 맥락, 실행 환경, 통제 장치를 대 주는 실행 틀입니다. 마이크로소프트는 깃허브 코파일럿이 쓰는 하네스를 2026년 10월 파운드리에 공개했습니다.
오픈소스Open source
소프트웨어 코드를 공개해 누구나 보고 고치고 나눌 수 있게 한 것입니다. 큰 오픈소스 프로젝트는 보안 공지와 패치도 공개적으로 냅니다.
저장소Repository
프로젝트의 코드와 파일, 바뀐 기록을 한곳에 모아 둔 곳입니다. 깃허브에 올린 저장소는 '레포(repo)'라고도 부릅니다.
플러그인Plugin
기존 프로그램에 기능을 덧붙이는 추가 모듈입니다. 브라우저 확장 프로그램도 같은 개념입니다.
