뜻

코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.

함께 보면 좋은 용어

노코드No-code
코드를 몰라도 블록을 끌어다 놓는 방식으로 앱이나 자동화를 만드는 도구입니다.
라이브러리Library
자주 쓰는 기능을 미리 만들어 둔 코드 묶음입니다. 가져다 쓰면 처음부터 짤 필요가 없습니다.
릴리스Release
소프트웨어의 새 버전을 공개하는 일입니다. 무엇이 바뀌었는지는 릴리스 노트(변경 기록)에 적습니다.
바이브 코딩Vibe coding
코드를 직접 쓰는 대신 AI에게 말로 설명해 앱을 만드는 방식입니다. 보안·배포는 사람이 확인해야 합니다.
베타Beta
정식 출시 전에 일부 사용자에게 먼저 공개하는 시험판입니다. 기능이 바뀌거나 오류가 있을 수 있습니다. 정식 출시는 GA(General Availability)라고 부릅니다.
브라우저Browser
크롬·사파리·엣지처럼 웹사이트를 보여 주는 프로그램입니다. AI가 대신 클릭·입력해 주는 '에이전트 브라우저'도 나오고 있습니다.
알고리즘Algorithm
어떤 문제를 풀기 위한 계산 절차입니다. SNS에서는 '어떤 글을 누구에게 보여 줄지 정하는 규칙'이라는 뜻으로도 씁니다.
앱App
스마트폰이나 컴퓨터에서 쓰는 응용 프로그램(애플리케이션)을 줄여 부르는 말입니다.
