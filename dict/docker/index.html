도커Docker

뜻

프로그램과 실행에 필요한 환경을 '컨테이너'로 묶어 어느 컴퓨터에서나 똑같이 돌게 하는 도구입니다. n8n 같은 도구를 설치할 때 자주 씁니다.

함께 보면 좋은 용어

깃허브GitHub
코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.
노코드No-code
코드를 몰라도 블록을 끌어다 놓는 방식으로 앱이나 자동화를 만드는 도구입니다.
라이브러리Library
자주 쓰는 기능을 미리 만들어 둔 코드 묶음입니다. 가져다 쓰면 처음부터 짤 필요가 없습니다.
렌더링Rendering
코드나 설계 정보를 실제로 보이는 화면·이미지·영상 파일로 만들어 내는 일입니다. 영상은 프레임마다 그려야 해서 시간이 걸립니다.
리눅스 커널Linux kernel
리눅스 운영체제의 중심이 되는 소프트웨어입니다. 하드웨어와 프로그램 사이에서 메모리와 장치를 관리하고, 전 세계 개발자가 오픈소스로 함께 고칩니다.
리모션Remotion
리액트(React) 코드로 영상을 만드는 프레임워크입니다. 개인과 전체 인원 3명 이하 회사는 무료이고, 그보다 큰 회사는 유료 라이선스가 필요합니다.
린(Lean)Lean
수학 증명을 컴퓨터가 한 단계씩 검사할 수 있게 적는 프로그래밍 언어입니다. 사람이 쓴 증명이 맞는지 기계로 확인할 때 씁니다.
릴리스Release
소프트웨어의 새 버전을 공개하는 일입니다. 무엇이 바뀌었는지는 릴리스 노트(변경 기록)에 적습니다.
