AI가 찾아낸 PHP 엔진 취약점, 웹의 70%가 영향권

위즈 리서치가 로그인 없이 서버를 장악할 수 있는 PHP 엔진 취약점 묶음을 찾아 공개했습니다. 발견부터 공격 코드 검증까지 AI 모델을 썼습니다. PHP 5.4 이후 거의 모든 버전이 영향을 받으며 PHP 보안 업데이트를 적용하면 막을 수 있습니다.

PHP 엔진 자체의 원격 코드 실행 취약점(PHP2Shell)이 공개된 만큼, 작은 사이트도 업데이트 설정을 한 번은 점검해 둬야 합니다. 워드프레스 공식 문서에 나온 설정법과 AI에게 물어볼 프롬프트를 함께 정리했습니다.

위즈Wiz
클라우드 보안 회사입니다. 연구팀 위즈 리서치가 2026년 10월 PHP 엔진 취약점 묶음 PHP2Shell을 공개했습니다.
원격 코드 실행(RCE)Remote code execution
공격자가 멀리서 남의 서버나 컴퓨터에 원하는 명령을 실행할 수 있게 되는 취약점입니다. 가장 위험한 축으로 보며 패치를 서둘러야 합니다.
웹 호스팅Web hosting
웹사이트 파일을 올려 두고 인터넷에 24시간 보여 주는 서버를 빌려주는 서비스입니다. 업체에 따라 PHP·워드프레스 업데이트를 대신 해 주기도 합니다.
제로데이Zero-day
개발사가 아직 모르거나 패치가 나오기 전인 취약점입니다. 고칠 시간이 '0일'이라는 뜻이라 특히 위험합니다.
취약점Vulnerability
소프트웨어의 보안 구멍입니다. 로그인 없이 서버에서 명령을 실행하게 해 주는 원격 코드 실행(RCE)이 가장 위험한 축입니다.
CVE·CVSSCVE · CVSS
CVE는 공개된 취약점에 붙는 고유 번호, CVSS는 위험도를 0~10으로 매긴 점수입니다. 9점 이상이면 '치명적'으로 봅니다.
PHPPHP
웹 서버에서 페이지를 만들어 내는 프로그래밍 언어입니다. 워드프레스를 비롯해 웹사이트 상당수가 PHP로 돌아가서 PHP 엔진 취약점은 영향 범위가 넓습니다.
구글 딥마인드Google DeepMind
