함께 보면 좋은 용어

단어 오류율(WER)Word error rate
음성 받아쓰기가 얼마나 틀렸는지 재는 지표입니다. 정답 문장과 비교해 빠지거나 바뀌거나 더해진 단어의 비율이고 낮을수록 정확합니다.
모델 카드Model card
모델의 성능·한계·안전 시험 결과를 정리해 공개하는 문서입니다. 새 모델이 나올 때 함께 냅니다(시스템 카드라고도 합니다).
모델 하드웨어 표준(MHS)Model Hardware Standard
AI 에이전트가 실험 장비 같은 물리 장치를 안전하게 다루도록 앤트로픽이 만든 공통 규격입니다. 2026년 8월 연구용 미리 보기로 열렸고 대기자 명단으로 참여를 받습니다.
양자화Quantization
모델의 숫자를 더 적은 자릿수로 줄여 가볍게 만드는 기술입니다. 품질을 조금 내주는 대신 메모리와 비용을 크게 줄여 노트북·폰에서도 돌릴 수 있게 합니다.
에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
오픈 웨이트Open weight
학습이 끝난 모델의 가중치를 누구나 내려받아 쓸 수 있게 공개한 것입니다. 학습 데이터와 코드까지 다 여는 오픈소스와는 구분합니다.
음성 인식Speech-to-text
말을 글자로 바꾸는 기술(STT, 받아쓰기)입니다. 회의록·자막·음성 비서의 기본입니다.
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일입니다. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있습니다.
