보안·안전

Node.js 취약점 10건 패치, 고위험 1건은 오픈AI 코덱스가 찾았다

Node.js가 10월 21일 22·24·26 세 버전군에 보안 업데이트를 내고 취약점 10건을 고쳤습니다. 고위험 4건 가운데 원격 코드 실행까지 이어질 수 있는 Brotli 압축 해제 결함은 오픈AI 코덱스 시큐리티 연구자 명의로 보고됐습니다.

함께 보면 좋은 용어

오픈소스Open source
소프트웨어 코드를 공개해 누구나 보고 고치고 나눌 수 있게 한 것입니다. 큰 오픈소스 프로젝트는 보안 공지와 패치도 공개적으로 냅니다.
오픈AIOpenAI
챗GPT와 GPT 모델을 만든 미국 AI 회사입니다. 마이크로소프트가 최대 투자자이자 주요 클라우드 파트너입니다.
취약점Vulnerability
소프트웨어의 보안 구멍입니다. 로그인 없이 서버에서 명령을 실행하게 해 주는 원격 코드 실행(RCE)이 가장 위험한 축입니다.
코덱스Codex
오픈AI의 코딩 에이전트입니다. 코드를 쓰고 고치며 보안 취약점을 찾는 데도 쓰입니다.
패치Patch
소프트웨어의 버그나 보안 구멍을 고치는 업데이트입니다. 취약점이 공개되면 패치를 얼마나 빨리 적용하느냐가 피해를 가릅니다.
깃허브GitHub
코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.
노코드No-code
코드를 몰라도 블록을 끌어다 놓는 방식으로 앱이나 자동화를 만드는 도구입니다.
라이브러리Library
자주 쓰는 기능을 미리 만들어 둔 코드 묶음입니다. 가져다 쓰면 처음부터 짤 필요가 없습니다.
