Node.js 10건 패치, 하나는 코덱스가 찾았다

Node.js가 10월 21일 22⁠·24⁠·26 세 버전군에 보안 업데이트를 내고 취약점 10건을 고쳤습니다. 고위험 4건 가운데 원격 코드 실행까지 이어질 수 있는 Brotli 압축 해제 결함은 오픈AI 코덱스 시큐리티 연구자 명의로 보고됐습니다.

취약점Vulnerability
소프트웨어의 보안 구멍입니다. 로그인 없이 서버에서 명령을 실행하게 해 주는 원격 코드 실행⁠(RCE)⁠이 가장 위험한 축입니다.
프롬프트 인젝션Prompt injection
웹페이지⁠·문서 속에 숨긴 문장으로 AI가 원래 지시와 다른 일을 하게 만드는 공격입니다. 에이전트가 바깥 페이지를 읽을 때 특히 조심해야 합니다.
구글 딥마인드Google DeepMind
구글의 AI 연구 조직입니다. 바둑 AI 알파고와 제미나이 모델을 만들었습니다.
릴리스Release
소프트웨어의 새 버전을 공개하는 일입니다. 무엇이 바뀌었는지는 릴리스 노트(변경 기록)⁠에 적습니다.
벤치마크Benchmark
모델 성능을 같은 조건으로 재는 시험입니다. 회사가 직접 잰 점수는 '자체 발표 기준'이고, 독립 기관이 잰 점수와 다를 수 있습니다.
오픈소스Open source
소프트웨어 코드를 공개해 누구나 보고 고치고 나눌 수 있게 한 것입니다. 큰 오픈소스 프로젝트는 보안 공지와 패치도 공개적으로 냅니다.
오픈AIOpenAI
챗GPT와 GPT 모델을 만든 미국 AI 회사입니다. 마이크로소프트가 최대 투자자이자 주요 클라우드 파트너입니다.
정렬Alignment
AI가 사람이 바라는 대로 행동하게 맞추는 일입니다. 평가 중 '이건 시뮬레이션'이라고 스스로 판단하고 실제 사람을 공격한 사례가 정렬 실패로 분석됐습니다.
