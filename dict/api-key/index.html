인포스틸러 VOLTA, LLM으로 피해자 가치 평가

시스코 탈로스(Cisco Talos)⁠가 윈도우 정보 탈취 악성코드 VOLTA를 분석했습니다. 비밀번호와 세션, 암호화폐 지갑을 훔친 뒤 오픈라우터로 LLM을 불러 피해자의 자산 가치와 보안 습관을 평가한 보고서를 만드는 악성코드입니다.

MS 코파일럿 하네스, 파운드리 미리 보기

마이크로소프트가 10월 28일 깃허브 코파일럿 앱과 CLI, VS Code에서 쓰던 에이전트 실행 틀 ‘코파일럿 하네스’⁠를 파운드리 에이전트 서비스에 공개 미리 보기로 열었습니다. 20개 넘는 모델을 고를 수 있고 12월 1일부터 사용량에 따라 요금을 받습니다.

함께 보면 좋은 용어

깃허브GitHub
코드를 저장하고 여럿이 함께 고치는 웹 서비스입니다. 오픈소스 프로젝트 대부분이 여기에 코드와 새 버전을 공개합니다.
에이전트 하네스Agent harness
AI 모델 바깥에서 지시문과 맥락, 실행 환경, 통제 장치를 대 주는 실행 틀입니다. 마이크로소프트는 깃허브 코파일럿이 쓰는 하네스를 2026년 10월 파운드리에 공개했습니다.
BYOKBring Your Own Key
서비스가 정해 둔 AI 대신 내가 따로 발급받은 API 키를 넣어 원하는 모델을 쓰는 방식입니다. 요금은 키를 발급한 AI 회사에 직접 냅니다.
CLICommand Line Interface
마우스 대신 글자 명령으로 프로그램을 다루는 방식입니다. 코딩 에이전트 상당수가 터미널에서 CLI로 일합니다.
MCPModel Context Protocol
AI가 드라이브⁠·메일⁠·디자인 툴 같은 바깥 앱에 접속할 때 쓰는 공통 규격입니다.
SDKSoftware Development Kit
특정 서비스나 기기용 프로그램을 만들 때 쓰는 도구 묶음입니다. 라이브러리⁠·예제⁠·문서가 들어 있어 API를 더 쉽게 쓸 수 있게 해 줍니다.
마이크로소프트Microsoft
윈도우⁠·오피스를 만드는 회사입니다. 오픈AI의 최대 투자자이며 '코파일럿'이라는 이름으로 제품마다 AI 기능을 넣고 있습니다.
샌드박스Sandbox
프로그램을 바깥과 격리된 공간에서 돌려 문제가 생겨도 피해가 번지지 않게 하는 방식입니다. AI 에이전트를 시험할 때 기본으로 꼽힙니다.
