AI 사전

기사에 나오는 용어를 한 줄로. 모르는 말이 나오면 여기서 찾고, 관련 기사로 이어서 읽는다.

에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 한다.
관련 기사: ‘시뮬레이션인 줄’ 실제 개발자 공격한 AI, 영국·앤트로픽 분석 공개
정렬Alignment
AI가 사람이 바라는 대로 행동하게 맞추는 일. 평가 중 '이건 시뮬레이션'이라고 스스로 판단하고 실제 사람을 공격한 사례가 정렬 실패로 분석됐다.
관련 기사: ‘시뮬레이션인 줄’ 실제 개발자 공격한 AI, 영국·앤트로픽 분석 공개
토큰Token
AI가 글을 읽고 쓰는 최소 단위. API 요금은 보통 '100만 토큰당 얼마'로 매긴다.
관련 기사: 클로드 하이쿠 5.5, 값은 하이쿠 4.5의 10분의 1로
추론 비용Inference cost
만들어진 모델을 실제로 돌려 답을 받는 데 드는 돈. 학습 비용과 달리 쓸 때마다 나간다. 작은 모델과 캐시가 이 비용을 줄이는 주된 방법이다.
관련 기사: 클로드 하이쿠 5.5, 값은 하이쿠 4.5의 10분의 1로
오픈 웨이트Open weight
학습이 끝난 모델의 가중치를 누구나 내려받아 쓸 수 있게 공개한 것. 학습 데이터와 코드까지 다 여는 오픈소스와는 구분한다.
관련 기사: 키미 K3.1 프로, 터미널 코딩서 클로드 오퍼스 5.5 턱밑까지
벤치마크Benchmark
모델 성능을 같은 조건으로 재는 시험. 회사가 직접 잰 점수는 '자체 발표 기준'이고, 독립 기관이 잰 점수와 다를 수 있다.
관련 기사: 키미 K3.1 프로, 터미널 코딩서 클로드 오퍼스 5.5 턱밑까지
오픈소스Open source
소프트웨어 코드를 공개해 누구나 보고 고치고 나눌 수 있게 한 것. 큰 오픈소스 프로젝트는 보안 공지와 패치도 공개적으로 낸다.
관련 기사: Node.js 취약점 10건 패치, 고위험 1건은 오픈AI 코덱스가 찾았다
취약점Vulnerability
소프트웨어의 보안 구멍. 로그인 없이 서버에서 명령을 실행하게 해 주는 원격 코드 실행(RCE)이 가장 위험한 축이다.
관련 기사: AI가 찾아낸 PHP 엔진 취약점, 웹의 70%가 영향권
CVE·CVSSCVE · CVSS
CVE는 공개된 취약점에 붙는 고유 번호, CVSS는 위험도를 0~10으로 매긴 점수다. 9점 이상이면 '치명적'으로 본다.
관련 기사: AI가 찾아낸 PHP 엔진 취약점, 웹의 70%가 영향권
학습 데이터Training data
AI 모델을 만들 때 읽히는 글·그림·코드 뭉치. 어디서 가져왔는지, 학습 중 외부와 연결되는지가 안전과 저작권 문제로 이어진다.
관련 기사: 오픈AI, 프런티어 모델 훈련에서 실시간 인터넷 끊는다
데이터센터Data center
AI 모델이 실제로 돌아가는 서버 건물. 큰 모델은 칩 여러 장에 나눠 실어야 해서 칩 사이 통신 속도가 성능을 좌우한다.
관련 기사: 세레브라스, 3조 매개변수 모델을 웨이퍼 59장에 나눠 싣는 법
AI 표시AI label
AI가 만들거나 고친 콘텐츠에 붙이는 표시. 이미지·영상·광고부터 의무화가 시작됐고, 글은 기준이 아직 갈린다.
관련 기사: 펜실베이니아, AI로 소비자 속이는 광고에 표시 의무화
광고 타깃팅Ad targeting
이용자 정보를 바탕으로 광고를 골라 보여 주는 일. 어떤 데이터가 쓰이는지는 개인정보처리방침에 적혀 있다.
관련 기사: 구글 개인정보처리방침 개정, 지메일 데이터도 광고 맞춤에 쓰일 수 있다
환각Hallucination
AI가 그럴듯하지만 틀린 내용을 사실처럼 말하는 현상. 숫자·날짜·출처를 원문으로 확인하는 것이 기본 대책이다.
관련 기사: 키미 K3.1 프로, 터미널 코딩서 클로드 오퍼스 5.5 턱밑까지
컨텍스트 윈도우Context window
AI가 한 번에 읽을 수 있는 분량. 토큰으로 센다. 길게 넣을수록 단가가 오르는 요금제도 있다.
관련 기사: 클로드 하이쿠 5.5, 값은 하이쿠 4.5의 10분의 1로
추론 모델Reasoning model
답하기 전에 생각 과정을 길게 거치는 모델. 수학·코딩처럼 단계가 많은 문제에 강하지만 느리고 비싸다.
관련 기사: SKT, 서울대·KAIST와 ‘수학 난제’로 A.X K2 추론력 키운다
파인튜닝Fine-tuning
만들어진 모델에 특정 데이터를 더 학습시켜 한 분야에 맞추는 일. 좁은 분야에서는 작은 모델을 파인튜닝하는 쪽이 더 정확할 때가 있다.
관련 기사: 10년 된 CNN, 피부암 진단에서 GPT-6·클로드를 앞질렀다
MCPModel Context Protocol
AI가 드라이브·메일·디자인 툴 같은 바깥 앱에 접속할 때 쓰는 공통 규격.
관련 기사: 앤트로픽, ‘에이전트 스킬’ 표준을 리눅스재단 산하 AAIF에 넘긴다
스킬Skill
AI 에이전트에게 '이런 일은 이렇게 해'라고 적어 둔 작업 설명서 묶음. 앤트로픽이 표준으로 공개했다.
관련 기사: 앤트로픽, ‘에이전트 스킬’ 표준을 리눅스재단 산하 AAIF에 넘긴다
음성 합성Text-to-speech
글을 사람 목소리로 읽어 주는 기술(TTS). 받아쓰기(전사)와 묶어 음성 에이전트를 만든다.
관련 기사: 미스트랄 ‘복스트랄 3’, 받아쓰기·음성 합성·음성 에이전트 한 묶음
멀티모달Multimodal
글뿐 아니라 이미지·소리·영상을 함께 읽고 만드는 AI.
관련 기사: 미스트랄 ‘복스트랄 3’, 받아쓰기·음성 합성·음성 에이전트 한 묶음
온디바이스 AIOn-device AI
서버 대신 스마트폰·노트북 안에서 바로 돌아가는 AI. 데이터가 기기 밖으로 나가지 않는 것이 장점이다.
관련 기사: 트랜스포머 대신 새 구조로, 네이버 D2SF가 고른 온디바이스 AI ‘트레이스위브’
프롬프트Prompt
AI에게 건네는 요청 문장. 무엇을, 어떤 형식으로, 어디까지 할지 적을수록 결과가 안정된다.
개인정보 가리기Redaction
이름·전화·이메일·주소를 [이름1] 같은 자리표로 바꿔 AI에 올리는 방법. 결과에만 내 PC에서 되돌린다.
RAGRetrieval-Augmented Generation
답하기 전에 내 문서에서 관련 내용을 먼저 찾아 읽고 답하게 하는 방식.
바이브 코딩Vibe coding
코드를 직접 쓰는 대신 AI에게 말로 설명해 앱을 만드는 방식. 보안·배포는 사람이 확인해야 한다.
