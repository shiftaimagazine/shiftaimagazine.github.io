포스트맨, 클로드 코드 플러그인 자동 설치 의혹

포스트맨(Postman) 데스크톱 앱이 클로드 코드와 코덱스에 자체 플러그인을 사용자 동의 없이 설치했다는 보고가 깃허브 이슈로 올라와 있습니다. 보고자의 로그와 설정 파일 기록, 11월 3일 추가 재현 댓글을 정리했습니다.

GPT-⁠6.1 테라, API 값 절반⁠⁠·속도 3배

오픈AI가 중간 등급 모델 GPT-⁠6.1 테라를 내놨습니다. API 값은 직전 GPT-⁠5.6 테라나 상위 모델 GPT-⁠6.1 솔의 절반이고 작업 속도는 세 배 넘게 빠르다고 밝혔습니다. 다만 가장 어려운 코딩에는 여전히 상위 모델을 쓰라고 권했습니다.

오픈AI 모델, 구글 클라우드에서 판다

오픈AI의 프런티어 모델과 코덱스를 구글 클라우드 ‘모델 가든’⁠에서 살 수 있게 됩니다. 기업은 이미 맺은 구글 클라우드 약정 금액으로 결제할 수 있고 정식 출시는 수 주 안에 이뤄집니다. 오픈AI는 마이크로소프트가 여전히 주된 클라우드 파트너라고 따로 밝혔습니다.

Node.js 10건 패치, 하나는 코덱스가 찾았다

Node.js가 10월 21일 22⁠·24⁠·26 세 버전군에 보안 업데이트를 내고 취약점 10건을 고쳤습니다. 고위험 4건 가운데 원격 코드 실행까지 이어질 수 있는 Brotli 압축 해제 결함은 오픈AI 코덱스 시큐리티 연구자 명의로 보고됐습니다.
