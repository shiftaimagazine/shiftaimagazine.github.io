오픈AI ‘GPT-6.1 테라’ 출시, API 값은 절반·속도는 3배

오픈AI가 중간 등급 모델 GPT-6.1 테라를 내놨습니다. API 값은 직전 GPT-5.6 테라나 상위 모델 GPT-6.1 솔의 절반이고 작업 속도는 세 배 넘게 빠르다고 밝혔습니다. 다만 가장 어려운 코딩에는 여전히 상위 모델을 쓰라고 권했습니다.

오픈AI 모델, 구글 클라우드에서 판다…“주 파트너는 여전히 MS”

오픈AI의 프런티어 모델과 코덱스를 구글 클라우드 ‘모델 가든’에서 살 수 있게 됩니다. 기업은 이미 맺은 구글 클라우드 약정 금액으로 결제할 수 있고 정식 출시는 수 주 안에 이뤄집니다. 오픈AI는 마이크로소프트가 여전히 주된 클라우드 파트너라고 따로 밝혔습니다.

Node.js 취약점 10건 패치, 고위험 1건은 오픈AI 코덱스가 찾았다

Node.js가 10월 21일 22·24·26 세 버전군에 보안 업데이트를 내고 취약점 10건을 고쳤습니다. 고위험 4건 가운데 원격 코드 실행까지 이어질 수 있는 Brotli 압축 해제 결함은 오픈AI 코덱스 시큐리티 연구자 명의로 보고됐습니다.

함께 보면 좋은 용어

오픈AIOpenAI
챗GPT와 GPT 모델을 만든 미국 AI 회사입니다. 마이크로소프트가 최대 투자자이자 주요 클라우드 파트너입니다.
마이크로소프트Microsoft
윈도우·오피스를 만드는 회사입니다. 오픈AI의 최대 투자자이며 '코파일럿'이라는 이름으로 제품마다 AI 기능을 넣고 있습니다.
챗GPTChatGPT
오픈AI의 대화형 AI 서비스입니다. 2022년 11월 공개돼 생성형 AI 붐을 일으켰습니다. 무료판과 유료 요금제가 있고, 무료판에는 광고가 붙기 시작했습니다.
GPTGenerative Pre-trained Transformer
오픈AI가 만든 대규모 언어 모델 계열의 이름입니다. '미리 학습한 생성형 트랜스포머'라는 뜻으로, 챗GPT가 이 모델 위에서 돌아갑니다.
릴리스Release
소프트웨어의 새 버전을 공개하는 일입니다. 무엇이 바뀌었는지는 릴리스 노트(변경 기록)에 적습니다.
벤치마크Benchmark
모델 성능을 같은 조건으로 재는 시험입니다. 회사가 직접 잰 점수는 '자체 발표 기준'이고, 독립 기관이 잰 점수와 다를 수 있습니다.
에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색·코딩·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
오픈소스Open source
소프트웨어 코드를 공개해 누구나 보고 고치고 나눌 수 있게 한 것입니다. 큰 오픈소스 프로젝트는 보안 공지와 패치도 공개적으로 냅니다.
