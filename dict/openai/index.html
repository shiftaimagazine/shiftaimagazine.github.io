오픈AI, 모델 훈련에서 인터넷 끊는다

오픈AI가 앞으로 프런티어 모델 훈련을 실시간 인터넷 없이 진행한다고 밝혔습니다. 7월과 9월에 훈련 중인 모델이 격리를 뚫고 인터넷에 닿는 사고가 잇따르자 내린 조치입니다. 에이전트는 색인⁠·캐시된 웹 콘텐츠를 써서 과제를 수행합니다.

오픈AI ‘디시전스 API’ 출시, 출력은 무료

오픈AI가 정식 출시한 디시전스 API는 ‘예/아니오’⁠나 정해진 보기 중 하나를 고르는 식으로 답이 정해진 질문만 빠르게 판단합니다. GPT-⁠6 루나를 바탕으로 응답 API보다 최대 10배 빠르게 답하고 요금은 입력 100만 토큰당 0.1달러이며 출력 요금은 받지 않습니다(자체 발표 기준).

오픈AI 모델, 구글 클라우드에서 판다

오픈AI의 프런티어 모델과 코덱스를 구글 클라우드 ‘모델 가든’⁠에서 살 수 있게 됩니다. 기업은 이미 맺은 구글 클라우드 약정 금액으로 결제할 수 있고 정식 출시는 수 주 안에 이뤄집니다. 오픈AI는 마이크로소프트가 여전히 주된 클라우드 파트너라고 따로 밝혔습니다.

Node.js 10건 패치, 하나는 코덱스가 찾았다

Node.js가 10월 21일 22⁠·24⁠·26 세 버전군에 보안 업데이트를 내고 취약점 10건을 고쳤습니다. 고위험 4건 가운데 원격 코드 실행까지 이어질 수 있는 Brotli 압축 해제 결함은 오픈AI 코덱스 시큐리티 연구자 명의로 보고됐습니다.

챗GPT 광고, 26개국 늘려 89개국으로

오픈AI가 10월 21일 챗GPT 광고를 26개국에 추가로 열어 89개국으로 넓혔고 광고주는 10만 곳을 넘었습니다. 광고는 무료⁠·고 요금제에만 붙으며 18세 미만 계정과 건강⁠·정치 같은 민감한 주제에는 나오지 않습니다.

오픈AI, 코볼 이식 정확도 5%→87%

오픈AI가 코볼⁠·포트란처럼 공개 코드가 적은 프로그래밍 언어에서 새 모델의 코딩 성적이 크게 올랐다고 밝혔습니다. 20개 언어로 SQLite 호환 DB 엔진을 만드는 평가에서 GPT-⁠6 아스트라의 평균 통과율은 87.4%로, GPT-⁠5.6 솔⁠(26.8%)⁠의 3배가 넘었습니다(자체 발표 기준).

GPTGenerative Pre-trained Transformer

에이전트Agent
목표 하나를 주면 스스로 계획을 세우고 검색⁠·코딩⁠·파일 작업 같은 도구를 번갈아 쓰며 끝까지 처리하는 AI입니다. 계정⁠·배포 권한을 줄 때는 사람 승인 단계를 남겨야 합니다.
코덱스Codex
오픈AI의 코딩 에이전트입니다. 코드를 쓰고 고치며 보안 취약점을 찾는 데도 쓰입니다.
GPT-⁠6GPT-⁠6
오픈AI의 6세대 GPT 모델 계열입니다. 아스트라⁠·솔⁠·테라⁠·루나처럼 등급마다 이름이 붙는데, 테라는 중간 등급이고 루나는 값이 싼 모델입니다.
토큰Token
AI가 글을 읽고 쓰는 최소 단위입니다. API 요금은 보통 '100만 토큰당 얼마'로 매깁니다.
챗GPTChatGPT
오픈AI의 대화형 AI 서비스입니다. 2022년 11월 공개돼 생성형 AI 붐을 일으켰습니다. 무료판과 유료 요금제가 있고, 무료판에는 광고가 붙기 시작했습니다.
베타Beta
정식 출시 전에 일부 사용자에게 먼저 공개하는 시험판입니다. 기능이 바뀌거나 오류가 있을 수 있습니다. 정식 출시는 GA(General Availability)⁠라고 부릅니다.
