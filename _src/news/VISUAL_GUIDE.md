# SHIFT AI 이미지·시각 자료 규칙 (2026-10-29~)

글을 쓸 때(사람이든 예약 작업이든) 이 문서를 따릅니다. 계기: 10/29 칼럼 5편에 사이트 로고, 주제와 상관없는 기사 사진(구글 서비스 정리 칼럼에 마인크래프트)이 대표 이미지로 들어간 일.

## 1. 대표 이미지는 그 글의 주제여야 합니다
- **사이트 로고(img/logo*.webp)는 어떤 글의 대표 이미지로도 쓰지 않습니다.** assemble.py 가 막습니다.
- 기사: 원문 쪽 실제 이미지(공식 대표 이미지 → 원문 og:image → 원문 화면 캡처, fetch_images.py 가 자동). AI 생성 이미지는 쓰지 않습니다.
- 칼럼: 두 가지 중 하나입니다.
  1. **정말 한 기사를 바탕으로 쓴 칼럼**이면 `rel` 에 그 기사 id 를 넣고 그 기사 사진을 씁니다(화면에 '바탕이 된 기사'로 나옵니다).
  2. 여러 회사·서비스를 비교하거나 정리하는 칼럼처럼 바탕 기사가 없으면 `rel: null` 로 두고 **표지 인포그래픽**을 만들어 `image` 에 넣습니다(3장). 관련 기사는 본문의 링크 상자로 겁니다.
- 아무 기사나 rel 로 붙여 그 사진을 빌려 쓰지 않습니다. 글과 사진이 따로 놀면 독자가 바로 알아챕니다.
- 대표 이미지에는 출처(`credit`)를 적습니다. 직접 만든 표지는 "그림: SHIFT AI · (자료 출처) 기준".

## 2. 비교·정리 글에는 시각 자료를 넣습니다
글로만 길게 늘어놓지 말고 아래 블록을 씁니다(칼럼 body 에 넣는 JSON, 화면은 app.js). 그림 파일이 아니라 HTML 이라 검색엔진이 글자를 읽고 어두운 화면·휴대폰에서도 맞게 보입니다.

| 블록 | 언제 | 형식 |
|---|---|---|
| `table` | 숫자·항목 비교의 기본 | `{"table": {"head": [...], "rows": [[...]], "note": "출처·기준일"}}` |
| `bars` | 금액·크기를 한눈에 비교 | `{"bars": {"t": 제목, "sub": 부제, "groups": [색 순서], "rows": [[묶음, 항목, 숫자, 보이는 값]], "note": ...}}` — 묶음(회사)마다 색이 고정, 값은 막대 옆 글자로 꼭 표시 |
| `matrix` | 기능이 되나/안 되나 | `{"matrix": {"t", "head": ["", A, B, ...], "rows": [[기능, o, p, x, -, ?]], "note"}}` — o 무료로 됨 · p 무료는 조금만 · x 유료부터 · - 기능 없음 · ? 공식 자료로 확인 못 함 (기호와 글자 설명이 함께 나옴) |
| `cards` | 서비스·도구 목록(서비스 지도) | `{"cards": {"t", "sub", "items": [{"n": 이름, "d": 설명 문장, "b": 요금제 표시}]}}` |
| `steps` | 날짜순 변화(연표) | `{"steps": {"t", "items": [[날짜, 내용]], "note"}}` |
| `link` | 관련 기사·튜토리얼·도구로 보내기 | `{"link": {"k": "관련 기사", "t": 제목, "u": "/news/<id>/", "d": 설명}}` — 사이트 안 주소만 |

- 색은 정해진 순서(파랑·주황·청록·노랑)로 묶음에 붙고 바뀌지 않습니다. 같은 글 안에서 회사 순서를 표지·막대와 맞춥니다(예: 챗GPT·클로드·제미나이·그록).
- 숫자는 공식 자료에서 확인한 것만. 환산 값은 환율과 기준일을 `note` 에 적습니다(AI 요금 계산기와 같은 환율 `ai_prices.json` fx).
- 확인하지 못한 칸은 비우거나 지어내지 말고 `?` 로 표시하고 note 에 이유를 적습니다.

## 3. 표지 인포그래픽 만들기
1. `_src/news/covers.json` 에 항목을 추가합니다: `{"id": 칼럼 id, "kicker": 작은 제목, "title": "두 줄\n제목", "tiles": [[이름, "줄1\n줄2"], ...(2~4개)], "foot": 아래 한 줄}`. 제목이 길면 `"size": 70`.
2. `python3 _src/covers.py <칼럼 id>` → `img/cover/<칼럼 id>.webp`(1280×720).
3. 칼럼에 `"image": {"src": "img/cover/<id>.webp", "credit": "그림: SHIFT AI · … 기준", "alt": 제목}` 을 넣고 `rel: null`.
4. 만든 그림을 열어 보고(글자 넘침·잘림) 올립니다.
- 회사 로고, 제품 화면을 흉내 낸 그림, 실존 인물 사진은 넣지 않습니다. 글자와 색 띠만 씁니다.
- 대표 사진이 꼭 필요한 기사(제품 발표 등)는 표지 대신 원문의 공식 이미지를 씁니다.
