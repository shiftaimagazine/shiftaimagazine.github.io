# SHIFT AI 튜토리얼 쓰는 법 (2026-10-27~)

튜토리얼은 `_src/news/D_tutorials.json` 의 `tutorials` 배열 맨 뒤에 하나씩 넣는다(목록은 사이트가 날짜순으로 정렬). 기사와 같은 원칙: **사실은 공식 문서·공식 GitHub·도움말에서 확인한 것만**, 다른 사람 블로그·유튜브·언론 기사 문장은 옮기지 않는다. 말투는 **습니다체**, AI 티 나는 표현 금지(BRIEF.md 2장). 다 쓰면 `_src/humanize/HUMANIZE.md` 규칙으로 다듬는다(`shift_humanize.py export --batch 이름 --kinds tutorial --ids t-...` → after.txt 고치기 → `apply --batch 이름`). 끝 주의 단락을 "~해야 합니다"로 줄줄이 닫거나 도입의 주의를 끝에서 되풀이하지 않는다. 이미지는 실제 화면 캡처(직접 실행해서 찍은 것)·공식 이미지·위키미디어 공용 사진만, AI로 만든 그림은 쓰지 않는다.

## 한 편의 짜임 (화면에 이 순서로 나온다)
1. 제목·한두 문장 소개(deck) — 제목은 "무엇을 · 몇 단계/몇 개" 가 보이게.
2. 정보 줄: 주제 · 도구 · 난이도, 읽는 데 N분(자동 계산), STEP N개 / 프롬프트 N개, 따라 하는 시간
3. 대표 사진(tutorial_links.json TFIG)
4. **이 글에 담긴 것**: 단계 목차(자동) + 따라 하는 시간
5. **바쁘면 이것만 (Quick Start)**: `quick.lines` 세 줄과 `quick.links`(공식 주소)
6. **통째로 맡기는 프롬프트**(선택): `master` — Claude Code 같은 에이전트에 붙여 넣으면 이 글의 단계를 대신 해 주는 프롬프트. 역할·맥락·입력·작업·제약·출력·검증 순서로 쓴다.
7. 필요한 것(tools) / 걸리는 시간(time) / 왜 필요한가요(why), 도입 문단(intro)
8. 단계(items): "STEP 1. 제목 · 3분" + 첫 줄 목적 한 문장(d) + 본문. d 는 단계마다 같은 틀("이 단계에서는 ~", "~하는 프롬프트입니다")로 시작하지 않게 문장 모양을 바꾼다(2026-10-29, AI 티 C-6)
9. 보너스 체크리스트(bonus, 선택)
10. **솔직히 한계**(limits): 이 방법이 안 되는 경우, 비용·보안 주의 2~4줄
11. **공식 자료**(sources): 확인에 쓴 공식 문서 주소

## 필드
```json
{
  "id": "t-영문-슬러그", "date": "YYYY-MM-DD",
  "cat": "주제 하나",                       // 업무 | 자동화 | 스킬·MCP | 비용 절약 | 영상·이미지 | AI 답 검증 | 보안·개인정보 | 공부·리서치 | 콘텐츠·커리어
  "tool": ["Claude Code"],                  // 도구 태그(목록 '도구' 버튼). 예: Claude Code, Claude, ChatGPT, 제미나이, n8n, 크롬, 엑셀·시트
  "kind": "steps",                          // steps = 따라 하는 단계(STEP), prompts = 프롬프트 모음
  "level": "입문", "time": "20분",           // time = 따라 하는 데 걸리는 시간
  "tools": "필요한 것 한 문장",
  "title": "...", "deck": "1~2문장", "why": "1~2문장", "intro": "도입 문단",
  "quick": {"lines": ["바쁘면 이것만 1", "2", "3"], "links": [["공식 GitHub", "https://..."]]},
  "master": {"tool": "Claude Code", "prompt": "역할: ...\n맥락: ...\n입력: ...\n작업: ...\n제약: ...\n출력: ...\n검증: ..."},
  "items": [{
    "h": "단계 제목", "time": "3분",
    "d": "이 단계의 목적 한 문장(매번 같은 틀로 시작하지 않기)",
    "how": "본문 문단", "more": ["문단", "..."],
    "term": [["용어", "쉬운 풀이"]],
    "code": [{"label": "터미널", "cmd": "실행할 명령", "ok": "성공하면 ~가 보입니다"}],
    "bad": "❌ 이렇게 말고", "good": "✅ 이렇게",
    "table": {"head": ["윈도우", "맥"], "rows": [["...", "..."]]},
    "prompt": "복사해서 쓰는 프롬프트", "example": {"in": "...", "out": "..."},
    "img": {"src": "img/ph/...webp", "alt": "...", "cap": "무엇을 찍은 화면인지 · 출처"}
  }],
  "bonus": {"title": "...", "items": ["..."]},
  "limits": ["솔직히 한계 1", "2"],
  "sources": [["공식 문서 이름", "https://..."]],
  "cover": {"tag": "SHIFT AI 무료 정리본", "line": "썸네일 한 줄(20자 안팎)"}
}
```
- 명령어(`code.cmd`)는 직접 실행해 보고 확인한 것만 쓴다. 실행 못 했으면 공식 문서에 있는 그대로 쓰고 `ok` 는 문서가 말하는 결과만.
- 가격·한도·버전 숫자는 공식 페이지에서 확인한 날짜 기준으로 쓰고, 바뀔 수 있다고 한계에 적는다.
- 새 튜토리얼 썸네일: TFIG 에 실제 사진을 넣고 `python3 _src/tut_thumbs.py t-아이디`.
