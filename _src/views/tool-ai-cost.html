AI 요금 계산기

챗GPT·클로드·제미나이 같은 AI를 API로 쓰면 한 달에 얼마가 나오는지, 회사별 공식 가격표로 계산해 원화로 비교합니다.

무료공식 가격표 기준가격 기준일 확인 중

1어떻게 쓸지 고르기

토큰은 AI가 글을 세는 단위입니다. 한글은 모델마다 세는 방식이 달라서 기본값을 넉넉하게 1글자 ≈ 1토큰으로 잡았습니다. 오픈AI 최신 토크나이저(o200k)로 SHIFT 기사 2만 8천 자를 세어 보니 한글 약 1.7자가 1토큰이었습니다.

2한 달 요금 비교

API 요금(쓴 만큼 내는 값)입니다. 챗GPT 플러스·클로드 프로 같은 월 구독료와는 다릅니다. 세금, 이미지·음성·검색 같은 추가 기능 요금, 회사별 할인·무료 사용량은 넣지 않았습니다. 실제로 결제하기 전에는 아래 공식 가격표를 꼭 확인하세요.

가격 출처 (회사 공식 가격표)

    자주 묻는 질문

    챗GPT 플러스·클로드 프로 같은 구독료도 계산되나요?

    계산하지 않습니다. 이 계산기는 쓴 만큼 내는 API 요금만 셉니다. 월 구독 요금제는 챗GPT·클로드·제미나이·그록 요금제 비교에 정리했습니다.

    가격은 어디서 가져오나요?

    오픈AI·앤트로픽·구글·xAI의 공식 가격표에서 확인한 값만 씁니다. 페이지 위에 가격 기준일이, 아래에 회사별 가격표 링크가 있습니다. 결제하기 전에는 공식 가격표를 다시 확인하세요.

    글자 수는 토큰으로 어떻게 바꾸나요?

    기본값은 한글 1글자 ≈ 1토큰으로 넉넉하게 잡았습니다. 모델마다 세는 방식이 다르며, 오픈AI 토크나이저(o200k)로 SHIFT 기사 2만 8천 자를 세어 보니 한글 약 1.7자가 1토큰이었습니다. 정확한 토큰 수를 알면 '토큰 수로'를 골라 직접 넣으세요.

    환율은 무엇을 쓰나요?

    한국자금중개가 고시한 미화 매매기준율을 기본값으로 씁니다. 기준일은 페이지 아래 가격 출처에 적혀 있고, 환율 칸에 다른 값을 넣으면 바로 다시 계산합니다.

    세금이나 이미지·검색 요금도 들어가나요?

    들어가지 않습니다. 부가세, 이미지·음성·웹 검색 같은 추가 기능 요금, 회사별 할인과 무료 사용량은 빼고 계산합니다.
