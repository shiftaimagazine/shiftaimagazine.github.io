개인정보처리방침

SHIFT AI(이하 "매거진")가 방문자와 주간 메일 구독자의 개인정보를 어떻게 다루는지 적었습니다. 시행일 2026년 10월 26일, 최근 변경 2026년 11월 11일.

변경 안내 (2026년 11월 4일 공지 · 11월 11일 시행)11월 11일부터 원하는 분께만 주간 메일 구독 신청을 받습니다. 구독하면 이메일 주소를 받아 메일 발송에만 쓰고, 발송은 Resend(미국)에, 신청 접수는 Cloudflare(미국)에 맡깁니다. 1번·3번·4번·5번을 새로 쓰거나 고쳤습니다. 구독하지 않으면 지금과 달라지는 것이 없습니다.
변경 안내 (2026년 10월 27일 공지 · 11월 3일 시행)11월 3일부터 어떤 글이 많이 읽히는지 보려고 방문 통계 도구 GoatCounter 를 씁니다. 쿠키를 쓰지 않고 IP 주소를 저장하지 않으며, 페이지별 방문 수 같은 집계 숫자만 남깁니다. 아래 2번 표에 추가했습니다.

1. 받는 정보

매거진은 회원 가입을 받지 않습니다. 글을 읽는 데 이름·이메일 같은 정보는 필요하지 않습니다. 주간 메일을 받고 싶은 분이 직접 신청할 때만 이메일 주소를 받습니다(2026년 11월 11일부터).

언제받는 정보쓰는 곳보관 기간
주간 메일을 구독할 때이메일 주소(필수). 발송 도구가 자동으로 남기는 신청·확인 시각, 메일 발송·전달·반송 기록주간 메일 발송, 구독 확인·해지 관리, 발송 오류 확인구독을 해지할 때까지(해지하면 지체 없이 발송 명단에서 뺌)
메일로 문의·제보·정정 요청을 보낼 때이메일 주소, 보내 주신 내용답장, 기사 정정답장을 마친 뒤 1년

구독은 두 번 확인합니다. 신청하면 그 주소로 확인 메일이 가고, 메일 안의 '구독 확정하기'를 눌러야 발송 명단에 들어갑니다. 확정하지 않은 주소는 명단에 넣지 않으며, 확인 링크는 2일 뒤 쓸 수 없게 됩니다. 만 14세 미만은 구독할 수 없습니다.

2. 웹사이트 운영에 쓰는 외부 서비스

서비스나라하는 일받을 수 있는 정보
GitHub Pages (GitHub, Inc.)미국웹사이트 호스팅접속 기록(IP 주소 등, 보안 목적)
Google Fonts (Google LLC)미국글꼴 제공접속 정보(IP 주소, 브라우저 정보)
GoatCounter (운영자 Martin Tournoij, 2026년 11월 3일부터)아일랜드(서버: 핀란드·독일)방문 통계본 페이지 주소, 들어온 경로(이전 사이트 주소), 브라우저·운영체제 이름, 화면 너비, 나라. IP 주소와 브라우저 정보 전체는 저장하지 않고, 재방문 구분을 위해 최대 8시간 메모리에만 둠. 쿠키 없음. 구독 칸에 넣은 이메일 주소는 보내지 않음

각 회사의 방침: GitHub 개인정보 보호정책 · 구글 개인정보처리방침 · GoatCounter 개인정보 방침. 이 웹사이트는 자체 쿠키를 쓰지 않습니다. 글자 크기 같은 화면 설정은 내 브라우저에만 저장됩니다.

3. 주간 메일을 맡기는 곳(처리 위탁⁠·국외 이전)

받는 곳나라맡기는 일넘어가는 정보언제·어떻게보관 기간
Resend (Plus Five Five, Inc.) · support@resend.com미국확인 메일·주간 메일 발송, 구독자 명단 보관, 구독 해지 처리이메일 주소, 발송·전달·반송 기록구독을 신청하고 확정할 때, 암호화된 통신으로구독 해지 또는 위탁이 끝날 때까지
Cloudflare Workers (Cloudflare, Inc.) · privacyquestions@cloudflare.com미국(전 세계 서버망)구독 신청 접수, 확인 링크 검사이메일 주소, 접속 정보(IP 주소, 브라우저 정보)구독 칸에서 신청하거나 확정 버튼을 누를 때, 암호화된 통신으로매거진은 따로 저장하지 않음. 접속 기록은 Cloudflare 정책에 따름

각 회사의 방침: Resend 개인정보처리방침 · Cloudflare 개인정보처리방침. 국외 이전을 원하지 않으면 구독하지 않으시면 됩니다. 이 경우에도 웹사이트 이용에는 제한이 없습니다.

4. 동의하지 않을 권리와 지우는 방법

  • 구독을 위한 이메일 수집·이용과 국외 이전에 동의하지 않아도 됩니다. 동의하지 않으면 주간 메일을 받을 수 없을 뿐, 웹사이트의 글은 모두 그대로 읽을 수 있습니다.
  • 모든 주간 메일 아래의 '구독 해지' 링크로 언제든 해지할 수 있습니다. 해지하면 발송 명단에서 바로 빠집니다. 같은 주소로 다시 메일이 가지 않도록 해지 기록이 발송 도구에 남을 수 있는데, 완전히 지워 달라고 요청하시면 지체 없이 지웁니다.
  • 구독자 명단은 발송 도구의 관리자 계정으로만 볼 수 있습니다. 명단을 다른 곳에 팔거나 넘기지 않습니다.
