안티그래비티 /teamwork 성과 공개
구글 리서치가 11월 13일 안티그래비티의 /teamwork 성과를 공개했습니다. 여러 에이전트가 서로 검증하는 방식으로 수학 추측 증명과 코드 재작성에 쓰였고, 외부 연구자와 개발자는 제미나이 4 모델로 오늘부터 쓸 수 있습니다.
판정 이유: 성과는 구글이 직접 낸 보고이고 일부 패턴은 아직 제공 전이며 요금은 원문에 없습니다.

제미나이 4 하이드로젠 공개
구글이 11월 12일(미국 시각) 제미나이 4 하이드로젠을 내놨습니다. 구글 검색에 모든 사용자 대상으로 적용되고 API 값은 입력 100만 토큰당 1.50달러, 출력 100만 토큰당 7.50달러입니다.
판정 이유: 속도와 점수는 모두 구글 자체 발표이고 요금제별 사용 한도는 원문에 없습니다.

제미나이 결정 API, 질문 1,000개를 한 번에
구글 딥마인드가 11월 11일(미국 시각) 제미나이 결정 API를 공개했습니다. 닫힌 질문을 한 번에 최대 1,000개 처리하고 입력 100만 토큰당 0.10달러이며 출력 토큰은 과금하지 않습니다.
판정 이유: AI 스튜디오 무료 단계에서 써 볼 수 있고 입력 값이 100만 토큰당 0.10달러로 적혀 있습니다.

제미나이 인텔리전스, 픽셀 10·모토로라로
구글이 11월 10일(미국 시각) 제미나이 인텔리전스(Gemini Intelligence)를 모토로라 시그니처 27과 픽셀 10 계열로 넓히고 램블러, 위젯 만들기 같은 새 기능을 발표했습니다. 한국 출시 일정은 원문에 없습니다.

클로드 페이블 5.2·미토스 5.2 공개
앤트로픽이 11월 9일 클로드 페이블 5.2와 미토스 5.2를 공개했습니다. 두 모델은 같은 기반 모델이고, 페이블은 모든 이용자가 쓰며 API 값은 입력 100만 토큰당 8달러, 출력 40달러입니다.
