리퀴드 AI LFM3, 약 1GB 오픈 모델 6종

텍스트⁠·이미지⁠·음성⁠·옴니⁠·의사결정 모델 · 허깅페이스에 가중치 공개

리퀴드 AI(Liquid AI)⁠가 10월 27일 소형 모델 묶음 LFM3를 공개했습니다. 텍스트, 이미지⁠·영상, 음성, 이 셋을 함께 다루는 옴니, 의사결정용 모델까지 6종이고 모두 같은 기반 모델 LFM3-1.7B-Base에서 갈라져 나왔습니다. 가중치는 허깅페이스에 올라왔습니다.

SHIFT 판정 · 지켜보세요텍스트 모델 지원 언어에 한국어가 없고 성능 점수는 모두 회사가 직접 잰 것입니다.
오늘 바로 해 보세요허깅페이스의 LFM3-VL-⁠2B 모델 카드를 열어 한국어를 포함한 지원 언어 16개와 라이선스, 실행 방법을 확인해 보세요.

같은 뿌리에서 나온 여섯 모델

텍스트 모델 LFM3-1.7B는 22조 개 토큰으로 사전 학습했고 한 번에 256K 토큰까지 읽습니다. 이미지와 영상을 보는 LFM3-VL-⁠2B는 19억, 말을 듣고 말하는 LFM3-Audio-⁠2B는 20억, 세 가지를 함께 다루는 LFM3-Omni-⁠2B는 22억 파라미터입니다. 의사결정 모델로 묶인 d1-2B와 d1-Omni-⁠2B 가운데 d1-Omni-⁠2B는 음성까지 입력으로 받고 43개 언어의 말소리를 구별합니다.

기기 안에서 돌리기 위한 숫자들

텍스트 모델은 4비트로 줄이면 약 1GB에 들어갑니다. 회사가 세 기기에서 잰 해독 속도는 다음으로 빠른 모델보다 1.8~2.8배 빨랐습니다(자체 발표 기준). 128K 토큰 문맥을 다 채울 때 필요한 KV 캐시는 1.6GB로 큐원3.5-4B의 4.3GB, 미니CPM5-2B의 5.6GB보다 작고 음성 모델이 첫 토큰을 내기까지는 짧게는 50밀리초가 걸립니다. 실행 도구 목록에는 llama.cpp, MLX, vLLM, 올라마⁠(Ollama), LM 스튜디오가 들어 있습니다.

점수는 회사가 직접 잰 것입니다

LFM3-1.7B는 도구 호출 평가 BFCL V4에서 71.39점을 받았고 큐원3.5-9B는 62.83점이었습니다(자체 발표 기준). 웹에서 일을 처리하는 WebArena-Verified에서도 38.42점으로 큐원3.5-9B의 28.94점보다 높았습니다. 이전 세대 LFM2.5-2.6B보다 파라미터를 35% 적게 쓰면서도 성능은 앞선다고 회사는 설명했습니다. LFM3-VL-⁠2B는 시각 평가 62개의 평균이 71.4점으로 젬마 4 12B의 71.7점과 비슷했습니다. 의사결정 모델 d1-2B는 회사 평가인 디시전 벤치에서 85.2점을 받아 이전 모델 d1-3B⁠(83.6점)⁠를 넘었습니다.

서버와 미세 조정 도구까지 함께 나왔습니다

가중치 말고도 리퀴드 AI 플레이그라운드와 API, 실시간 추론 파이프라인 RIPL로 모델을 쓸 수 있습니다. 출시 협력사로는 AMD, Arm, 인텔(OpenVINO), 엔비디아, 퀄컴, 오픈라우터(OpenRouter), 버셀⁠(Vercel), 앰버렐라(Ambarella)⁠가 이름을 올렸습니다. 엔비디아 B300 서버에서 동시 요청 1,024개를 받으면 텍스트 모델은 하루 약 36억 토큰을 처리하고 VL 모델은 초당 1만 2,000토큰 넘게 처리합니다(자체 발표 기준). 모든 모델은 GPU 한 장으로 미세 조정할 수 있고 회사는 풍력 발전기 예제에서 SFT와 GRPO를, 로봇 예제에서 랭크 32 LoRA를 썼습니다.

한국어와 라이선스는 모델마다 다릅니다

VL 모델 카드는 지원 언어 16개에 한국어를 넣었지만 텍스트 모델의 지원 언어 목록에는 한국어가 없습니다. 오디오 모델은 18개 언어를 지원한다고 적었는데 목록은 공개하지 않았습니다. 라이선스는 ‘LFM Open License v1.0’⁠이고 모델 카드에는 상업적 이용 조건이 따로 적혀 있지 않습니다. llama.cpp의 VL 모델 지원은 아직 검토 중이며 영상 입력은 되지 않습니다.
