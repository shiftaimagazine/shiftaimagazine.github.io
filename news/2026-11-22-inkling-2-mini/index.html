인클링 2 미니, 32GB 맥에서 로컬 실행

씽킹 머신스 랩의 아파치 2.0 공개 모델 · 총 264억⁠·활성 34억 파라미터 · 컨텍스트 100만 토큰

씽킹 머신스 랩(Thinking Machines Lab)⁠이 11월 20일 인클링 2 미니(Inkling 2 Mini)⁠를 허깅페이스에 공개했습니다. 총 264억 파라미터 가운데 34억이 활성화되는 혼합 전문가⁠(MoE) 구조이고 텍스트와 이미지를 받아 텍스트를 내놓으며 라이선스는 아파치 2.0입니다. 컨텍스트 창은 최대 100만 토큰입니다.

SHIFT 판정 · 지켜보세요로컬 실행은 되지만 한국어는 지원 언어에 이름이 없고 속도는 런타임과 기기마다 다릅니다.
오늘 바로 해 보세요메모리 32GB 이상 맥이 있다면 모델 카드에 안내된 올라마⁠(Ollama) 등으로 받아 한국어 질문 하나를 넣고 답이 어떤지 확인해 보세요.

  • 체크포인트 약 20GB. 메모리 32GB 이상 애플 실리콘이나 DGX Spark 1대에서 로컬 추론을 지원합니다

층을 세 번 되풀이하는 구조

모델 카드는 인클링 2 미니를 멀티모달 자기회귀 루프형 트랜스포머로 소개합니다. 24개 층의 디코더 전용 트랜스포머에서 가운데 12개 층이 같은 가중치로 세 번 돌아가고 토큰마다 128개 전문가 중 8개가 선택됩니다. 되풀이할 때마다 활성 파라미터가 약 10억 개 늘어서 토큰당 유효 활성 파라미터는 54억 개가 됩니다. 씽킹 머신스는 이 모델이 자사가 공개한 첫 루프형 트랜스포머라고 적었습니다.

로컬에서 돌릴 수 있는 사양

체크포인트는 NVFP4와 MXFP8 혼합 정밀도로 약 20GB입니다. 카드가 지원 환경으로 꼽은 것은 엔비디아 DGX Spark 1대와 메모리 32GB 이상의 애플 실리콘 기기(맥북, 맥 미니, 맥 스튜디오)⁠이며 다른 GPU는 VRAM 32GB 이상을 권합니다. 실행 도구로는 트랜스포머스, vLLM, SGLang, 언슬로스⁠(GGUF), llama.cpp, 올라마, 도커 모델 러너가 올라 있습니다. vLLM에서는 pip install vllm 뒤에 vllm serve 명령으로 모델 이름을 넣으면 OpenAI 호환 주소가 열립니다.

성능표에 실린 숫자와 비교 대상

카드의 성능표는 코딩, 에이전트 작업, 이미지 이해, 추론, 안전 항목을 한꺼번에 담았고 비교 대상은 젬마 4 31B, 뮤즈 글리머, 큐원 3.8-27B, 네모트론 3.5 슈퍼 VL입니다. 같은 카드는 인클링 2 미니가 상위 모델 인클링 2 스몰보다 대부분의 평가에서 낮다고 적었습니다.

한국어와 한계는 카드에서 따로 확인해야 합니다

언어 항목은 '영어, 일반 다국어 지원'이어서 한국어는 이름이 없고 영어 밖에서는 품질이 낮을 수 있습니다. 카드는 중국어 시험에서 문장이 끊기고 언어가 섞이는 것을 관찰했다고 적었습니다. 추론이 길게 맴도는 일이 있어서 특히 코드 디버깅에서는 출력 토큰과 에이전트 턴에 상한을 두라고 권합니다. 에이전트로 쓰면 파일을 확인 없이 지우거나 덮어쓰는 행동을 할 수 있고 작업 결과를 정확하게 보고하지 않을 수도 있습니다. 루프형 모델을 지원하는 로컬 런타임은 새것이라 속도는 런타임과 하드웨어에 따라 달라집니다.
