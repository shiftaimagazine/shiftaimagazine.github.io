스탠퍼드대 등 연구진이 문서 모음 전체를 읽어 질문마다 16개의 메모리 토큰으로 바꿔 주는 모듈 메모릴라(Memorilla)⁠를 프로젝트 페이지에 공개했습니다. 언어 모델의 가중치는 그대로 두고 이 모듈만 학습하며, 연구진은 8개 벤치마크 평균 점수가 비교한 방식 가운데 가장 높았다고 적었습니다(자체 발표 기준).

문서는 한 번만 저장하고 질문마다 읽어 냅니다

메모릴라는 기억하는 일과 떠올리는 일을 나눕니다. 고정된 인코더가 문서를 하나씩 임베딩으로 저장해 두고, 질문이 들어오면 학습된 메모리 슬롯이 질문과 저장소 전체를 읽어 메모리 토큰을 내놓으며, 언어 모델은 이 토큰을 질문과 함께 읽습니다. 문서를 새로 넣는 비용은 인코더를 한 번 통과시키는 것이고 모델이 받는 토큰 수는 늘 같으며, 지도학습 실험에서는 16개였습니다. 학습은 메모리 모듈만 하고 위키백과 문장 바꿔 쓰기, 일반 질의응답과 요약, 벤치마크별 학습 데이터 순서로 단계를 밟았습니다. 모든 실험은 큐원 인코더와 큐원 디코더를 짝지어 텍스트만 다뤘습니다.

토큰은 줄고 점수는 대체로 올랐지만 한 곳은 졌습니다

주된 실험은 큐원3-8B(Qwen3-8B)⁠를 고정해 놓고 했습니다. NarrativeQA에서 문서 토큰은 전체 컨텍스트와 비교해 4,000배 넘게 줄었고, 문서 512개를 H100 80GB 한 장에서 배치 크기 1로 처리한 지연은 0.74초로 전체 컨텍스트의 19.9초보다 27배 낮았습니다. FactKG에서는 전체 컨텍스트보다 문서 토큰이 108배 적었고 트리비아QA에서는 743배 적었습니다. 8개 벤치마크 전체로 보면 RAG-50보다 문서 토큰이 기하평균 113배 적었다고 합니다. 반대로 PubMedQA는 전체 컨텍스트와 비교 방식 LLMLingua-⁠2보다 점수가 낮았습니다. 비교한 방식과 점수는 표에 정리했고, PersonaMem-v2와 PersonalizationV4는 벤치마크 전용 추가 미세조정을 받았다고 표 각주에 적혀 있습니다.

게임 에이전트 실험과 연구진이 적은 한계

텍스트 게임 환경 TextWorld에서는 큐원3-4B 에이전트에 메모리 토큰 8개를 붙였더니 평균 성공률이 18.6%에서 24.2%로, 세 번 시도 안에 끝낸 게임 비율이 25.0%에서 37.5%로 올랐습니다. 이 시험은 게임 한 묶음에서 한 판 최대 50턴까지만 다룹니다. 한계 항목에서 연구진은 정확한 이름 같은 세부 정보가 사라질 수 있다고 적었습니다. 메모리를 언어 모델의 입력 임베딩에 쓰기 때문에 가중치가 공개된 모델이 있어야 하고 모델마다 메모리 모듈을 따로 학습해야 하며, 다른 모델 계열과 텍스트 밖의 자료, 생의학 밖의 코드와 과학 분야는 아직 시험하지 않았습니다. 코드와 가중치, 논문 주소는 프로젝트 페이지에 실려 있고 라이선스는 페이지에서 확인되지 않았습니다.
