엔비디아 Nemotron 3.5 Transcribe 공개…한국어 포함 40개 언어 받아쓰기

오픈 웨이트 음성 모델 · 1시간 녹음, 화자 8명까지 구분 · 학습 라벨 Granary v2도 공개

SHIFT 판정 · 써볼 만해요허깅페이스에 상업적 이용이 가능한 가중치로 공개됐고 한국어 품질 등급이 'Leading'입니다.
오늘 바로 해 볼 것허깅페이스의 Nemotron 3.5 Transcribe 데모에 개인정보가 없는 짧은 한국어 녹음을 올려 지금 쓰는 받아쓰기 도구와 결과를 비교해 보세요.

무엇받아쓰기·번역·화자 구분 오픈 웨이트 음성 모델

세 줄 요약
  • 40개 언어 받아쓰기. 한국어는 품질 등급 ‘Leading’
  • 1시간 녹음, 화자 8명. 녹음 파일용이고 실시간 스트리밍용은 아님
  • Granary v2. 48개 언어, 음성 463,062시간 분량 라벨

엔비디아(NVIDIA)가 10월 28일(미국 시각) 음성 모델 Nemotron 3.5 Transcribe를 허깅페이스와 모델스코프에 공개했습니다. 녹음된 말의 받아쓰기와 화자 구분, 번역, 녹음 내용에 관한 질문 답변을 모델 하나가 맡습니다. 학습에 쓴 음성 라벨 데이터 Granary v2도 함께 나왔습니다.

한국어는 가장 높은 등급에 들어 있습니다

모델 카드의 언어 표에서 한국어는 받아쓰기, 영어와 오가는 번역, 여러 화자 받아쓰기, 언어가 섞인 말 받아쓰기에 모두 표시돼 있고 품질 등급은 가장 높은 ‘Leading’입니다. 받아쓰기는 40개 언어, 영어와 오가는 번역은 31개 언어, 화자 구분은 13개 언어에서 됩니다. 녹음 내용 이해와 말로 하는 지시 따르기는 영어로만 평가했다고 모델 카드에 적혀 있습니다.

지시문 한 줄로 결과물이 달라집니다

같은 회의 녹음이라도 “Transcribe this recording and label each speaker.”라고 지시하면 화자를 붙인 받아쓰기가, “What decisions were made in this meeting?”이라고 물으면 회의에서 정한 일이 나옵니다. 잘 틀리는 전문 용어는 지시문에 후보로 적어 줄 수 있습니다. 엔비디아가 든 의료 녹음 사례에서는 지시문에 영어와 라틴 문자를 적어 준 것만으로 단어 오류율이 30.8%에서 23.8%로 내려갔고 미세 조정까지 하자 11.8%가 됐습니다(자체 발표 기준). 이 미세 조정에는 GB300 GPU 한 장으로 약 14시간이 걸렸습니다.

오픈 모델 비교에서 받은 점수

영어 받아쓰기 평가의 평균 단어 오류율은 5.33%로 오픈 웨이트 모델 가운데 1위였습니다. 7개 언어 평균은 4.62%, 긴 녹음 평균은 10.98%로 비교한 오픈 모델 중 가장 낮았고 21개 언어 화자 구분 평가에서도 오류율 18.26%로 시스템 14개 가운데 가장 낮았습니다(자체 발표 기준). 전체 파라미터는 300억 개지만 토큰마다 쓰는 것은 약 40억 개입니다. 엔비디아 블랙웰 서버 GPU 한 장으로 100시간 분량 녹음을 3분 안에 처리했는데, 이 측정에는 NVFP4 양자화 버전을 썼습니다.

상업적 이용과 학습 데이터

모델은 OpenMDW-1.1 라이선스로 공개됐고 모델 카드는 상업적·비상업적 용도 모두에 쓸 수 있다고 적었습니다. 함께 나온 Granary v2는 16개 말뭉치의 음성 463,062시간에 붙인 받아쓰기·번역 라벨로, 1판의 25개 언어에서 48개 언어로 늘었고 한국어도 들어 있습니다. 저장소에는 라벨 목록만 있고 음성 파일은 들어 있지 않습니다. 모델은 녹음 파일을 처리하는 용도여서 실시간 스트리밍 받아쓰기는 지원하지 않습니다.

생각해 볼 질문회의 녹음을 받아쓸 때 가장 자주 틀리는 부분은 무엇인가요?
