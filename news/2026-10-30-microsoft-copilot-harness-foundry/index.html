마이크로소프트(Microsoft)⁠가 10월 28일(미국 시각) 마이크로소프트 코파일럿 하네스(Microsoft Copilot harness)⁠를 기업 개발자에게 열었습니다. 하네스는 AI 모델 바깥에서 지시와 맥락, 실행 환경, 통제 장치를 대 주는 층으로, 깃허브 엔지니어링 팀이 만들어 회사 전체가 쓰고 있습니다. 이번에는 마이크로소프트 파운드리(Microsoft Foundry)⁠의 에이전트 서비스에서 공개 미리 보기로 나왔습니다.

SHIFT 판정 · 지켜보세요파운드리 기업 개발자용 공개 미리 보기이고 12월 1일부터는 사용량 요금이 붙습니다.
오늘 바로 해 보세요깃허브 코파일럿을 쓴다면 copilot-sdk 저장소 README에서 우리 팀 언어의 설치 명령과 BYOK 안내를 찾아 지금 환경에 맞는지 확인해 보세요.
  • 이미 쓰이던 엔진. 코파일럿 코드, 코파일럿 스튜디오, 깃허브 코파일럿 앱, CLI, VS Code
  • 모델 선택. 20개 넘는 최상위 모델과 BYOK
  • 요금. 12월 1일부터 vCPU 시간당 0.0994달러, GiB 시간당 0.0118달러

에이전트 반복과 샌드박스는 마이크로소프트가 맡습니다

하네스를 쓰면 에이전트가 판단하고 도구를 부르고 다시 판단하는 반복 과정과 코드를 돌리는 샌드박스를 마이크로소프트가 운영합니다. 개발자는 지시문과 스킬, 도구, 쓸 모델을 정합니다. 미리 보기에는 다시 쓸 수 있는 스킬, 파운드리 도구와 MCP 도구 연결(인증과 승인은 직접 설정), 파일⁠·코드 실행과 하위 에이전트, 소스 관리에 넣을 수 있는 에이전트 정의가 들어 있습니다. 이 하네스는 지금도 코파일럿 코드와 코파일럿 스튜디오, 깃허브 코파일럿 앱, CLI, VS Code에서 돌고 있습니다.

모델은 20개 넘게 고를 수 있습니다

하네스는 20개 넘는 최상위 모델과 직접 가져온 API 키(BYOK)⁠를 지원하고, 작업에 맞는 모델로 일을 나눠 보내는 기능도 있습니다. 모델을 바꿔도 하네스나 나머지 기술 구성은 그대로 쓸 수 있다는 것이 회사 설명입니다. 발표문에는 어떤 모델이 들어가는지 이름이 나오지 않습니다. 같은 엔진을 앱에 넣을 수 있는 깃허브 코파일럿 SDK는 파이썬, 타입스크립트, Go, .NET, 자바, 러스트용이 MIT 라이선스로 나와 있습니다.

12월 1일 전까지 하네스 실행은 무료입니다

파운드리의 하네스 요금은 12월 1일부터 쓴 만큼 받습니다. 그 전까지 하네스 실행 자체는 무료지만 모델 추론과 따로 요금이 붙는 도구⁠·서비스는 원래대로 청구됩니다. 12월 1일부터 샌드박스 컴퓨팅은 vCPU 시간당 0.0994달러, 메모리는 GiB 시간당 0.0118달러이고 지역과 계약에 따라 달라질 수 있습니다.

미리 보기에서 아직 안 되는 것

미리 보기 기간에는 에이전트를 만들 때 하네스를 골라야 하고 만든 뒤에는 바꿀 수 없습니다. 기존 에이전트는 바뀌지 않으며 실행 환경의 CPU와 메모리, 대기 설정은 파운드리가 관리합니다. 자기 프레임워크를 들고 오는 호스팅 에이전트에는 작업이 끊기면 원래 입력으로 다시 시작하는 기능이 이번에 정식 출시됐습니다. 지원 지역과 모델 목록은 마이크로소프트 문서 페이지에 따로 정리돼 있습니다.
