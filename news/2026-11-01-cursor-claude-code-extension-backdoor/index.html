AI 코드 편집기 커서(Cursor)⁠가 자사 VS Code 확장 마켓플레이스에서 클로드 코드 확장의 변조판이 배포됐다고 공지했습니다. 변조된 버전은 2.1.312와 2.1.313이며 10월 29일(미국 태평양 시각) 오전 2시 27분부터 오후 1시 35분 사이에 올라와 있었습니다. 커서는 이 버전들을 앤트로픽이 만든 것이 아니라고 밝혔습니다.

커서 마켓플레이스에 올라온 변조판

변조판이 올라온 곳은 커서가 운영하는 VS Code 확장 마켓플레이스입니다. 다른 버전이나 공식 배포본이 영향을 받았다는 증거는 없다고 커서는 설명했습니다. 커서는 발견 즉시 변조판을 내리고 배포를 막았습니다. 이후 마켓플레이스를 통째로 닫은 채 접근 기록을 점검해 다른 확장은 변조되지 않았음을 확인했고 키를 바꾼 뒤 마켓플레이스를 다시 만들어 열었습니다. 공지는 10월 30일 오전 11시 30분(태평양 시각)⁠에 영향받는 버전과 침해 지표를 고쳐 다시 올라왔습니다. 변조판이 어떤 경로로 올라왔는지와 설치 수는 공지에 나오지 않습니다.

SSH 키를 심고 밖으로 통로를 여는 코드

변조판은 설치된 컴퓨터의 호스트 이름, 사용자 이름, 운영체제, 홈 폴더 경로, 깃 이메일, 공인 IP 같은 정보를 모아 외부 서버로 보냈습니다. 이어 공격자의 공개 키를 svc-telemetry라는 이름으로 SSH authorized_keys 파일에 덧붙인 다음 컴퓨터의 SSH 서비스를 켜고 역방향 SSH 터널을 열려고 했습니다. 이 단계는 관리자 권한이 필요해서 커서를 관리자 권한으로 띄운 드문 경우가 아니면 맥OS와 윈도우 대부분에서 실패했을 것이라고 커서는 봅니다. 그래도 맥OS에는 LaunchAgent를, 윈도우에는 SYSTEM 권한으로 도는 예약 작업을 남기려 했고 이 스크립트는 약 60초마다 터널 연결을 다시 시도합니다. 공격자 서버는 커서가 호스팅 업체와 협력해 내린 상태입니다.

컴퓨터에 남는 흔적

공지에 실린 침해 지표를 보면 변조판은 윈도우용(win32-x64)⁠과 맥OS용(darwin-arm64) 확장 파일로 나왔습니다. 맥OS와 리눅스에서는 ~/.config/.smt, ~/.config/.smtk 파일과 /tmp 아래 .stk_로 시작하는 파일이 생길 수 있고 맥OS에는 com.apple.sysmond라는 이름의 LaunchAgent가 붙습니다. 윈도우에서는 사용자 폴더의 .config 안에 smt.cmd가, 시작 프로그램 폴더에 sysmon.cmd가 생기고 SysMon이라는 예약 작업이 등록됩니다. 공지에는 변조된 확장 파일 네 개와 실제 악성 코드 파일의 SHA-⁠256 해시도 함께 실려 있습니다.

확장만 지워서는 끝나지 않습니다

커서는 확장을 지우는 것만으로는 충분하지 않을 수 있다고 경고했습니다. 변조판이 확장과 따로 도는 스크립트를 남기기 때문입니다. 맥OS에서는 authorized_keys 파일에서 svc-telemetry 문자열을 찾는 명령 한 줄로 감염 여부를 볼 수 있고 윈도우는 PowerShell로 같은 파일을 살핍니다. 키가 나오면 그 컴퓨터를 네트워크에서 떼어 놓고 커서가 올린 정리 스크립트를 돌린 다음 그 컴퓨터에서 접근할 수 있던 계정 정보와 세션을 믿을 수 있는 다른 기기에서 바꿔야 합니다. 맥OS 스크립트는 root가 아닌 해당 사용자 계정으로 실행하고 윈도우 스크립트는 관리자 권한 PowerShell에서 실행합니다. 문의 창구는 security@cursor.com입니다.
