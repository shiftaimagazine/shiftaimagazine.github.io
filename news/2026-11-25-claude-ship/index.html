앤트로픽(Anthropic)⁠이 11월 23일(미국 시각) 풀 리퀘스트⁠(PR)를 검토하고 고치고 승인까지 맡는 기능 묶음 '클로드 쉽(Claude Ship)'을 베타로 내놓았습니다. 코드 리뷰, PR 스튜어드(PR Steward), 클로드 어프루벌스(Claude Approvals) 세 가지로 이뤄져 있고 팀이 정해 둔 정책에 따라 병합해도 되는 변경을 클로드가 직접 승인합니다.

SHIFT 판정 · 지켜보세요베타 단계이고 Team⁠·Enterprise 플랜의 깃허브 저장소에서만 쓸 수 있습니다.
오늘 바로 해 보세요클로드 Team이나 Enterprise를 쓰는 팀이라면 저장소 한 곳에서 관찰 전용 모드로 먼저 켜 보고 승인 정책 파일 초안을 관리자와 상의해 보세요.
  • 세 기능 묶음. 코드 리뷰는 정식 출시이고 PR 스튜어드와 클로드 어프루벌스는 베타입니다
  • Team⁠⁠·Enterprise 플랜의 깃허브 저장소. 제로 데이터 보존 조직은 쓸 수 없습니다
  • 사용량은 토큰으로 과금. 관리자가 지출 한도를 정할 수 있습니다

검토, 수리, 승인이 따로 움직입니다

코드 리뷰는 여러 관점으로 PR을 깊게 살피고 찾은 문제를 적대적으로 검증한 뒤 분류해서 PR에 올립니다. 리뷰 수준은 저장소마다 퀵, 스탠더드, 딥(Quick, Standard, Deep) 중에서 고릅니다. PR 스튜어드는 실패한 CI 검사와 병합 충돌, 리뷰 의견을 처리해 PR을 초록불 상태로 유지하려고 하지만 PR을 승인하거나 병합하지 않도록 설계되었습니다. 푸시할 때마다 무엇을 바꿨고 어떻게 되돌리는지 댓글을 남기고 개발자는 @claude로 지시하거나 @claude stop으로 멈춥니다.

승인 여부는 저장소 안의 정책 파일이 정합니다

클로드 어프루벌스는 팀이 저장소 안의 파일로 써 둔 승인 정책을 적용합니다. 소개 글은 이를 더 똑똑한 CODEOWNERS 파일에 비유합니다. 정책이 허용하는 일상적인 변경은 클로드가 스스로 승인하고 특정 상황에서는 사람의 승인을 요구할 수 있으며 판단 신호로는 코드 리뷰 결과나 자연어 분류기를 쓸 수 있습니다. 앤트로픽은 먼저 관찰 전용(observe-only) 모드로 켜서 신뢰를 쌓으라고 권하고 기존 브랜치 보호와 필수 검사도 그대로 쓸 수 있습니다.

개발자는 /ship, 관리자는 저장소 단위로

개발자는 클로드 코드의 새 /ship 명령으로 푸시와 PR 열기, 리뷰, 실패한 검사 처리까지 맡길 수 있습니다. 무엇을 병합할 수 있는지는 개발자의 권한과 저장소의 브랜치 규칙에 따르고 /ship은 클로드 코드와 데스크톱 앱에 이날부터 순차 배포됩니다. 관리자가 저장소 단위로 켜면 그 저장소의 PR 전체에 적용되고 저장소마다 리뷰 수준과 실행 시점, 지출 한도를 정합니다.

요금과 쓸 수 없는 조직

사용량은 토큰으로 과금되므로 켜면 조직 비용이 늘 수 있고 비용은 포함되는 PR의 수와 크기, 리뷰 수준, 실행 빈도, PR 스튜어드의 작업량에 따라 달라집니다. 클로드 어프루벌스에는 기본 요금이 없지만 정책에 쓰는 분류기가 쓴 토큰은 청구됩니다. 자격이 되는 Enterprise 조직은 클로드 쉽 크레딧을 최소 1만 달러 받을 수 있고 2027년 1월 15일까지 청구한 뒤 30일 안에 써야 합니다. 제로 데이터 보존, HIPAA 구성, 고객 관리 암호화 키를 쓰는 조직은 이용할 수 없으며 국가별 제공 여부는 소개 글에 나오지 않습니다.
