캔바, 첫 자체 이미지 모델 '크래프트' 공개…구도부터 짜고 그린다

캔바 리서치 · 드림랩·공개 API 바로 제공, MCP 연동은 '곧'

  • 레이어로 편집. 매직 레이어스와 연동해 생성 이미지를 편집 가능한 요소로 분리
  • 드림랩·API 바로. 전 세계 사용자 대상, MCP 연동과 경량 버전은 '곧'

디자인 플랫폼 캔바(Canva)가 처음으로 직접 만든 이미지 생성 모델 '캔바 크래프트(Canva Craft)'를 공개했다. 사내 AI 연구조직 캔바 리서치가 처음부터 설계하고 학습시킨 첫 파운데이션 모델이다. 외부 모델을 빌려 쓰던 디자인 툴이 생성 엔진까지 직접 쥐겠다는 신호다.

무슨 일인가

캔바는 뉴스룸에서 크래프트를 디자인 작업을 위해 만든 이미지 모델로 소개했다. 핵심은 2단계 구조다. 첫 단계에서 계획 모델이 프롬프트를 읽고 어떤 요소가 어디에 얼마나 크게 들어갈지, 시각적 위계와 들어갈 글자까지 담은 구성안을 쓴다. 두 번째 단계에서 렌더링 모델이 이 구성안대로 최대 2K 해상도 이미지를 그린다. 화면비는 30종 넘게 고를 수 있다. 회사는 이 계획 단계 덕분에 글자 가독성, 사물 배치, 개별 요소 제어가 나아졌다고 설명했다. 이미지 속 글자는 55개 언어로 넣을 수 있고 프롬프트는 어느 언어로 써도 된다.

세부 내용

학습 데이터에는 사람이 만든 캔바 템플릿 수백만 개가 들어갔다. 사후 학습에서는 전문 디자이너의 피드백으로 지도 미세조정과 강화학습을 거쳤다. 내부 평가에서는 디자이너들이 2만 5,000쌍이 넘는 이미지를 주요 모델 결과와 비교했다. 생성 결과는 캔바의 '매직 레이어스'로 이어진다. 한 장짜리 이미지를 편집 가능한 디자인 요소로 쪼개 주는 기능이다. 캔바는 외부 순위 사이트 디자인아레나(DesignArena)에서 크래프트가 이미지 생성 모델 4위로 데뷔했고, 인물·초상과 풍경·자연 부문에서는 1위에 올랐다고 밝혔다(자체 발표 기준). 자동 평가와 디자이너 판단이 엇갈릴 때는 디자이너 쪽을 따랐다는 설명도 붙였다.

속도와 안전장치

캔바는 모델 증류로 추론 단계 수를 원래 모델의 일부 수준으로 줄였고, 자체 추론 엔진을 붙여 첫 내부 버전보다 한 자릿수 이상 빨라졌다고 밝혔다. 매직 레이어스 변환에는 요소마다 경계 상자를 JSON으로 지정하는 방식을 써 정확도와 속도를 높였다고 했다. 앞으로는 참조 이미지 활용과 더 정교한 편집 기능을 같은 구조 위에 얹을 계획이다. 입력·출력 검열과 신고 도구를 묶은 '캔바 실드'도 크래프트에 똑같이 적용된다. 드림랩은 편집 화면 왼쪽 아래 패널이나 canva.com/dream-lab에서 열 수 있다.

왜 중요한가

자체 모델을 가지면 비용과 기능 로드맵을 스스로 정할 수 있다. 특히 '글자가 제대로 들어간 이미지'와 '나중에 고칠 수 있는 결과물'은 포스터나 배너를 만드는 실무자가 가장 아쉬워하던 부분이다. 범용 이미지 모델이 완성된 그림 한 장을 내놓는 데서 끝났다면, 크래프트는 디자인 파일의 재료를 만들겠다는 쪽에 가깝다. 수많은 템플릿을 쌓아 온 캔바가 그 데이터를 모델 경쟁력으로 바꾸려는 시도로도 읽힌다.

남은 쟁점

크래프트는 드림랩에서 모든 캔바 사용자에게 열렸고 개발자용 공개 API도 바로 나왔다. 반면 AI 비서나 에이전트가 캔바 MCP 서버를 통해 크래프트를 부르는 기능은 '곧 제공'으로 표시돼 있다. 비용을 낮춘 '크래프트-패스트'와 '크래프트-울트라패스트'도 예고만 됐고 출시일은 없다. 요금과 요금제별 사용 한도도 공개되지 않았다. 순위는 캔바가 인용한 수치라 실제 작업 품질은 직접 써 봐야 판단할 수 있다.

남는 질문이미지 속 글자를 다시 손보던 시간이 줄어든다면, 디자인 작업을 한 툴 안에서 끝낼 수 있을까.
