오픈AI(OpenAI)⁠가 10월 26일(미국 시각) 중간 등급 모델 ‘GPT-⁠6.1 테라⁠(Terra)’⁠를 공개했습니다. API 표준 가격은 입력 100만 토큰당 1달러, 출력 5달러로 이전 세대인 GPT-⁠5.6 테라나 상위 모델 GPT-⁠6.1 솔⁠(Sol)⁠보다 50% 쌉니다. 회사는 속도와 사실 정확도도 크게 나아졌다고 밝혔습니다(자체 발표 기준).

성능과 비용 사이의 중간 등급

테라는 오픈AI 모델 라인업에서 성능과 비용의 균형을 맡는 중간 등급입니다. 오픈AI는 “오늘부터 챗GPT 워크와 코덱스에서 모든 플러스⁠·프로⁠·엔터프라이즈⁠·에듀 사용자가 쓸 수 있다”⁠고 밝혔고 개발자는 API에서 ‘gpt-⁠6.1-terra’⁠라는 이름으로 부를 수 있습니다. 같은 사용량 한도 안에서 GPT-⁠5.6 테라보다 더 많은 작업을 처리할 수 있다는 설명도 붙였습니다.

회사가 직접 잰 평가 점수

오픈AI가 공개한 수치는 모두 자체 측정입니다. 에이전트 평가 ‘에이전츠 라스트 이그잼(Agents' Last Exam)’⁠에서 중간 추론 강도 기준 GPT-⁠5.6 테라보다 15%포인트 높았고 토큰당 가격이 10분의 1인데도 GPT-⁠6 아스트라⁠(Astra)⁠와 비슷한 성적을 냈다고 했습니다. 터미널 작업 평가 터미널벤치 4.0에서는 최대 추론 강도로 과제의 50.3%를 풀어 GPT-⁠5.6 테라의 21.5%를 두 배 넘게 앞섰습니다. 오류를 일부러 유도하는 내부 질문 세트에서 낮은 추론 강도 기준 오답률은 53.6%에서 16.7%로 떨어졌습니다.

사내 도구의 월 비용 계산

대부분의 업무 자동화와 챗봇은 최상위 모델이 아니라 이런 중간 모델로 돌아갑니다. 같은 일을 절반 값에 세 배 빨리 처리한다면 API로 사내 도구를 만든 팀은 월 비용을 다시 계산할 이유가 생깁니다. API 비용이 절반으로 줄어드는 만큼 같은 예산으로 더 많은 호출을 하거나 추론 강도를 한 단계 올리는 선택지도 생깁니다. 다만 오픈AI 스스로 “가장 복잡한 코딩 작업에는 GPT-⁠6.1 솔과 GPT-⁠6 아스트라가 여전히 더 나은 선택”⁠이라고 적었습니다. 그러니 쉬운 일은 테라에 맡기고 어려운 일만 상위 모델로 넘기는 방식이 기본값이 됩니다.

발표문에 빠진 사양

수치는 모두 회사 자체 평가여서 실제 업무에서 얼마나 차이가 나는지는 직접 비교해 봐야 합니다. 발표문에는 컨텍스트 길이나 지식 기준일 같은 세부 사양이 없습니다. MMMU-프로와 OSWorld 2.1 같은 평가는 ‘모든 설정에서 앞섰다’⁠는 설명만 있고 숫자가 빠져 있습니다. 공개 날짜도 본문에 따로 적혀 있지 않고 무료 사용자에게 언제 열릴지도 밝히지 않았습니다.
