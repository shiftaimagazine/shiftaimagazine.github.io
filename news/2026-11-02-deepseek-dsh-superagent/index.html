중국 AI 회사 딥시크(DeepSeek)가 주말 사이 코딩 에이전트 시제품 dsh-superagent를 깃허브에 공개했습니다. 저장소 하나를 맡아 팀원이 부탁한 일을 스스로 처리하고 결과를 풀 리퀘스트 같은 형태로 돌려주는 에이전트입니다. 라이선스가 MIT라서 누구나 코드를 내려받아 고쳐 쓸 수 있습니다.

부탁을 받으면 작업 항목부터 엽니다

README에 따르면 dsh-superagent는 딥시크 하네스(DeepSeek Harness)에 얹는 묶음 형태의 능동형 코딩 에이전트입니다. 깃허브를 지켜보고 설정하면 협업 도구 페이수(Feishu)의 대화도 함께 봅니다. 허락받은 사람이 일을 맡기면 작업 항목을 하나 열고 자기 전용 세션과 폴더에서 일한 다음 처음 요청이 온 대화에 풀 리퀘스트 같은 결과로 답합니다. 사람이 손대야 하는 일은 웹 패널에 따로 모여 보입니다.

팀의 주의를 아끼도록 정한 규칙

함께 공개된 설계 문서는 사람의 주의는 가능한 한 적게 쓰고 가치는 가능한 한 많이 내는 것을 첫 원칙으로 적었습니다. 에이전트는 누군가 직접 부탁했거나 팀이 써 둔 규칙이 허락할 때만 움직이고, 요청으로 인정되는 것도 에이전트를 직접 부르면서 팀이 허락한 사람이 보낸 경우뿐입니다. 아무도 부탁하지 않은 일을 하려면 팀이 쓴 규칙이 있어야 합니다. 그런 일도 처음에는 에이전트가 무엇을 했을지 기록만 남기는 방식으로 시작합니다. 말을 거는 때는 사람이 움직여야 하거나 결과를 쓸 수 있을 때로 정해 두었습니다.

공식 제품이 아닌 연구용 코드

딥시크는 README 맨 위에 참고용 연구 시제품이며 딥시크의 공식 제품이 아니라고 적었습니다. 팀의 일상 개발에서 자라난 코드이고 상당 부분을 코딩 에이전트가 만들었기 때문에 버그가 남아 있을 수 있고 코드 스타일도 고르지 않을 수 있습니다. 공개판은 내부 버전이나 글 〈Exploring Super-agent Design〉에서 설명한 구현과 같지 않습니다. 그 글에 나온 설계 일부는 아직 구현되지 않은 앞으로의 방향입니다. 어떤 모델을 쓰는지와 성능 수치는 저장소에 나오지 않습니다.

설치는 코딩 에이전트와 함께

설정 단계가 많아서 딥시크는 사용자가 쓰는 코딩 에이전트에게 SETUP.md를 읽고 함께 설치하자고 요청하는 방법을 안내합니다. 손으로 배포하려면 배포 문서를 따로 따르면 됩니다. 저장소는 pnpm 기반으로 짜여 있고 pnpm check 명령 하나로 타입 검사와 테스트, 빌드를 함께 돌립니다. README에는 설계 글의 원문 주소가 아직 걸려 있지 않습니다.
