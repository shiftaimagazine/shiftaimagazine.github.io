XYBench, 질문 속 오해 짚기 시험

Ai2가 질문 8,115개로 모델 5종을 시험 · 목표로 이끈 답은 사람 79%, GPT-⁠5 60% · 데이터⁠·코드 공개

이런 분께 추천합니다챗GPT⁠·클로드⁠·제미나이에 방법을 물어 업무를 처리하는 직장인

원문Ai2 블로그⁠·arXiv 논문
세 줄 요약
  • 질문 8,115개. 스택오버플로 1,557개, 스택익스체인지 184개, 직접 고른 102개, 위키하우 가이드 기반 6,272개입니다
  • 요청한 방법의 해결책을 먼저 답합니다. 스택오버플로 질문에서 요청한 방법의 해결책은 답의 75%에서 86%, 목표의 해결책은 59%에서 71%에 들어 있었습니다
  • 목표로 이끈 답은 사람이 더 많습니다. 상위 사람 답 79%, GPT-⁠5 60%, 클로드 소넷 4.6 47%입니다

Ai2가 11월 13일 XYBench를 공개했습니다. 사용자가 잘못된 방법을 전제로 물었을 때 AI가 오해를 알아채고 진짜 목표로 안내하는지 재는 질문 8,115개짜리 시험이며 논문과 데이터, 코드가 함께 나왔습니다.

오늘 바로 해 보세요챗봇에 방법을 물을 때 최종 목표도 한 문장 함께 적어 보내고, 목표에 맞는 해결책이 답에 들어오는지 비교해 보세요.
  • 질문 8,115개. 스택오버플로 1,557개, 스택익스체인지 184개, 직접 고른 102개, 위키하우 가이드 기반 6,272개입니다
  • 요청한 방법의 해결책을 먼저 답합니다. 스택오버플로 질문에서 요청한 방법의 해결책은 답의 75%에서 86%, 목표의 해결책은 59%에서 71%에 들어 있었습니다
  • 목표로 이끈 답은 사람이 더 많습니다. 상위 사람 답 79%, GPT-⁠5 60%, 클로드 소넷 4.6 47%입니다

프로스팅을 되직하게 만들기 전에

XY 문제는 어떤 사람이 X를 이루려고 Y라는 방법이 통할 것이라 가정하고 Y에 대해 묻는 상황입니다. 원문의 예는 컵케이크 위에 바른 프로스팅이 자꾸 흘러내려서 더 되직하게 만드는 법을 묻는 질문이고, 실제 원인은 컵케이크가 아직 따뜻하다는 것입니다. 청소기의 경우에는 모델이 더 센 청소기를 여러 문단에 걸쳐 권하면서 막힌 호스는 짧게만 언급하는 답이 문제로 꼽혔습니다. 사람에게는 오해를 먼저 짚는 답이 더 쓸모 있는데, 모델의 답은 질문이 가리킨 방법 쪽으로 끌려가는 경향이 있었습니다.

질문 출처와 채점 방식

포럼 질문에는 점수가 높은 사람 답 세 개와 채택된 답을 비교 대상으로 썼고, 위키하우 질문은 클로드 소넷 4.5가 그럴듯한 오해를 바탕으로 만들었습니다. 요청한 방법만 답해도 문제가 거의 풀리는 예는 뺐습니다. 채점은 목표의 해결책을 말했는지, 그것을 강조했는지, 오해를 알아챘는지 세 가지로 하고 채점자는 클로드 소넷 4.5입니다. 사람 검토자 두 명이 모델 답 500개를 확인했을 때 일치율은 해결책 포함 여부 97.5%에서 100%, 오해 식별 84.6%에서 93.3%, 강조 74.2%에서 79.8%였습니다.

다섯 모델이 질문에 끌려가는 정도

시험한 모델은 클로드 소넷 4.6, GPT-⁠5, 제미나이 3.1 프로, 큐웬3.5-9B, 딥시크-V4 프로이고 질문마다 한 번씩 답하게 했습니다. 답이 주로 목표에 맞춰진 경우는 스택오버플로에서 35%에서 41%였고 47%에서 57%는 요청한 방법에 맞춰져 있었습니다.

요청한 방법의 해결책과 목표의 해결책 중 하나를 고르게 하면 GPT-⁠4.1을 더한 여섯 모델 모두 스택오버플로에서 71%에서 84%로 목표에 맞춘 답을 골랐습니다. 연구진은 좋은 조언을 알아보는 능력과 직접 만들어 내는 능력 사이에 간격이 있다고 해석합니다. 요청한 방법과 목표를 둘 다 알려 주면 소넷 4.6이 목표의 해결책을 말하는 비율이 59%에서 67%로 올랐지만 오해를 식별하는 비율은 47%에서 34%로 내려갔고, 모든 모델이 오해 식별에서 사람에 못 미쳤습니다.

영어 질문과 한 번 묻고 답하는 형식

시험은 영어 질문과 주로 절차형 문제를 다루고, 한 번 묻고 답하는 형식만 평가합니다. 채점을 LLM이 맡았다는 점도 한계로 적혀 있습니다. 다른 언어와 여러 차례 이어지는 대화로 넓히는 일은 열린 방향으로 남아 있습니다. 데이터는 허깅페이스 allenai/XYBench-dataset, 코드는 깃허브 allenai/XYBench에 있고 두 페이지 모두 라이선스를 적지 않았습니다. Ai2는 이 논문이 EMNLP 2026에서 최우수 리소스 논문상을 받았다고 적었습니다.
