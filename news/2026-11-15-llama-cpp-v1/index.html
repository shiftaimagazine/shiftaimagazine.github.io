로컬에서 AI 모델을 돌리는 오픈소스 엔진 llama.cpp가 11월 13일 v1.0.0을 냈습니다. 함께 쓰이는 라이브러리 ggml도 같은 번호로 올라갔고, 공개 C API가 호환되지 않게 바뀔 때는 앞으로 메이저 번호를 올린다는 약속이 붙었습니다.

  • 폐지 함수 35개 제거. FP8 KV 캐시와 MoE 전문가 캐시가 새로 들어왔습니다

1.0이라는 번호가 정하는 약속

블로그는 프로젝트가 시작한 지 3년 반이 됐고 이 라이브러리를 바탕으로 만든 앱이 많아졌다고 설명합니다. 그래서 유연하면서도 안정된 API가 가장 중요하고, 1.0.0은 그 개발자들에게 책임을 지겠다는 신호로 냈다고 합니다. 앞으로 llama.cpp와 ggml은 API와 ABI가 호환되지 않게 바뀔 때 메이저 번호를 올립니다. 공개 C API(./include)⁠를 깨는 변경이 메이저, 하위 호환 기능과 백엔드 업데이트, 모델 지원, API 추가가 마이너, API가 그대로인 버그 수정이 패치입니다.

빠진 함수와 새로 들어온 기능

릴리스 노트에 따르면 폐지됐던 공개 API가 제거됐습니다. llama_set_warmup과 폐지 함수 35개, defrag_thold 옵션이 빠졌고 NextN과 추측 디코딩 API는 llama.h로 올라왔으며 llama_set_embd_state_src는 llama_set_ctx_state_src로 이름이 바뀌었습니다. 제거된 함수를 부르던 코드는 새 버전에서 빌드되지 않을 수 있습니다. 새 기능으로는 FP8 KV 캐시(-ctk/-ctv f8_e4m3)⁠와 호스트 메모리에 두는 MoE 전문가 캐시가 있고, llama_context_params에는 moe_cache_size와 moe_cache_cpu_share가 생겼습니다. 새로 지원하는 모델에는 Kimi-K3.1-Pro와 새 밀집 구조의 Ripple-⁠65B-Preview, drama-⁠3 음성 합성이 있으며 음성 합성용 /v1/audio/speech 엔드포인트도 추가됐습니다.

서버 보안 수정과 설치 경로

서버에는 SSRF, CORS, DNS 리바인딩, MCP 도구 취소와 관련한 보안 수정이 들어갔습니다. 인증 없는 도구 호출과 사설 주소 미디어 접근은 -⁠-⁠allow-unauthenticated-tools와 -⁠-⁠media-allow-private-urls 옵션을 직접 켜야 쓸 수 있습니다. 웹 화면은 대화 묶음과 마크다운 편집기, 모바일 배치를 갖춰 새로 만들었습니다. llama.cpp는 150종이 넘는 아키텍처 변형을 지원하고 CI에는 엔비디아, AMD, 퀄컴, Arm, IBM, 인텔의 하드웨어가 쓰입니다. 설치는 홈브루, 윈젯, conda-forge, 도커, 데비안, 맥포트로 할 수 있고 안드로이드와 iOS는 사전 릴리스 파일로 받습니다. 성능 수치와 라이선스는 블로그와 릴리스 노트에 나오지 않습니다.
